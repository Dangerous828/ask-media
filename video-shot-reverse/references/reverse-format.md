# 反推格式

> 本文件是**本仓落地版**。公开材料只给出「镜头边界判定表」与「八要素公式／一镜一运镜」两条规则，
> 完整规则未公开。逐镜 schema、证据分级、置信度、标签规则与 QC 条目按本仓既有纪律补齐，
> 不声称复刻任何第三方实现。

## 逐镜台账 schema

一次拆解的输出是严格 JSON，不允许大段场景概括代替逐镜：

```json
{
  "video": {"id": "@视频1", "source": "...", "duration_seconds": 0.0},
  "global": {"aspect_ratio": "", "color": "", "lighting": "", "style": "", "medium": ""},
  "shots": [
    {
      "shot_id": "SRC-01",
      "in": 0.0,
      "out": 0.0,
      "shot_size": "",
      "angle": "",
      "camera_height": "",
      "camera_motion": {"dominant": "", "secondary": "", "note": ""},
      "subjects": [{"tag": "<主体1>", "description": "", "evidence": "observed|inferred|unclear"}],
      "location": {"tag": "<场景1>", "description": "", "evidence": "observed|inferred|unclear"},
      "action": "",
      "expression": "",
      "blocking": "",
      "transition_in": "",
      "transition_out": "",
      "visible_text": [{"text": "", "position": "", "evidence": "observed|inferred|unclear"}],
      "audio": {"dialogue": "", "sfx": "", "music": "", "evidence": "observed|inferred|unclear"},
      "props": [{"item": "", "state": "", "evidence": "observed|inferred|unclear"}],
      "confidence": "high|medium|low",
      "notes": ""
    }
  ]
}
```

**字段纪律**：`in/out` 是切点秒数，不是 caption 内容；每项证据按三级标；`confidence` 是整镜可信度。
没有观测到的字段留空并写进 `notes`，不填推断值。

### 两次追问

第一次要严格 JSON。返回的是场景概括时，第二次只追三件事：切点、运镜变化、动作状态变化。
第二次结果**只当补充证据**，与第一次矛盾时两条都留进 `notes`，在 QC 里裁决，不静默取一条。

## 证据分级

| 级别 | 判据 | 能写进哪里 |
|---|---|---|
| `observed` 观测 | 画面／音轨直接可见可听 | 台账事实列、caption 正文 |
| `inferred` 推断 | 由多个观测推出，但本帧看不见 | 只进 `notes`，写「疑似」 |
| `unclear` 未观测 | 被遮挡、过暗、出画、听不清 | 只进 `notes`，写「看不清／没听到」 |

**遮挡处不补动作**：手被挡住就写「手部不可见」，不写「握紧拳头」。模型会把编出来的动作演成一只没设计过的手。

## 镜头边界判定表

**开新行**（任一实质变化）：

- 硬切、叠化、划像等明确转场
- 机位、景别、角度明显变化
- 场景或地点变化
- 主体动作节拍、情绪节拍、走位变化大到需要新提示词
- 字幕、标题、图形出现或消失
- 重要道具、产品状态变化

**不拆**：

- 不因「过了几秒」拆；画面没实质变化，几秒不等于新镜头
- 不因「主体相同」合并；两个视觉上明显不同的镜头不能合并

判据一句话：**有实质变化才拆，没有实质变化不拆**。实质变化 = 转场、机位、场景、动作节拍、文字、
道具状态里至少一个质变。

## 稳定标签

反复出现且**视觉特征稳定**的主体、场景建 `<主体1>` `<场景1>`，跨镜复用，映射表单独列。
只出现一次的用描述性短语，比硬贴标签更清楚。
标签只承担身份与地理，不承载动作、姿势或情绪——这些每镜重新观测。

## 观测 → caption 翻译层

观测数据是原始材料，直接搬进提示词会出三类事故：时间码被当字幕烧进画面、一镜叠多种运镜、
情绪词没有物理证据。过一道翻译：

1. **八要素**：精确主体 + 动作细节 + 场景环境 + 光影色彩 + 运镜方式 + 视觉风格 + 画质 + 约束。
   没观测到的要素一律不当事实写；需要画质或稳定性约束时放全局约束段，并标注「生成附加约束」。
2. **一镜一主导运镜**：`fixed` / `slow push-in` / `slow pull-back` / `pan` / `tilt` / `dolly` /
   `follow shot` / `lateral tracking shot` / `orbit` / `handheld slight shake` / `over-the-shoulder close-up`，
   每镜只选一种最明显的，次要趋势写进备注。
   「镜头推进并摇移」→ 主导写 `slow push-in`，备注「同时有轻微左右摇」。
3. **情绪翻成物理证据**：不写「他很紧张」，写观测到的「手指反复扣住杯沿、视线两次移向门口」。
4. **音频与文字固定符号，只在有证据时用**：（ ）背景音乐、< > 音效、{ } 对话、【 】字幕标题。
   没听到的对话不写，没看到的字不编。

### 方言可插拔

上面 1–4 是**格式骨架**，与模型无关；符号与运镜词表属于具体方言。

- **SD2 / Seedance caption**：使用本节符号、八要素公式与运镜词表，一镜一运镜为硬规则。
- **MiniMax H3（本仓主通道）**：正文由 `h3-prompt-writing` 的 Ref2VA 六段／三段结构承担，帧数按 `17k+5`
  吸附、经 h3q 提交、无参考图否定通道、接缝靠真实末帧接力。**SD2 的 （ ）< >{ }【 】 符号与
  「八要素」句式不进 H3 正文**；搬运的只有观测字段、证据分级和一镜一主导运镜这条纪律。
- 反推产物默认是**人读、可存档、可拍的分镜台账**。要送去生成时才按目标方言翻译；这一步是新的授权。

## QC 12 条

逐条给结论（通过／已修正／不适用＋理由）。`不适用` 也要写理由，不留空。

1. 每行是否恰好对应一个镜头，没有一行塞两镜、一镜拆两行
2. 每镜是否只有一种主导运镜，次要趋势是否进了备注
3. 时间码／秒数是否跑进了 caption 列
4. 有没有裸露的资产 ID、路径或内部编号混进 caption
5. 遮挡、出画、过暗处有没有被脑补成具体动作
6. 形容词有没有加码（「非常」「极其」「电影感」这类没有观测支撑的堆叠）
7. 未观测要素是否都留在 `notes` 而不是写进事实列
8. 稳定标签是否只给了视觉特征稳定的主体／场景
9. 字幕、图形、道具状态变化是否都触发了新行
10. 两次追问的矛盾是否已在 `notes` 里裁决
11. 音频与文字符号是否只在有证据时出现
12. 方言是否匹配目标通道：SD2 符号没进 H3 正文，H3 正文没套 SD2 句式

## 组装

完整分析 = 视频概览（时长／全局风格／画幅色彩光照） + 引用映射表（`<主体1>` → 描述与出处镜）
+ 分镜表（逐行一镜，含证据等级与置信度） + QC 备注（12 条结论与未决项）。
