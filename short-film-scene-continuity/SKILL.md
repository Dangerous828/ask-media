# 短片场景账与连续性

短片最常见的结构病是"场景断层"：场景多而无动机、同场陈设和光位漂移、跨景道具凭空消失。病根在大纲层，所以场景账在写正文之前定死，正文和分镜不许违账。**连续性按镜头关系判定，不按片长豁免：5 秒、10 秒、30 秒、60 秒及更长的独立短片都执行同一套账。**

## 何时用 / 不用

- 用：任何时长独立短片的大纲、剧本或分镜定稿前；分镜开工前核场景；发现同场陈设漂移、换景突兀时回查。
- 不用：长剧分集结构（走 `short-drama-develop`）；镜头语言与提示词（走 `storyboard-30s`、`doc-still-prompt`、`h3-prompt-writing`）。

## 1. 场景账三问（大纲层回答，正文不许新增场景）

1. 本片共几个场景？
2. 每次转变落在哪一镜 / 哪一拍？
3. 转变的叙事动机是什么：情绪转折、空间逻辑、时间推进？

建议：**非短剧独立短片**优先以 2 个主场景 + 1 次转变为宜，超出时先检查能否合并进同一空间；这是结构建议，不按片长设门槛，也不替代逐镜连续性核对。短剧单集的场景数以已接受剧本和《导演.md》为准，不按此打回。

## 2. 场景即情绪

转变踩在情绪弧的转折点上，不任意切。常见映射：封闭空间承载对抗/防御，开阔空间承载接受/和解。映射服从本片剧情，不当公式套用。

## 3. 空间锚点三件套（每场一组，同场所有镜头共享）

| 锚点 | 写什么 |
|---|---|
| ① 地面/墙面材质 | 如"暖木地板 + 浅色墙""草坪 + 白色木桌" |
| ② 主光源实体与方向 | 如"窗口斜射日光""高空太阳 + 天空反弹" |
| ③ 边界陈设一件 | 如"沙发""远处篱笆/树荫" |

- 大纲里每场写一句"空间锚点概述"；分镜层展开为三件套，写进分镜片头【场景】，并对应关键帧账本"光从哪来"一行。
- 没有锚点的场 = 场景断层，不许开写镜头。

## 4. 换景纪律

1. 换景只发生在**镜间切点**；一场之内方位、陈设、光位不漂移，跨景别切换也不改陈设。
2. 换景镜给足建立信息（新场景空镜或带人建立镜）。
3. 转变后第一镜是全片场景契约的**重建点**：重新交代地面、光源、陈设与人物新方位，后续镜头回指这组锚点。
4. 跨景连续物（手里端着的碗、嘴角的痕迹）在换景镜显式声明"物随人走"，到新场景**先落位再动作**。

## 5. 连续性

1. 每个转折落在一个**可见动作**上（摔门、递出、转身），不只靠台词宣告。
2. 相对时间（"后半段""最后 N 秒"）先按片长换算成明确时间边界再写；换算只解决时间定位，不降低连续性要求。
3. 站位 / 视线 / 持物：写下一场前核上一场末姿态（谁拿着什么、谁面朝哪）；同场内不许跳。
4. **同场连续性账**：同一场景内每个可见人物登记身份视图、服装与关键道具状态、屏幕方向、持物手、主光源与边界陈设。下一镜从上一镜的末状态续起；有意改变时必须写明可见动作与原因，并同步上游文档。
5. **生成边界也服从连续性**：为执行限制拆分生成任务时，每段仍须从上一段的真实结束状态续起；不能因换生成任务而重置人物、服装、光位、持物或空间方向。
6. 原文改编只做结构化提取，不整段复制，台词重写为口语。

## 6. 信息差三层账

每场或每集记账：观众知道什么 / 角色知道什么 / 角色以为什么。

- 每集至少揭示一层，同时埋一个新谜；揭示时刻给实物或反应特写，不用台词解释。
- **悬疑题材附加**（仅题材需要时）：关键证据三次出现（伏笔 → 强调 → 回收）；设一个红鲱鱼，回收时反转其含义；关键道具在动作描述里给特写级描写，便于资产提炼。

## 7. 交付：场景账表

```text
| 场景 | 镜/拍范围 | 空间锚点（地面 / 主光源 / 边界陈设） | 情绪职责 | 进入动机 | 随人进出的连续物 |
| 信息差 | 观众知道 | 角色知道 | 角色以为 | 本集揭示 | 新埋的谜 |
```

交给下游：短剧项目交 `short-drama-storyboard`，独立短片交 `storyboard-30s`（片头【场景】【道具】、道具进出 `名（进场镜→退场镜）`）与 `doc-still-prompt`（账本光源行、SHOTLIST 跨镜连续物）。

## 自检

- [ ] 场景数量与转变次数有叙事理由，没有为凑变化增加场景？
- [ ] 每次转变有动机，且落在镜间切点？
- [ ] 每场有锚点三件套？
- [ ] 转变后第一镜重建了锚点？
- [ ] 跨景连续物已登记"物随人走"或"留在原场景"？
- [ ] 同场每个可见人物的身份视图、服装、持物、屏幕方向和光位有连续性登记？
- [ ] 每次生成任务拆分都有接缝的起止状态，不因拆分而重置人物或空间？
- [ ] 每个转折有可见动作？信息差账至少揭示一层？
