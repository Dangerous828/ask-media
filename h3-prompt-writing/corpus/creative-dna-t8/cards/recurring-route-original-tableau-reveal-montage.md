# 路线揭幕｜重复通道依次亮出原创反应场景

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Preserve the user's subject and objective, then fill every missing scene, trigger, event-chain, camera, sound, and payoff slot.
2. Treat these anchors as mandatory:

- Establish one recurring route and one repeatable reveal zone before the first tableau.
- Use a physically motivated object to create a complete visual occlusion before every reveal.
- Return to the same route between tableaux while preserving direction and environmental anchors.
- End on a fully readable original reaction with no unfinished wipe.

3. Change source-specific people, setting, props, palette, dialogue, shot boundaries, sound family, and payoff surfaces together.
4. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
5. Silently verify anchor coverage, continuity, timing, physical causality, and anti-copy distance before returning the final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define stable subjects once and preserve event order, camera motivation, sound intent, and overall duration.
- Use a simple paragraph for simple concepts or an ordered multi-shot structure for complex concepts.
- State overall duration once; do not copy H3 field labels or per-shot timecode grammar.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism instead of returning a generic portrait or showcase.
- Do not omit, reorder, or weaken a required anchor.
- Do not reuse source people, brands, dialogue, exact storyboard, signature props, exact timings, or recognizable effect surfaces.

## 用途

让同一条移动通道反复回场，每次用经过物形成完整遮挡，再在同一空间位置揭出一个独立原创反应场景；每个场景只保留一次清楚关系变化和短暂停顿，随后回到通道继续接力，最后用新的原创场景收束。

`重复通行路线 + 固定揭幕区 + 每次完整移动遮挡 + 不同全成年原创反应场景 + 场景之间回到同一路线 + 完整终态反应`

# 路线揭幕｜重复通道依次亮出原创反应场景 Template

## Mechanism

Establish one recurring transit route as the connective carrier. Use a fully motivated moving occluder to replace that route with one self-contained original reaction tableau in a fixed reveal zone. Give each tableau a different adult cast, prop family and single readable relationship change, hold it briefly, then restore the same route before the next reveal. End on a completed original reaction rather than a partial wipe. The reusable mechanism is recurring-route continuity, motivated occlusion, distinct tableau revelation and reaction closure—not any source meme, recognizable likeness, exact pose, city block, taxi, vehicle interior, food gesture, wardrobe, timing, watermark, creator identity or model label.

## Invariants

### inv-01

- Rule: Establish one recurring route and one repeatable reveal zone before the first tableau.
- Purpose: Provides connective geography for otherwise separate situations.
- Failure if removed: Unrelated establishing shots turn the result into an ordinary compilation.

### inv-02

- Rule: Use a physically motivated object to create a complete visual occlusion before every reveal.
- Purpose: Makes each replacement attributable and hides the spatial handoff cleanly.
- Failure if removed: An arbitrary cut loses the route-based montage grammar.

### inv-03

- Rule: Give every tableau one distinct adult cast, prop family and readable relationship change.
- Purpose: Prevents the sequence from repeating the same joke with cosmetic swaps.
- Failure if removed: Copying familiar poses or reusing the same interaction becomes imitation rather than a reusable system.

### inv-04

- Rule: Return to the same route between tableaux while preserving direction and environmental anchors.
- Purpose: Keeps the montage legible as one relay rather than disconnected sketches.
- Failure if removed: Changing the street axis or travel direction removes connective continuity.

### inv-05

- Rule: End on a fully readable original reaction with no unfinished wipe.
- Purpose: Provides a terminal payoff and a countable final state.
- Failure if removed: Ending during transit leaves the last tableau unresolved.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Establish one recurring route and one repeatable reveal zone before the first tableau.
- Use a physically motivated object to create a complete visual occlusion before every reveal.
- Return to the same route between tableaux while preserving direction and environmental anchors.
- End on a fully readable original reaction with no unfinished wipe.

## Anti-Copy Boundary

- all recognizable source meme tableaux, public likenesses, facial identities, signature poses and reaction timing
- the source city block, storefronts, taxis, road vehicles, car interior and repeated urban route
- the source phone, cup, red-dress glance tableau, child passenger reaction, food-service gesture and yellow-shirt reaction
- the source wardrobe, prop colors, camera positions, transition cadence and exact scene order
- the source creator identity, Seedance 2.5 claim, platform overlays, watermark and any visible branding

   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
