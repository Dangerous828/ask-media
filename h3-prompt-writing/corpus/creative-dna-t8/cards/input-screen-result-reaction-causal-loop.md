# 输入—屏幕—结果—反应｜实体操作与虚拟反馈逐拍闭环

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Preserve the user's subject and objective, then fill every missing scene, trigger, event-chain, camera, sound, and payoff slot.
2. Treat these anchors as mandatory:

- Establish one clearly adult operator, physical controls and response display together.
- Show each important physical input before its matching virtual response.
- Escalate from setup and navigation to one decisive result state.
- End by reconnecting the result to the same adult's readable reaction.

3. Change source-specific people, setting, props, palette, dialogue, shot boundaries, sound family, and payoff surfaces together.
4. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
5. Silently verify anchor coverage, continuity, timing, physical causality, and anti-copy distance before returning the final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define stable subjects once and preserve event order, camera motivation, sound intent, and overall duration.
- Use a simple paragraph for simple concepts or an ordered multi-shot structure for complex concepts.
- State overall duration once; do not copy H3 field labels or per-shot timecode grammar.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism instead of returning a generic portrait or showcase.
- Do not omit, reorder, or weaken a required anchor.
- Do not reuse source people, brands, dialogue, exact storyboard, signature props, exact timings, or recognizable effect surfaces.

# 输入—屏幕—结果—反应｜实体操作与虚拟反馈逐拍闭环 — 摘要

## 用途

先建立成年玩家、实体控制器和屏幕同框关系；每个虚拟动作前必须先看见一次具体输入，屏幕反馈随后发生，玩家再给出清楚可辨的人物反应。用选角、移动、反击和胜负四级闭环升级，终局只确认结果与人物，不补写来源中未出现的再开一局。

## 推荐输入格式

`明确成年原创操作者、实体输入设备和响应屏幕或机器同一地理先建立 + 每个重要虚拟或机械事件前先展示一个具体物理输入 + 至少三组不同输入—响应对应且输出不得提前 + 从选择、导航或防御升级到一个决定性结果 + 终局把结果重新连接到同一成年人物的清楚可辨的人物反应`

> 原创夜间温室控制室内，一名明确成年技术员、触觉控制台和展示三条种植区的玻璃墙同框建立。；依次展示三组不同对应：拉杆向下后通风口关闭，摇杆向左后机械臂左摇，按下带护罩按钮后授粉扫描器下降；绝不让输出先于输入。；回到同一成年人松开控制器并克制地舒一口气，绿色通道仍可见；不复制来源街机、游戏、机柜、角色与品牌。

# 输入—屏幕—结果—反应｜实体操作与虚拟反馈逐拍闭环 Template

## Mechanism

Establish one original clearly adult operator, a physical input device and a visible response display in the same geography. For every important virtual event, show one specific physical input first, then the corresponding screen or machine response, then a readable operator reaction when appropriate. Escalate from selection through locomotion and defense to one decisive result. Reconnect the result to the same adult rather than ending on the interface alone. The reusable mechanism is input-before-output evidence, device-screen correspondence, escalating task states and human-result closure—not the source woman, arcade, game, characters, cabinet, controls, moves, venue, creator identity or timing.

## Invariants

### inv-01

- Rule: Establish one clearly adult operator, physical controls and response display together.
- Purpose: Creates a verifiable causal system.
- Failure if removed: Screen-only footage cannot prove who caused the action.

### inv-02

- Rule: Show each important physical input before its matching virtual response.
- Purpose: Preserves temporal causality.
- Failure if removed: Output-first editing makes control correspondence ambiguous.

### inv-03

- Rule: Use at least three different input-response pairs rather than repeating one button.
- Purpose: Demonstrates a reusable control grammar.
- Failure if removed: A single repeated action provides little mechanism breadth.

### inv-04

- Rule: Escalate from setup and navigation to one decisive result state.
- Purpose: Builds a complete task arc.
- Failure if removed: Disconnected interactions feel like a demo reel.

### inv-05

- Rule: End by reconnecting the result to the same adult's readable reaction.
- Purpose: Closes machine evidence with human meaning.
- Failure if removed: An interface-only ending loses the operator.


## Variable Slots

| Slot | Constraint |
|---|---|
| lead_subject | An original stable subject or pair with a readable role. |
| setting | A new setting with fixed spatial anchors and no source-specific surface. |
| escalation_variable | One causal variable that changes through visible stages. |
| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Establish one clearly adult operator, physical controls and response display together.
- Show each important physical input before its matching virtual response.
- Escalate from setup and navigation to one decisive result state.
- End by reconnecting the result to the same adult's readable reaction.

## Anti-Copy Boundary

- source adult woman, face, clothes and reactions
- source Japanese arcade venue, cabinet and game screen
- source game characters, moves, selection and knockout interface
- source token, joystick, buttons and exact hand actions
- source camera route, Seedance 2.5 wording, creator identity and timing

## Transfer Tests

1. An adult greenhouse technician uses a tactile console to select a zone, steer a camera arm, close a vent and complete a pollination scan; each lever or dial precedes the visible machine response and final status reaction.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family
2. An adult museum lighting operator uses an original cue desk to choose a gallery, move one spotlight, dim a wall and trigger a final exhibition reveal, with each input shown before the room response.
   - Preserved: inv-01, inv-02, inv-03, inv-04, inv-05
   - Changed: lead_subject, setting, escalation_variable, performance_rule, camera_grammar, payoff, sound_family

## Model Skeletons

### MiniMax H3

    integrated_multimodal_description: [new subject, environment, ordered actions, camera, light and final state preserving every anchor]
    overall_soundscape: [diegetic ambience, action cues and causal payoff]
    non_diegetic_music: [original music arc or N/A]

### Seedance 2.0

    任务：[原创实例意图]
    总时长约[4–15]秒。
    主体定义：[稳定人物、物体与空间关系]
    事件或镜头：[按因果顺序实现全部锚点]
    整体风格与画质：[原创媒介、光影、色彩与声音]
    约束：[连续性、物理逻辑、反复制与结尾状态]

Adapt shot count to the user's concept. Preserve the causal mechanism, not a fixed storyboard.
