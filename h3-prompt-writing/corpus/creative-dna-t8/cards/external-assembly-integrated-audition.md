# 外部装配｜逐件安装到整机动作验收

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Read [references/summary.md](references/summary.md) for fit, input slots, and the concise starting example.
2. Read [references/template.md](references/template.md) completely before drafting.
3. Preserve the user's subject and objective, then fill every missing scene, trigger, event-chain, camera, sound, and payoff slot.
4. Treat these anchors as mandatory:

- Establish one stable subject, assembly station and unmodified baseline.
- Install major components one at a time and return to a whole-subject check after each stage.
- Complete all small functional or decorative components before testing motion.
- End with one integrated movement audition and a held complete state.

5. Change source-specific people, setting, props, palette, dialogue, shot boundaries, sound family, and payoff surfaces together.
6. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
7. Silently verify anchor coverage, continuity, timing, physical causality, and anti-copy distance before returning the final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define stable subjects once and preserve event order, camera motivation, sound intent, and overall duration.
- Use a simple paragraph for simple concepts or an ordered multi-shot structure for complex concepts.
- State overall duration once; do not copy H3 field labels or per-shot timecode grammar.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism instead of returning a generic portrait or showcase.
- Do not omit, reorder, or weaken a required anchor.
- Do not reuse source people, brands, dialogue, exact storyboard, signature props, exact timings, or recognizable effect surfaces.

# 外部装配｜逐件安装到整机动作验收 Template

## Mechanism

Keep one subject and assembly station spatially fixed while a visibly larger external operator installs components in a deliberate order. Alternate local contact proof with repeated whole-subject state checks so every addition accumulates. Reserve fine calibration for after the main silhouette is complete, then require one integrated movement audition that demonstrates all installed parts together before the final hold.

## Invariants

### inv-01

- Rule: Establish one stable subject, assembly station and unmodified baseline.
- Purpose: Provides a state reference for every addition.
- Failure if removed: Without a baseline, later parts cannot be attributed to the operator.

### inv-02

- Rule: Install major components one at a time and return to a whole-subject check after each stage.
- Purpose: Makes accumulation inspectable.
- Failure if removed: A montage of close-ups hides whether parts coexist.

### inv-03

- Rule: Use local contact proof for fine calibration only after the primary structure is complete.
- Purpose: Separates structural assembly from detail tuning.
- Failure if removed: Early fine detail weakens the state ladder.

### inv-04

- Rule: Complete all small functional or decorative components before testing motion.
- Purpose: Prevents the audition from introducing unexplained changes.
- Failure if removed: Late unseen additions break causality.

### inv-05

- Rule: End with one integrated movement audition and a held complete state.
- Purpose: Proves the assembled system works together.
- Failure if removed: A static beauty pose cannot validate integration.
