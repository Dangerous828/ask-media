````text
# 跨媒介旅伴路线｜地标换章、同步动作与共同终姿

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Read [references/summary.md](references/summary.md) for fit, input slots, and the concise starting example.
2. Read [references/template.md](references/template.md) completely before drafting.
3. Preserve the user's subject and objective, then fill every missing scene, trigger, event-chain, camera, sound, and payoff slot.
4. Treat these anchors as mandatory:

- One clearly adult live-action identity and one clearly adult illustrated identity retain different media signatures throughout.
- Every location change preserves paired travel direction and follows a visible shared transition carrier.
- Alternating foreground occlusion proves shared depth without merging faces, bodies or rendering media.
- The terminal frame reunites both adults, one destination object and one exact original route title in a shared action.

5. Change source-specific people, setting, props, palette, dialogue, shot boundaries, sound family, and payoff surfaces together.
6. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
7. Silently verify anchor coverage, continuity, timing, physical causality, and anti-copy distance before returning the final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define stable subjects once and preserve event order, camera motivation, sound intent, and overall duration.
- Use a simple paragraph for simple concepts or an ordered multi-shot structure for complex concepts.
- State overall duration once; do not copy H3 field labels or per-shot timecode grammar.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism instead of returning a generic portrait or showcase.
- Do not omit, reorder, or weaken a required anchor.
- Do not reuse source people, brands, dialogue, exact storyboard, signature props, exact timings, or recognizable effect surfaces.
````

````text
## 用途

固定一名成年真人和一名成年二维原创旅伴，两者保持不同材质却共享方向、节拍与地标路线；每章由一次同步手势或步态证明同场，最终以共同动作结束而非互相替换。

## 推荐输入格式

`一名明确成年真人原创角色和一名明确成年二维原创旅伴 + 两种材质身份始终分离 + 至少三个由可见载体连接的路线章节 + 每章一次同步动作与一致行进方向 + 至少一次交替前景遮挡证明共享深度 + 终局共同操作同一目的地对象`

> 配对原创真人成年植物调查员和明确二维的成年地图师：真人佩戴红围巾与帆布挎包，动画旅伴为海军蓝短发、黄色外套和墨线阴影。；路线圆盘擦拭切换到峭壁小路、室内市场和盐湖码头；每章都保留两种身份、向右路线和一次同步本地动作。；两人在山顶观测站共同转身、触碰同一投影地图，并肩完成一步，在准确原创标题【TWO MEDIA / ONE ROUTE】下结束。

## 使用方法

1. 保留用户给出的主体与目标。

3. 同时改变人物、环境、道具、风格、声音与结局表面，禁止只换名词。
````

````text
## Invariants

### inv-01

- Rule: One clearly adult live-action identity and one clearly adult illustrated identity retain different media signatures throughout.
- Purpose: Establishes the baseline identity, object or geography that every later state must preserve.
- Failure if removed: Without this exact baseline rule, later changes cannot be attributed to the same subject, object or place, so the sequence loses its reference state. Removed rule: "One clearly adult live-action identity and one clearly adult illustrated identity retain different media signatures throughout."

### inv-02

- Rule: Every location change preserves paired travel direction and follows a visible shared transition carrier.
- Purpose: Makes the visible trigger precede and explain the first mechanism response.
- Failure if removed: Without this exact trigger rule, the response appears spontaneously and the central cause-and-effect claim is no longer demonstrated. Removed rule: "Every location change preserves paired travel direction and follows a visible shared transition carrier."

### inv-03

- Rule: Each chapter contains one synchronized action that proves common timing and local geography.
- Purpose: Keeps the middle progression registered instead of allowing an unexplained reset.
- Failure if removed: Without this exact progression rule, the middle can jump to a replacement state and the accumulated result is no longer traceable. Removed rule: "Each chapter contains one synchronized action that proves common timing and local geography."

### inv-04

- Rule: Alternating foreground occlusion proves shared depth without merging faces, bodies or rendering media.
- Purpose: Reconnects the changed or partial state to the established subject and spatial anchor.
- Failure if removed: Without this exact reconnection rule, detail or transformed shots can belong to a different subject or geography and continuity cannot be verified. Removed rule: "Alternating foreground occlusion proves shared depth without merging faces, bodies or rendering media."

### inv-05

- Rule: The terminal frame reunites both adults, one destination object and one exact original route title in a shared action.
- Purpose: Turns the terminal hold into observable proof that the mechanism completed.
````
