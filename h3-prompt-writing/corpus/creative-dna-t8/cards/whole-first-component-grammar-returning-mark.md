# 成品先现的组件语法｜首秒爆拆、材质章节与符号化复归

Create a new execution from the reusable mechanism, not a surface reskin of any reference video.

## Workflow

1. Preserve the user's subject and objective, then fill every missing scene, trigger, event-chain, camera, sound, and payoff slot.
2. Treat these anchors as mandatory:

- Show the complete original object at frame zero before any parts separate.
- Make the first second the single fastest disassembly and preserve component order.
- Return briefly to the whole between at least two chapters while color and order remain stable.
- Abstract and recombine components into one original mark, not simply the opening object.

3. Change source-specific people, setting, props, palette, dialogue, shot boundaries, sound family, and payoff surfaces together.
4. Compile MiniMax H3 and Seedance 2.0 independently; do not leak one model's field syntax into the other.
5. Silently verify anchor coverage, continuity, timing, physical causality, and anti-copy distance before returning the final prompts.

## MiniMax H3

- Use the current official H3 task grammar and language profile.
- Separate integrated visual action, overall soundscape, and non-diegetic music or explicit silence.
- Use timestamps only to make event order executable; keep shots consecutive and duration-safe.

## Seedance 2.0

- Define stable subjects once and preserve event order, camera motivation, sound intent, and overall duration.
- Use a simple paragraph for simple concepts or an ordered multi-shot structure for complex concepts.
- State overall duration once; do not copy H3 field labels or per-shot timecode grammar.

## Output

Return one concept sentence, the filled slots, an anchor-coverage check, one MiniMax H3 prompt, one Seedance 2.0 prompt, and a short anti-copy validation note.

## Non-Negotiable

- A subject-only request is underspecified. Preserve that subject and complete the mechanism instead of returning a generic portrait or showcase.
- Do not omit, reorder, or weaken a required anchor.
- Do not reuse source people, brands, dialogue, exact storyboard, signature props, exact timings, or recognizable effect surfaces.

# 成品先现的组件语法｜首秒爆拆、材质章节与符号化复归 Template

## Mechanism

Show one complete original constructed object at frame zero and make the first second the fastest, clearest disassembly event. Preserve a fixed component order and assign each major component one visually distinct material or manufacturing grammar in later slower chapters. Reintroduce the complete object briefly between at least two chapters as an assembly-memory anchor. Progressively abstract the same components from objects into dots, bands, rings or outlines while preserving their order and color identity. End by recombining the simplified components into one original identity mark rather than merely returning to the opening product. The reusable mechanism is whole-first hook, maximum-speed disassembly, one grammar per component, intermittent whole-memory, progressive abstraction and mark-level reassembly—not the source burger, ingredients, Japanese copy, palette, patterns, logo, exact motions, creator identity or timing.

## Invariants

### inv-01

- Rule: Show the complete original object at frame zero before any parts separate.
- Purpose: Gives the audience an assembly memory and immediate hook.
- Failure if removed: Starting with fragments delays recognition.

### inv-02

- Rule: Make the first second the single fastest disassembly and preserve component order.
- Purpose: Concentrates attention while keeping the system legible.
- Failure if removed: Repeated equally fast explosions create noise.

### inv-03

- Rule: Assign each major component one distinct slower material or making grammar.
- Purpose: Turns parts into meaningful chapters rather than debris.
- Failure if removed: Reusing one motion for every part flattens identity.

### inv-04

- Rule: Return briefly to the whole between at least two chapters while color and order remain stable.
- Purpose: Refreshes the memory map across abstraction.
- Failure if removed: Without returns, later graphic parts lose their object relation.

### inv-05

- Rule: Abstract and recombine components into one original mark, not simply the opening object.
- Purpose: Converts demonstration into brand-level closure.
- Failure if removed: A literal loop adds no final conceptual gain.

| Slot | Constraint |

| performance_rule | A restrained acting or motion rule that keeps the mechanism legible. |
| camera_grammar | An information order that proves each state without copying source shot boundaries. |
| payoff | A clean final physical, informational or social consequence. |
| sound_family | An original hierarchy of diegetic cues; no unsupported source-audio claim. |

## Required Human-Facing Anchors

- Show the complete original object at frame zero before any parts separate.

- the source cream, red, yellow, green and black palette, dots, stripes, rings and patterns
- the source explosion, pouring, dripping, ingredient chapters, camera sequence and 15-second timing
- the source creator identity, MiniMax H3 claim and quoted prompt fragment
