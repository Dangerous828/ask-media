# 界面角色触发扰动｜生理动作、图标失序与恢复

## 用途

先建立角色与原创界面的稳定关系，一次明确生理动作触发图标和窗口失序；角色主动追踪并回收关键元素，最终回到可辨工作状态。

## 推荐输入格式

`界面角色＋单次触发＋封闭图标组＋主动恢复`

## 可直接改写的简短示例

> 成年纸片技师、中性工作台界面、六个几何工具图标、一次喷嚏。

## 必须保留的结构锚点

- 先建立稳定界面
- 一次触发导致全部偏移
- 同一角色恢复并保留轻微痕迹

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。

- 原帖：https://x.com/Mayz1169/status/2102030213513461970
