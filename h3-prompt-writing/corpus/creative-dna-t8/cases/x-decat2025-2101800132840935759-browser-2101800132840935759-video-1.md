# 双载具间距｜同轴移动与安全错位

## 用途

两种载具保持同一行进轴线，以高度与距离变化形成无碰撞张力。

## 推荐输入格式

`两种载具＋共同方向＋间距变化＋安全收束`

## 可直接改写的简短示例

> 封闭测试山谷，只有一辆原创蓝色缆车和一艘小型琥珀色维护飞艇；两者都朝同一上站移动，山坡、索道和上站位置固定。

## 必须保留的结构锚点

- 共同运动轴明确
- 相对高度和间距可读
- 不发生穿模或碰撞

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
