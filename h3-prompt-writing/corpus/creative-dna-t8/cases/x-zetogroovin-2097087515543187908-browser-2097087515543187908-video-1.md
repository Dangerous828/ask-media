# 副词角色卡接力｜一词一人物、一动作一图形世界

## 用途

五个准确短词各绑定一个不同成年动漫角色、主色和动作语气；字形既是标题也是构图结构，章节间用字母形状或光带擦屏，最终五名角色与五个词在同一版式汇合。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 把准确单词【PRECISELY】与一名原创成年制图师绑定在黑白线框网格中。；把【WILDLY】与一名成年鼓手绑定在青洋红撕纸爆发中，并安排一次有力转头。；让五名成年人在准确标题【FIVE MODES】下汇合，每个单词仍与对应人物和颜色相邻。

## 必须保留的结构锚点

- Exactly five short words map one-to-one to five clearly adult characters.
- Each chapter uses a distinct palette, pose and graphic grammar.
- Transitions reuse letter shapes or graphic motifs rather than random cuts.
- The final board preserves all five mappings simultaneously.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。

## 来源
