# 材质到使用｜产品关联与实证回归

## 用途

同一产品在材料、实际使用和回归镜头之间建立可检查的联系。

## 推荐输入格式

`原创产品＋两种材料线索＋使用动作＋结果回归`

## 可直接改写的简短示例

> 同一无品牌不锈钢冷饮瓶，浅绿色硅胶密封圈，一名明确成年的徒步者、深色帆布包和一条短林径；不得改动瓶身形状或角色身份。

## 必须保留的结构锚点

- 产品身份连续
- 材质与使用有可见关系
- 不把暗示写成未经验证的功效

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。

## 来源

- 作者：@Aiwithmaha
- 原帖：https://x.com/Aiwithmaha/status/2101887507059351894
