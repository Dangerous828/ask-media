# 一人变群像｜合影后近景反应

## 用途

一人与独立观察者先建立关系，再出现可数的新群体，合影后用面部反应收束。

## 推荐输入格式

`原始人物＋独立摄影者＋逐渐成群＋近景反应`

## 可直接改写的简短示例

> 蓝实验外套成年讲解员、橙夹克成年摄影者、空白展墙、数码相机。

## 必须保留的结构锚点

- 人数从一清楚增加
- 摄影者保持独立
- 结尾反应不臆造原因

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
