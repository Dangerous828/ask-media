# 不可逆烹饪状态链｜食材、工具、锅体、成品与品尝连续证明

## 用途

同一明确成年厨师、厨房、主食材与关键工具持续锁定，每镜只推动一次不可逆食品状态变化，并让上一状态残留成为下一步原料；用颜色、容器和手部锚点防止食材跳变。成品装盘后必须由同一人物完成一次克制品尝。

## 推荐输入格式

`一名明确成年原创操作者、固定空间、主材料组、主要容器与手部或工具锚点先建立 + 至少五个不可逆状态且每镜只执行一次清楚操作 + 上一状态的残留、形状、颜色、蒸汽或容器连续成为下一步输入 + 不得回到已消失的早期状态并保持数量合理 + 同一成品由同一成年人完成一次克制使用或品尝证明`

## 可直接改写的简短示例

> 原创陶瓷工作室内，一名明确成年釉料师、钴蓝围裙、铜色戒指、标记矿物粉、一只黑研钵和一块白测试砖稳定同框。；向残留粉末加入一次定量透明液体，搅成连续灰蓝釉液，再把同一混合物通过小筛进入标记杯；不得重置为干粉。；烧成砖回到原工作台，同一成年人把它在灯下倾斜一次，再用戴手套的手沿完整边缘摸过；成品材料证明稳定收束，不复制厨师、意面、食材和配方。

## 必须保留的结构锚点

- Lock one clearly adult original cook, kitchen, ingredient set, primary vessel and hand or tool anchors.
- Perform exactly one irreversible operation per beat and preserve visible residue into the next.
- Keep food color, quantity and container transitions plausible through cooking and plating.
- End with the same plated serving and one restrained taste by the same adult.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
