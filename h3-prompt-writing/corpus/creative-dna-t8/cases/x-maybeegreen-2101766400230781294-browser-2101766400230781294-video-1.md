# 巨构近触｜尺度远景与微动作回望

## 用途

巨型场景先把旅行者缩小，再靠近一个可读微动作，最后回原远景。

## 推荐输入格式

`巨构＋旅行者＋近接微动作＋原位远景`

## 可直接改写的简短示例

> 一名成年文物修复师、一座巨大的青铜水钟大厅、从开头已亮的少量校准灯和一个待检查的固定齿轮盒。

## 必须保留的结构锚点

- 远景建立大小对比
- 微动作位置可追踪
- 回远景维持同一地理

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
