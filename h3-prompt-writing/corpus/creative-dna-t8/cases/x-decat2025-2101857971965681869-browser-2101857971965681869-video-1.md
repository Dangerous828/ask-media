# 中心触发｜径向环境变形与余波

## 用途

中心动作依次触发外扩边界和场景几何变化，最终保留原点与余波。

## 推荐输入格式

`中心主体＋单次触发＋径向扩张＋空间余波`

## 可直接改写的简短示例

> 同一座原创温室、一个成年维护工程师和多个无品牌小车；工程师站在有支撑的中央平台，按钮固定在平台上；小车在启动前停到不下降的外侧安全平台。

## 必须保留的结构锚点

- 中心主体锚定
- 传播先于几何变化
- 终态仍可追溯原空间

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
