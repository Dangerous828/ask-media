# 植物香水材质接力｜露珠、花叶、喷洒与瓶身回归

## 用途

用同一成年调香师和原创香水瓶连接温室、叶片露珠、花朵、雾气与一次喷洒；相同金绿高光贯穿材质镜头，最终回到瓶身与人物共同英雄状态。

## 推荐输入格式

`一个原创产品与固定背景、尺度和构图参照 + 至少两种可清楚区分且可逆切换的表面状态 + 每次状态切换都回到同一主体位置 + 一次能证明真实材质细节的微距检查 + 终局返回完整产品英雄画面并锁定指定表面状态`

## 可直接改写的简短示例

> 让一名明确成年的原创调香师和一只切面瓶出现在晨光温室。；把坠落露珠匹配到一滴透明液体进入同一切面瓶。；形成一个克制金色花瓣舞台，让准确原创名称【VERDANT NOTE】与瓶身、调香师同框。

## 必须保留的结构锚点

- One clearly adult model and one original bottle persist.
- Macro materials share one controlled highlight family.
- Exactly one spray action occurs.
- Source brand names, labels, identity and watermark are excluded.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。
