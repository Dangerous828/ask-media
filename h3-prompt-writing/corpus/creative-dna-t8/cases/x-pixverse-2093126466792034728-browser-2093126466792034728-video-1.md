# 拟音字武侠接力｜动作承诺、语义撞击与三章升级

## 用途

用同一高对比视觉语法串联三个独立动作章节；每章先给短标题承诺，再让人物、道具和拟音字在同一方向发生碰撞，最后以更大尺度运动兑现升级。

## 推荐输入格式

`Establish one clearly adult original subject, three identity anchors and one continuous world axis. + Bind each decisive action to exactly one short original semantic word that appears only after the action begins. + Make each word occupy, divide, reflect or redirect the physical environment rather than float as a subtitle. + Escalate typography scale and spatial depth while preserving identity, travel direction and readable action. + Return to the same adult face or full-body anchor and resolve the word sequence into one terminal identity proof.`

## 可直接改写的简短示例

> 象牙黑原创字场先显示准确章节标题【HOLD THE LINE】，成年桥梁巡检员携折叠测量杆入场。；切换准确标题【THROUGH THE FOG】，同一人物点亮信号灯并穿过斜向银雾。；路线与雾汇成一个原创终局标记，人物抵达桥端并停留。

## 必须保留的结构锚点

- Each chapter begins with one readable short title.
- One physical action drives one matching graphic stroke.
- Motion scale grows from hand tool to environment route.
- The final mark and completed action hold together.

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。

## 来源
