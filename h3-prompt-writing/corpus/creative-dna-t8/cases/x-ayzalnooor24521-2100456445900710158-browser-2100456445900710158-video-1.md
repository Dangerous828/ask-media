# 橱窗造型接管｜凝视触发、服装转移与街头结果证明

## 用途

先让成年行人与橱窗成衣建立清楚对应，一次凝视或手势触发服装沿可见载体转移；转变完成后以连续街头行走和日常动作证明新造型稳定。

## 推荐输入格式

`成年行人＋橱窗服装＋可见转移载体＋街头结果证明`

## 可直接改写的简短示例

> 成年建筑师、橱窗钴蓝外套、三条光带、路口行走和一次喝水。

## 必须保留的结构锚点

- 橱窗服装先清楚出现
- 只有衣物发生改变
- 转变后日常动作证明造型稳定

## 使用方法

1. 保留用户给出的主体与目标。
2. 按推荐输入格式补齐场景、事件链、镜头职责和结果。
3. 同时改变表面名词、风格、光影、声效与物理实现，不做来源视频换名词复刻。
4. 分别编译 MiniMax H3 与 Seedance 2.0，并逐项核对结构锚点。

## 来源

- 作者：@ayzalnooor24521
- 原帖：https://x.com/ayzalnooor24521/status/2100456445900710158
