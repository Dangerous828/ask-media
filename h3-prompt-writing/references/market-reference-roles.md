# 参考职责与入口核对

混合参考职责不清，或准备使用视频、音频、首帧等输入时读取。六段名称与顺序继续使用[主技能的 Full-Reference Mode](../SKILL.md#full-reference-mode)和[正式 Ref2VA 指南](ref-en.txt)，本文只补素材职责与可执行边界。

## 先核对入口，再绑定素材

1. 对照当前入口的实际模式、素材类型与组合限制，确认哪些素材能真实提交。模型文档支持视频、音频或混合输入，不证明当前本地工具、adapter或节点已经接入这些能力；字段可填写也不证明链路效果已验证。
2. 对每份实际可用素材，只绑定它确实满足且项目需要的职责；部分满足就限定维度，缺失信息如实记为未知。需要改变已接受模式、删去必要参考或补生产时，由对应 owner 处理真实分叉，不能在正文中假装素材已提供。
3. 按实际输入顺序保持标签一致，在既有六段中表达保留维度及发生位置；已确认的英文正文、对白原文与项目生成策略继续沿用。

## 职责分开，不互相代替

| 职责 | 可由实际素材提供的内容 | 核对边界 |
|---|---|---|
| 身份 | 人物脸型、发型、体型、服装或物体结构 | 参考的站姿、表情、持物与背景只在项目明确需要时迁移 |
| 风格／空间 | 媒介、材质、光向，或可见环境地理 | 风格图不自动贡献人物身份；未展示的空间不冒充已知布局 |
| 动作／摄影 | 视频中可观察的动作阶段、运镜与交接 | 仅在视频确实作为获准输入且入口支持时绑定；文字分析不冒充视频输入 |
| 时间 | 事件顺序、停顿、切点、显示或对白窗口 | 分清素材中的观察事实与项目另行确认的时序；不由参考图姿态推定完整运动 |
| 声音 | 音色、节奏、情绪、对白内容，或完整／局部音轨复用 | 说明实际采用哪个维度；带音轨不证明已核听，画面替换不自动授权换声 |

普通图片参考只提供声明的维度，不是像素级精确首帧。只有项目已明确选择相应关键帧模式、入口支持且实际传入时，才按首帧或尾帧约束描述；保持现有参考策略，不因混合参考而自动改模式。

完成检查：每个标签对应真实可提交的素材，每份素材的职责与可见／可听证据相符；模型能力、入口可调用性和本项目效果验证分别记录。
