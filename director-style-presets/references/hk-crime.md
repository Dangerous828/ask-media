# 港式警匪（霓虹手持）

类型：镜头语言（分镜层）。适用：都市犯罪、商战。只用于生图/分镜，禁止注入 H3 视频提示词。

## 写法

- **机位**：追逐/跟踪用肩扛跟拍 + 长焦压缩；对峙用广角近距仰拍制造压迫（仰拍须有权力动机）。
- **光线**：夜景可用青/品红霓虹对撞；仅在剧本明确有雨时用湿地反光；室内按既定场景光源设计阴影。
- **节奏**：对话正反打随冲突逐步加快；具体秒数服从分镜时长契约；有动作依据时才用手持特写或甩镜。
- **色调**：高对比、低照度，肤色偏青。
- **提示词**：写明当前场景已有光源方向与反射面。

## 边界

- 不为制造风格增添雨水、霓虹设施或新光源。
- 材质与表现媒介沿用项目画风；既有身份、服装配色、场景与光源事实优先。
- 肩扛/甩镜是“不稳定”的运镜，不要映射成斯坦尼康（稳定器，语义相反）。短剧项目按 short-drama-storyboard 的运镜写法直接写“手持跟拍、有意的不稳”；独立短片用 storyboard-30s 时，词库没有对应词就在画面内容栏说明。
