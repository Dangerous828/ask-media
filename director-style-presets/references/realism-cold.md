# 写实冷峻（现实题材）

类型：镜头语言（分镜层）。适用：现实题材短剧。只用于生图/分镜，禁止注入 H3 视频提示词。

## 写法

- **机位**：手持为主，允许轻微晃动；对话中景正反打，不做花哨运镜；关键情绪给固定长特写（2–3 秒不切）。
- **光线**：自然光逻辑，室内只用实用光源（台灯、窗光）；夜景压暗，只保面部可辨识。
- **节奏**：冲突升级可加快切换；慢动作与闪回须有剧情依据；镜长服从分镜与模型约束。
- **色调**：低饱和冷色，肤色真实，不用浓滤镜感。
- **表演**：动作具体（"指节发白""避开视线"），不写情绪形容词。

## 边界

- "写实"指克制观察与自然光逻辑，不改变媒介：3D 动画或水墨项目不因此改成真人照片。
- 无情绪或动作依据时保持固定镜头，不为方法本身增加晃动。
- 取景与光色偏好服从当前场景事实。
