# 浓色仪式感

类型：镜头语言（分镜 / 关键帧构图）。适用：视觉冲击优先、仪式性场面。只用于生图/分镜，禁止注入 H3 视频提示词。

## 写法

- **构图**：对称与几何分割优先；人群/器物排布成图案；大远景环境压人。
- **色彩**：从已有服装、道具与场景配色中选取本场主色，通过取景与光线关系强化；不改写资产配色。
- **机位**：静止大画框内让人物走进走出；升降与环绕用于仪式性场面（如婚丧、登基）。
- **节奏**：仪式性场面可延长停留，秒数服从分镜；特写优先给信物与面部高光时刻。
- **提示词**：写明主色与环境色的关系（原卡例："红嫁衣压靛蓝帐"，例子不属于本项目事实）。

## 边界

- 只在当前剧情与资产允许时采用；材质与表现媒介沿用项目画风。
- 竖屏大远景的主体占比按景别区分：远景环境镜人物全身约 1/5 画高并配前景参照物；近景/特写主体占画面
  60%–70%，防腰斩压扁（起点，非门槛）。
