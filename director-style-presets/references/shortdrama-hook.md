# 短剧爽点节奏（剧本节奏）

类型：剧本节奏（剧本/分集层）。适用：红果系短剧，或创作者点名要爽点节奏时。与画风无关；不进任何提示词正文。

修正说明：Slate 原卡 description 写"单集 1-2 分钟、每 30 秒小冲突"，正文写"服从项目制作规格"，二者矛盾。本预设以**服从项目规格**为准，不设固定时长与冲突间隔。

## 写法

- 单集时长、字数、分镜数量服从项目制作规格与当前分集卡（md 线的节奏数值见 `short-drama` 的 `rhythm_profile`，仅在已接受时核对）。
- 按集长安排可见的小冲突或反转；有铺垫时设置身份揭晓、处境逆转等情绪落点，不机械按秒数堆叠。
- 集尾钩子必须视觉化（人物出现、物件揭晓、倒计时开始），不用台词说破。
- 台词以人物性格与对白密度为准，关键反应可用短句；长独白只在剧情确需时保留。

## 边界

- 爽点镜的表演节拍按 `acting-beats-dual-track` 的"准备 → 反应 → 落点"写。
- 交给 `short-drama-develop` 或 `short-drama-write` 执行。
