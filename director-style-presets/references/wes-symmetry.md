# 横平竖直（中心对称）

类型：镜头语言（分镜 / 关键帧构图）。适用：轻喜剧、童话感。只用于生图/分镜，禁止注入 H3 视频提示词。

## 写法

- **构图**：严格中心对称，相机垂直于墙面；人物正对或 90° 侧对镜头，不用 45°。
- **调度**：横向走位（画面左右进出），像人偶被摆动；快速变焦推（snap zoom）做喜剧重音（两套分镜词库都没有这个词，在画面内容栏写明“快速变焦推近”）。
- **色彩**：高饱和糖果色 + 奶油质感，陈设对称摆放（仅在现有陈设允许时）。
- **节奏**：镜间硬切，干净利落。
- **提示词**：写明"居中对称构图"与主色。

## 边界

- 对称构图仅在现有空间和动作允许时采用，不移动既定门窗家具、不改人物姿态事实。
- 章节文字如需只在后期制作，生图关键帧不画字幕卡。
- 色彩与材质服从资产与项目画风。
