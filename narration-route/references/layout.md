# 画面文字排版规则

本文件解决竖屏旁白艺术字的实际排版问题。规则来自逐版实测（含 6 次返工），不是理论推导。

## 1. 可用空间（9:16 竖屏）

以 768×1344 为基准，换算到 1080×1920 乘 1.406：

| 区域 | 768×1344 | 用途 |
|---|---|---|
| 顶部安全区 | y 0–70 | 平台 UI，不放字 |
| 上部留白 | y 70–400 | 横排首选（常是墙面/天花板） |
| 中部主体 | y 400–950 | 人物在此，**避开** |
| 下部留白 | y 950–1180 | 竖排可用（桌面/地面） |
| 底部安全区 | y 1180–1344 | 平台 UI + 对白字幕，**不放旁白** |

**先判定主体位置再定字位**：逐镜抽帧找最大留白区，不要全片套同一位置。

## 2. 竖排

**列内字数上限**（决定会不会出画）：

```
每列字数 = (画面高 - 上下留白 240) / 行距
行距 ≈ 字号 × 1.16
```

- 字号 70px → 每列最多约 13 字
- 字号 54px → 每列最多约 17 字
- 字号 46px → 每列最多约 20 字

**超了就分列或拆段，不要硬排。** 出画的典型症状：底部字被切掉一半、字压到平台 UI。

**分列规则**：
- 按标点切语义段（`，。！？`），逐段灌列，尽量不拆词
- 列间距 ≈ 字号 × 0.20
- 整体按最长列**垂直居中**，不要在固定 y 起排（这是最容易出画的原因）
- 右对齐模式：列从右往左排，末列距右边缘留 78px

## 3. 横排

**行宽上限**：画面宽 - 120（左右各留 60）

- 字号 52px → 每行约 12 字
- 字号 46px → 每行约 14 字

**行数**：通常 2 行；超过 3 行改竖排或拆段。
**起始 y**：70–120（避开顶部安全区）。

## 4. 艺术字样式（实测可用组合）

| 项 | 值 | 说明 |
|---|---|---|
| 字体 | Songti SC Black（`/System/Library/Fonts/Songti.ttc` index 0） | 宋体粗黑，有书法感，macOS 自带 |
| 主色 | 暖白 #FFFAEB | 比纯白柔和，不刺眼 |
| 光晕 | 暖黄 #FFE196，高斯模糊 11px，不透明度 0.58 | 让字从背景里浮出来 |
| 描边 | 深墨 #19140F，MaxFilter 9，不透明度 0.88 | 深色背景下保可读 |
| 抖动 | 逐字 ±1px 随机偏移 | 手写批注感，避免机械排版 |
| 淡入 | 0.5s | |
| 淡出 | 0.6s | |

**抖动的坑**：随机种子必须固定，否则逐帧重算会让文字"跳动"。在预渲染 stage 一次性生成抖动，不要每帧重新 random。

## 5. 与对白字幕的关系

旁白文字与底部对白字幕是**两套视觉语言**，必须能一眼区分：

| | 旁白艺术字 | 对白字幕 |
|---|---|---|
| 位置 | 画面留白处漂浮 | 底部固定安全区 |
| 字形 | 竖排/横排 + 光晕 + 描边 + 抖动 | 横排单行 + 细描边 |
| 颜色 | 暖白 | 纯白（内心 VO 浅青） |
| 字号 | 46–70px 可变 | 固定（画面高 4.3%） |

**若创作者不要底部对白字幕**，旁白文字就是画面里唯一的字，位置可以更自由，但仍要避开主体。

## 6. 逐镜定位置（实操流程）

1. 每镜抽首/中/尾三帧
2. 标出人物头部、手部、关键道具的位置
3. 在剩余空间里找最大连续矩形
4. 判定该区适合竖排（高瘦）还是横排（扁宽）
5. 按 §2/§3 算字数上限，超了就拆段
6. 叠上去抽帧看，不满意再调

**不要跳过第 6 步。** 6 次返工都是因为只看代码算的坐标，没看实际叠上去的效果。

## 7. 常见错误

| 错误 | 症状 | 修法 |
|---|---|---|
| 固定 y 起排 | 长文案底部被切 | 按最长列垂直居中 |
| 单列硬塞长文案 | 竖排出画、字成一条长虫 | 分 2–3 列或拆成两段时间 |
| 抖动种子不固定 | 文字逐帧跳动 | 预渲染阶段一次性生成 |
| 全片套同一位置 | 有的镜压在脸上 | 逐镜定位置 |
| 字号太小 | 手机上看不清 | 不低于 40px；先试拆段 |
| 与字幕撞位 | 两行字重叠 | 旁白避开 y>1180 |
