# 旁白视角判别

**本文件解决一个最常见的失败：把"旁白"写成了"台词"。**

## 1. 三种身份，先选一个，全文不混

| 身份 | 人称 | 谁在说 | 能说 | 不能说 |
|---|---|---|---|---|
| **第三人称说书人** | 他 / 这个男孩 / 在场的人 | 故事外的局外人 | 外部可见事实、量级反差、对行为的评价 | 角色心里想什么 |
| **第一人称回忆** | 我 / 小时候的我 | 长大后的本人回看 | 当年的事实 + 现在的评价（"那时我不懂"） | 当年不可能知道的信息 |
| **角色内心独白** | 我（当下） | 剧中人此刻心声 | 只有角色知道的判断 | —— **这不是旁白，是台词** |

**创作者说"加旁白"，通常指前两种。** 若写成第三种，就退回剧本层，不进旁白。

## 2. 复述识别（最重要的一条红线）

**旁白不得复述画面或台词已经给出的信息。** 逐句自查：

| 台词/画面已经有的 | 写成旁白就是错的 | 正确的方向 |
|---|---|---|
| 角色说"这里只有两个账号" | 「他看见只有两个账号」 | 补量级：「全中国有上亿个QQ号，他盯着其中的两个」 |
| 角色皱眉思考（画面） | 「他开始思考」 | 补评价：「他没有问，也没有查，他开始了推理」 |
| 两人一脸懵（画面） | 「他们很困惑」 | 补结果：「他们努力理解这句话，失败了」 |
| 角色脸红（画面） | 「他很尴尬」 | 补落差：「从规则制定者到全校最傻的，只隔一个词」 |

**判定方法**：把旁白句子遮住，只看画面和台词，如果观众已经能得到这条信息 → 这句是重述，删掉或改写成新信息。

## 3. 第三人称的具体写法

第三人称旁白不下场，只陈述。用词的差别决定了成败：

| 弱（滑向内心） | 强（保持局外） |
|---|---|
| 他觉得这很简单 | 在他看来，这很简单 |
| 他以为全世界只有两个号 | 全世界有多少个号，他没查过 |
| 他们不懂 | 他们没有一个人问出口 |
| 他明白了 | 那个下午，他终于弄清楚了那串数字是什么 |

**核心技巧：把"内心判断"换成"外部事实"或"缺席的动作"。** 不写他想了什么，写他没做什么、实际发生了什么。

## 4. 第一人称回忆的纪律

- 只用**当年可观察的事实** + **现在的评价**，两者要能分清。
- "小时候的我一直不明白" —— 当年的状态，合法
- "后来我才知道，那时候全中国有上亿个号" —— 现在的补充，合法
- "我当时就预感到要出事" —— 违纪，当年不可能知道，且是给自己贴金

## 5. 视角混用的典型坏例

```
✗ 小时候的我一直不明白为什么只能选两个，他觉得这其中必有玄机。
   └─ 前半第一人称回忆，后半突然第三人称"他觉得" — 人称断裂

✓ 小时候的我一直不明白，为什么这里是个选择，而且只能选这两个。
   └─ 全程第一人称回忆，只陈述当年的困惑状态

✓ 那个八岁的男孩盯着屏幕上的两行数字，没有问为什么。
   └─ 全程第三人称，只写外部可见的"没问"这个动作
```

## 6. 时间语态

| 旁白位置 | 推荐语态 | 例 |
|---|---|---|
| 事件发生时 | 现在时或简单过去 | 「他按下左键。」 |
| 事后回看 | 过去时 + 现在评价 | 「那时我不懂，那只是登录记录。」 |
| 全片收束 | 现在完成或一般现在 | 「从那天起，我才知道QQ号是自己的。」 |

同一部片子里不要三种语态乱跳；选定一种主导语态，其余只在明确的时间跳跃处切。

## 7. 一句话自检

写完每句，问三个问题：

1. **谁在说这句？** 能明确指出身份吗
2. **这句里的信息，画面或台词给得出吗？** 给得出 → 重述，删
3. **这句有"他以为/他觉得/他心里"这类词吗？** 有 → 滑向内心了，改成外部事实
