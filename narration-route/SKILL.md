# narration-route · 旁白 / 解说路由

一句话：**旁白不是默认音轨。先判定它该不该存在、以什么身份说话、落在哪一层，再分派。**

本技能只做三件事：**判定（该不该/什么视角）→ 选形式（配音/文字/两者）→ 分派（去哪个技能执行）**。
它不写解说稿正文、不生成 TTS 音频、不做剪辑与叠层渲染。

## 目标

**解决什么问题**：短剧成片常常"画面看懂了，但笑点/荒谬/悲感没被点破"。创作者会要求"加个旁白"，
但直接开工最常见的两种失败是：

1. **写成台词**——把角色内心独白当旁白，观众得不到任何新信息（本技能 `perspective.md` 的红线）；
2. **形式选错**——该用文字点题却配了音轨，或该配音却塞进画面挤爆排版。

**产出什么**：一份可执行的旁白方案（判定结论 + 视角 + 落地形式 + 分派目标），以及给执行层的
结构化输入（`narration.json` 或叠层配置）。**不产出旁白稿正文本身。**

**成功判据**：`narration_job` 明确（取六类之一，含 `none`；取 `none` 时须有书面理由说明画面/原声/沉默已足够），视角全程单一、无复述、时间窗核算过、落地形式由创作者选定（取 `none` 时落地形式不适用）。

## 调用契约

### 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 成片或镜头素材 | 是 | 要加旁白的视频（已剪辑成片，或逐镜素材） |
| 创作者要求 | 是 | "加个旁白"这句话本身；有具体诉求时记录原话 |
| 剧本 / 分镜 | 推荐 | 用于判 `narration_job` 与避让台词发声窗口；缺省时按画面判断并在报告注明 |
| 落地形式 | 否 | 创作者已指定则直接用；未指定必须问，不替他选 |

### 输出

| 产物 | 内容 | 交给谁 |
|---|---|---|
| 旁白方案 | `narration_job` + 视角 + 每块时间窗 + 落地形式 + 每块字数核算 | 创作者确认 |
| `narration.json` | `start`/`end`/`narration`/`pause_after_ms`/`overlaps_speech`/`emotion` | 短剧项目：`short-drama-produce` 的 `tts` 模态（预览→确认→运行），音色取 `short-drama-assets` 的声音方向；非短剧项目可用外部 `video-recap-skills/video-voiceover`（本机未安装，需先安装） |
| 叠层配置 JSON | `text`/`start`/`end`/`mode`/`fsize` | `scripts/overlay_text.py`（文字路线） |

### 不做什么

- 不写解说稿正文（方法论与写稿归 `video-recap-skills/video-script`，本技能只给判定与约束）
- 不生成 TTS 音频（短剧项目归 `short-drama-produce` 的 `tts` 模态；其他项目可用外部 `video-recap-skills/video-voiceover`，本机未安装）
- 不做剪辑、不改剪辑单（归 `short-drama-edit`）
- 不改剧本、台词、故事事实（归 `short-drama-write`）

## 执行流程

### 第一步：判定该不该加（先过这一关）

按 `references/writing-rules.md` 的 **audio_owner / narration_job** 判定：

1. **画面 + 原声 + 沉默是否已经足够？** 够就写 `narration_job: none`，不要加。硬加旁白是常见过度设计。
2. **旁白补的是哪一类？** 只能是六类之一：`context`（背景）/ `causal_link`（因果）/ `foreshadow`（伏笔）/ `interpretation`（解释）/ `transition`（过渡）/ `none`。
3. **这条信息画面和台词给得出吗？** 给得出就是重述，退回。见 `references/perspective.md` §"复述识别"。

### 第二步：定视角

读 `references/perspective.md`，分清三种身份：

| 身份 | 谁在说 | 能说什么 | 典型错用 |
|---|---|---|---|
| **第三人称说书人** | 故事外的局外人 | 外部可见事实、量级反差、对行为评价 | 写"他以为"、"他觉得" → 滑向内心 |
| **第一人称回忆** | 长大后的自己回看 | "小时候的我…"、"那年…" | 混入当年不可能知道的信息 |
| **角色内心独白** | 剧中人当下心声 | 只有角色知道的判断 | **这不是旁白，是台词** |

定格一种，全文不混。创作者说"旁白"通常指前两种。

### 第三步：选落地形式（必须问创作者）

读 `references/placement.md`：

| 形式 | 何时选 | 代价 |
|---|---|---|
| TTS 配音 | 要"听得到"的解说、有足够时间窗 | 占时间窗、要调语速、要混音、要授权外发 |
| 画面文字 | 只要"看得到"的点题、不想动音轨 | 占画面空间、长文案排版难 |
| 两者并用 | 关键句双重强化 | 成本最高、时间轴必须严格对齐 |

**默认倾向**：短句点题（≤12 字）→ 文字；长句有语气转折 → 配音；创作者没说 → 先问。

### 第四步：时间窗核算

按 `references/writing-rules.md` §4 的核算表：

- 中文播音腔约 **4.2–4.6 字/秒**，每块加约 **0.45 秒** TTS 首尾静音
- 2s 窗口 ≈ 6–7 字，4s ≈ 14–16 字，6s ≈ 23–25 字
- **装不下就删字或拆分叙事任务，禁止靠放慢画面硬塞**

### 第五步：分派

| 要做的事 | 去哪 |
|---|---|
| 写解说稿正文 | 外部技能 `video-recap-skills/video-script` §4.4–§5.2；本技能 `references/writing-rules.md` 转载了核心 9 条 |
| TTS 合成音频 | 短剧项目：`short-drama-produce`（`tts` 模态，经本次确认；声音身份归 `short-drama-assets`）。非短剧：外部 `video-recap-skills/video-voiceover`（本机未安装）；渠道资料见 `references/tts-channels.md` |
| 画面文字叠层（短剧素材） | 走剪辑单的 `画面文字` 行，由 `short-drama-edit render`（Remotion）一次渲染进成片，并回填剪辑单；本技能的 `overlay_text.py` 不用于短剧成片（在成片上二次叠字会产出剪辑单之外的新成片） |
| 画面文字叠层（非短剧素材） | 本技能 `scripts/overlay_text.py`；排版见 `references/layout.md` |
| 并进成片 | `short-drama-edit` 的 `配音` 行（配音）或外部叠层（非短剧文字），并回填剪辑单 |

### 第六步：交付前抽帧核对

- **非短剧素材**：文字路线用 `overlay_text.py --preview <秒>` 定点导出单帧看位置，**不要整片重渲染后才发现出画**。
- **短剧素材**：画面文字由 `short-drama-edit render` 渲染进成片，抽帧核对在该链路里做（读交付成片的代表帧确认不压主体、不出画、不与底部字幕撞位）；不要再用 `overlay_text.py` 在成片上二次叠字。

## 安全与权限边界

### 可自动执行（无副作用）

- 读取成片、逐镜素材、剧本、分镜，测量时长与运动
- 计算时间窗与字数核算
- 生成 `narration.json` 骨架与叠层配置
- `overlay_text.py --preview` 出单帧预览（写临时文件，不覆盖成片）

### 必须创作者确认

| 动作 | 为什么要确认 |
|---|---|
| **采用旁白**（`narration_job` 非 none） | 旁白不是默认音轨；画面已足够时加了就是过度设计 |
| **落地形式** | 配音还是文字，成本与观感差异大，不能替选 |
| **TTS 外发** | 云端 TTS（MiMo / Fish）会把旁白文本发到外部；`--voice-ref` 还会外发参考音频 |
| **音色克隆** | 只在创作者有权使用该音频、且声音主人同意时使用 |
| **覆盖成片** | `overlay_text.py` 输出到新路径，不覆盖原成片 |

### 红线

- 不改剧本、台词、故事事实、角色关系、结局（要改回 `short-drama-write`）
- 不把技术成功当质量结论（叠上了、出声了、时长对上了，都不等于这条旁白有效）
- 不重复实现已有能力（写稿引用 `video-recap-skills`；短剧 TTS 走 `short-drama-produce`）

## 自检

交付前逐条核对：

- [ ] `narration_job` 明确（含 `none`）；若取 `none`，有书面理由（画面/原声/沉默已足够），未硬加旁白
- [ ] 视角单一，全文同一个人称，没混第三人称与角色内心（`none` 时不适用）
- [ ] 没有复述画面或台词已给出的信息（逐句对照 `perspective.md` 复述识别表）
- [ ] 每块字数按 4.2–4.6 字/秒核算过，含 0.45 秒静音余量（`none` 时不适用）
- [ ] 落地形式由创作者选定，不是代理自作主张（`none` 时不适用）
- [ ] 画面文字：非短剧走 `overlay_text.py --preview`、短剧走 `short-drama-edit render` 链路，抽帧确认过不压主体、不出画、不与底部字幕撞位
- [ ] 若用 TTS：音色与语速已试听，创作者知道文本会外发
- [ ] 分派目标写清楚（谁写稿、谁合成、谁并进成片）
