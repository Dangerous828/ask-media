# 工作思路：从剧本建白模 / 拉片 vs 逐帧复刻；技术路线

## 三条路线

- **从剧本建白模（准备阶段）**：人物形象未定，先把剧本的空间、走位、机位、轴线、景别、节奏落成可播放预演。
  产物用来写场记账（`设定集/场记.md`），不作生成参考图。见下节「从剧本建白模」。
- 拉片 Breakdown：理解镜头语言、拍新片。产出镜头级信息（景别/运镜/台词/动作），不需原片当背景。
- 逐帧复刻 Rotomation：要和某段原片构图一致。底板即镜头（原片当参考），代理对齐屏幕空间。
  AI 图生视频只需【镜级一致】（切点/时长/景别/前景是谁/轴线），不需帧级 roto。

## 从剧本建白模

适用：对话、室内对峙、围坐等固定机位人物关系镜头；项目还没人物形象，或要先定空间再谈美术。

1. 读剧本目标场次的场景 ID、在场人物、对白、动作与场景时间。
2. 读项目地点资产，把地面、主光源、边界陈设、出入口落成 `set` 与必要道具。没有地点资产时只建剧本写明的内容。
3. 人物写 `A`/`B`/`C` 占位代号，不写姓名与长相；站姿/坐姿、左右关系、谁面向谁按剧本动作定。
4. 按对白与动作拆镜，机位用 `wide`/`near`/`two`/`cu`/`ots` 解析；需要固定高度或特殊取景才写镜头级 `pos`/`look`。
5. 校验 JSON → 渲染 → 与剧本逐场核对 → 把摆出来的机位类型、机位高度、轴线侧、景别抄进场记账。

人物形象定稿之后，把 `actors` 的显示名换成姓名即可；白模本身不因为形象变化而重做，
除非走位或机位被推翻。

## 白模与场记账的对应

| 账 → 白模 | 白模 → 账 |
|---|---|
| 场景空间账（地面/主光源/边界陈设/出入口）→ `set` 与道具 | 「白模引用」行：白模工程、白模镜头 id、白模机位类型、核对状态 |
| 调度卡（站位/朝向/姿态）→ `actors.pos`、`staging`、`pose` | 摆不出来时写「白模缺此镜」并说明卡在哪 |
| 轴线侧与景别 → `cam` 选择；机位高度 → `pos` 的 y 值 | 账与白模不一致时改任一侧，都要写下改了哪边 |

白模镜头 id 与调度卡 id 要能互相对上；重排镜序时两边一起改。

## 技术路线（对白/短剧）
原片 → ①extract_shots.py 接触印片+切点（程序）→ 人工归并镜头
→ ②storyboard JSON（唯一数据源）
→ ③dialogue_engine.py：针孔投影(3D坐标→2D)、画家算法深度排序、
  盒子/球极简代理、机位由站位解析(wide/near/two/cu/ots)、叠加运镜/动作/提示词/【角色】台词，
  并经 ffmpeg 管道直出 H.264/yuv420p/faststart（无需再转码；无 ffmpeg 则报错）
→（可选）每镜首帧+提示词 → AI 图生视频。

从剧本建白模走同一套 ②③，只是跳过 ①：剧本直接给出场次、对白与动作，不需要从原片测量。

## 投影要点
- 相机 pos+lookAt 求 f/r/u；z'=d·f；sx=W/2+(d·r)/z'·focal；sy=H/2-(d·u)/z'·focal；focal=(W/2)/tan(fov/2)。
- 盒子8角投影+背向剔除+按深度排序画多边形；球中心投影、半径 r·focal/z' 画圆。
- 环境极简：地面+必要道具，不建假景。

## 经验/纪律
- 白模只锁机位/走位/轴线/景别/节奏，不做美术；美学交 AI 概念图。
- 白模是人物形象未定时的占位模具：方块就是人，不补长相、发型、服装细节。
- 白模产物不作生成参考图；它只提供能抄成文字的那几项，抄进场记账之后下游读账本。
- 对话用 2D；奇观大场面交 AI，别用白模拼环境。
- 一次只改被要求的那一镜；已确认绝不碰。每步抽帧与原片并排自检。
- 构图不对先查人物调度(blocking)，再查机位。硬信息靠测量不靠猜。
- 输出一律 H.264/yuv420p：引擎经 ffmpeg 管道直出，不用 mp4v 冒充成品；无 ffmpeg 时明确报错。
