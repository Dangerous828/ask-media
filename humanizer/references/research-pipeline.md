## 四道手

```
1 库检索 ──→ 2 精读证据包 ──→ 3 成稿 ──→ 4 去 AI 味 ──→ 投稿
  文献清单       带页码的证据       完整稿件      改前报告+终稿
```

### 1 库检索 → 2 精读

**交接物**：一组可唯一定位的文献（DOI 或八位 item_key）+ 每条的 PDF 路径。

**完成判据**：每条文献都有 `id` / `item_key` / 标题 / PDF 实际存在（`exists=true`）。缺 PDF 的单列出来，不进第 2 步。

有 `tensorreading` 时：`python scripts/tensorreading.py search "<主题>" --limit 20`，再对每条 `item "<id>"` 确认附件。没有时：作者自己整理一份 `文献清单.md`，字段对齐即可。

### 2 精读 → 3 成稿

**交接物**：每条文献一份证据包，至少含研究问题、方法、每个重要主张的页码定位（`[PDF p.7, Table 2]`）、证据覆盖说明。

**完成判据**：正文里每一个数字、每一个引语都能在证据包里指到页；AI 生成的 outline / note 明确标为「derived，需核对」，不作证明。没有 PDF 时写明「artifact-based」并列出哪些主张无法核实。

有 `tensorreading-deep-read` 时：python scripts/deep_read.py bundle "<id>" --out evidence.json（证据策略与判读等级见上游仓库的 evidence-policy 文档）。没有时：作者按同一形状手写证据包。

### 3 成稿 → 4 去 AI 味

**交接物**：完整稿件（`.md`），术语表（若期刊有规定）。

**完成判据**：稿子写完了才进第 4 步。第 4 步不负责补论点、补数据、补文献——那些是第 2/3 步的欠账，回到上游补。

### 4 去 AI 味 → 投稿

```bash
python3 scripts/detect.py 稿件.md --genre academic --json > /tmp/before.json
```

**完成判据**（全部满足才交稿）：

1. 改前报告已交付，作者已回复「按建议改」或给出调整范围。
2. 只改了报告里列入方案的项；语体保留项（降 C）、X 级已否决项、术语、公式、符号、单位都未动。
3. 复测报告已生成，A/B 命中清零或有明确保留说明，C 级指标无大幅摆动。
4. **「论文核查」清单逐项人工核对过**：引用真实性、数据自洽、贡献可验证、可复现性。脚本查不到这一层，报告不等于已通过核查。
5. 事实锁复核：正文数字、日期、人名、引语、出处在终稿里都在，且没有新增。

## 边界

- 第 4 步的 `--genre academic` 是**工程判读，非论文语料实测标定**，见 [academic-paper.md](./academic-paper.md)。报告里的「人类≈x/千字」是新闻自媒体语料的参考值，在论文里没有统计意义。
- 不用「去 AI 味」当理由改写学术语体规范：被动、名词化、枚举密度、分号层级是论文要求的。
- 术语表内的词一律不改；要动先问作者。
- 不在报告里宣称「本文统计显著是 AI 生成」——没有单篇显著性检验就不能这么说。
