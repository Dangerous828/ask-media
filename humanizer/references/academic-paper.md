# 论文 / 学术语体档（academic-paper）

> **证据等级：工程判读，非配对实测。** 主技能的两轮结论（629 篇对照 + 270 对同题同事实配对）语料以新闻、评论、自媒体、随笔为主，**没有人文学科或理工科学位论文/期刊稿**。本档把主技能的规则映射到论文语境，标注哪些失效、哪些保留、哪些要加，属于未经同口径复测的经验判断。对外不要把它说成"研究证明论文这样写是 AI 味"。

## 一、语体冲突：这些规则在论文里失效

论文的规范语体本身要求主技能判定为"AI 味"的写法。**命中不等于要改**，先看这张表。

| 主技能规则 | 论文语境 | 处置 |
|---|---|---|
| 5 顿号罗列过密 | 变量、指标、条件枚举是必要信息密度 | **降 C 只报告**。只改真正的同义堆砌 |
| 2 提示语冒号 | 摘要「目的：方法：结果：」是期刊格式要求 | **降 C 只报告**。格式规定的冒号不改 |
| 4 过长前置定语 | 术语定义的长定语不宜拆 | **降 C 只报告** |
| 4 前置话题壳 | 「在……方面」用于限定适用范围 | **降 C 只报告** |
| 4 句首连接词 | 「因此 / 此外」是论证路标 | **降 C 只报告** |
| 4 当…时从句 | 条件从句是方法章规范写法 | **降 C 只报告** |
| F 级分号（GPT 指纹） | 分号承担分句层级，论文里是功能用法 | **不按新闻口径判**。保留须说明它标的是哪层逻辑，不做密度清理 |
| 名词化、被动语态 | 学术语体核心特征 | 脚本无对应规则，不列入指标 |

**1 翻案腔、3 起手式在论文里仍然成立，脚本保留 A 级**：「不是 A 而是 B」「说白了」在论文里同样是空话，不因语体豁免。真正要守的是「不要为了去味塞进第一人称『我认为』」——那是禁止项，见第七节。

判定口径：**先问"换成一手好论文会不会也这么写"**。会，就不是 AI 味，是语体。

## 二、脚本档位

`detect.py` 的 `--genre academic` 落实上表：把 6 条与学术语体冲突的规则从 A/B 降到 C（只报告，不改），并追加「论文核查」清单。默认 `--genre general` 与上游完全一致。

```bash
python3 scripts/detect.py 论文.md --genre academic --json > /tmp/before.json
```

**降级是工程判读，不是实测标定**：上游两轮语料不含学位论文 / 期刊稿，降级后显示的「人类≈x/千字」仍是新闻自媒体语料的参考值，**在论文里没有统计意义**，报告里只作命中计数用。不要把它当成论文语料的显著性依据。

## 三、上游已否决的项，论文里同样不改

主技能 X 级清单是配对复测推翻了旧规则的结果，**论文语境下更要注意，因为这两条最容易被当成"学术八股"顺手清掉**：

- **「显著/大幅/明显」概括替代**：X 级，**即使同段有具体数值也不改**。复查净零（AI 更含糊 24.7% vs 更具体 26.0%）。学术写作里"显著"是统计判断用语，不是空话。
- **结论冒号引列表、序数词小标题、「这意味着」复述**：均 X 级，人类比 AI 更常用。论文的「结果表明：」与「（1）（2）（3）」编号是规范格式，**不改**。

本档不复述 X 级全文，以 [SKILL.md](../SKILL.md) 的「X 级清单（永不改，防误改）」为准。

## 四、论文里仍然成立的 AI 痕迹

下列各项**不在脚本正则表内**（脚本只做 F/C 与已列 A/B 项），由模型层判读，或人审。判读时同样遵守"换成一手好论文会不会也这么写"：

1. **章节路线图句**：「本节首先……然后……最后……」——除非期刊模板要求，直接删。目录已经承担这个功能。
2. **贡献列表凑数**：3–4 条并列，每条以"提出/设计/构建/验证"开头，拆开看是同一件事的三种说法。合并，或改成可验证的具体结论。
3. **空洞评价词**：有效、鲁棒、全面、深入、充分——后面没有数字、没有对比基线、没有效应量。**注意与第二节区分**：这类词要看清是不是在陈述统计结果，是则不动。
4. **转折套话连用**：值得注意的**是** / 需要指出的是 / 与此同时 / 综上所述。这些词都不在脚本正则表内，由模型层判读；只在明显堆砌时提示，一篇里出现两次以上删到一次。与第一节降级表区分：表中降 C 的「因此 / 此外」是论证路标（规范要求，不改）；「与此同时 / 总而言之」等转折套话不属路标，其中「总之」同族的概括词是主技能 X 级永不改项，改前先核对 SKILL.md 的 X 级清单，不得顺手删成空话。
5. **hedging 堆叠**：「可能在一定程度上或许会对……产生一定影响」。留一个限定词。
6. **高度同构三连**：连续三句"X 能够……，Y 能够……，Z 能够……"。**这一条脚本有检测**（`isomorphic_hits`），论文里同样成立，优先改。

## 五、论文特有维度（主技能不覆盖，需单独查）

主技能按符号与语义判断，管不到下面四类。它们比措辞更能暴露"生成稿未经核实"：

1. **引用真实性**：每条参考文献是否真实存在、作者年份卷期页码是否对得上、被引内容是否真的支持该处论断。AI 生成稿的引用常整条虚构或张冠李戴——**这条优先级高于所有措辞问题**，且必须逐条人工核对，脚本判不了。
2. **数据自洽**：正文数字、表格数字、图表标注、摘要数字是否一致；百分比基数、样本量与分母是否对得上；显著性水平与检验方法是否匹配。
3. **贡献可验证**：声称的贡献能否在方法章找到对应实现，实验章是否有对应验证。声称与实现错位是生成稿的典型症状。
4. **可复现性缺口**：超参、数据划分、随机种子、硬件环境、评价指标定义是否齐全到别人能重跑。

## 六、工作流调整

沿用主技能四步，但改三处：

- **第 1.5 步语义层**：只对文献综述、讨论、结论三章跑。方法章与结果章的候选默认 C 级，不送判读。
- **第二步报告**：指标表之外，另加一节「引用与数据核对」，逐条列出待人工确认的引用与数字。**明确写出脚本查不到这一层**，不要让用户以为报告已经过核实。
- **第三步改写**：只改第三节列出的项与脚本报出的 A 级项。语体特征（被动、名词化、枚举密度、分号层级）不动。改写后必须重新通读术语一致性——同义词替换在论文里会破坏术语统一，**术语表内的词一律不改**。

## 七、禁止项

- 不用"去 AI 味"当理由改写学术语体规范（被动改主动、删限定词、拆专业术语）。
- 不把 X 级项当问题改：「显著」类概括、结论冒号引列表、序数词编号、「这意味着」。
- 不为了让指标好看而删掉必要的枚举、限定与引用。
- 不在报告里宣称"本文统计显著是 AI 生成"——主技能已明确：没有单篇显著性检验就不能这么说，论文场景下这个错误后果更重。
- 术语、公式、符号、单位一律不动；要动先问作者。
