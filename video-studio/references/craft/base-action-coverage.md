# 基础动作 → 覆盖机位

从一条已经成立的动作出发补机位，不从分镜表出发逐格重写动作。

**何时读**：一场戏要多个机位（打斗、追逐、对白反打）、或反馈"每个角度都在重新设计整场戏""补出来的镜头接不上"。连续段规划与生成分组仍以 [sequence-planning.md](sequence-planning.md) 为准。

## 顺序

1. **先让一条动作成立。** 选承载完整因果的那一条：接近 → 接触 → 反应，人物间距离与力量关系读得出来。先出 draft，完整播放、逐段看相位，创作者认可后才算基准段。
2. **再补覆盖机位。** 每个新机位只回答一个新增信息：宽景给空间关系、低角度给威胁高度、前景遮挡给现场感、反打给反应。补机位是信息增量，不是凑镜数；没有新增信息就不补。
3. **继承，不重造。** 新机位沿用同一条动作的起止状态、抓握关系、服装、持物、光位与场景板。机位、景别、运镜可以变，动作链不许重写。
4. **末帧延展收尾。** 从已认可片段的真实末帧向后延展，接住动作收尾与喘息；人物位置、抓握、光线、服装都要接着上一段。

## 本地 h3q 的能力边界

原教程把选中的基础打斗当作 `@video_1` 送回模型生成新机位。**本地 h3q 没有 `reference_video`，也没有纯文生**；`last_frame` 已支持（FL2VA，见 [`minimax-h3.md`](../../../drama-skills/skills/short-drama-video-prompts/references/minimax-h3.md)），但 FL2VA 与 `reference_image` 互斥，所以这条"用视频参考生成新机位"的链仍然不成立。不要拿尾帧塞进 `reference_image` 冒充续接。

本地等价做法，按优先级：

| 做法 | 输入 | 约束 |
|---|---|---|
| 同一条已认可 draft 的真实末帧作 `first_frame` | 一幅图 + Base 三段正文 | 末帧必须是真实解码帧，不是计划帧或文字描述；新段开头要写清承接姿态 |
| 末帧作 `reference_image` 之一 | 多图 Ref2VA 六段 | 场景板、身份板与末帧同组挂；末帧只捐起始状态，不捐身份 |
| `flf_chain` 式逐镜接力 | 逐镜首尾帧 | 每镜做气闸；官方 FL2VA 默认单段，见 `video-studio` R4a |

三种都要求：基准段先通过 `short-drama-review` 的 `look_check` 且复核 `approved`、`use: reference`。生成物没批准就当参考，`ref_gate` 会拦（EP01 复盘已实测）。

**每次补机位都要带齐本镜出场角色的身份板。** 换了角度不等于换了身份；漏挂角色卡由共享 `ref_gate` 的 cast 覆盖检查拦截，见 `short-drama-produce` 画风闸门段。

## 完成判据

- 基准段已实看并认可，job id 与 draft 参数可回查；
- 每个补机位写清它新增的那一条信息，以及它从基准段继承了什么；
- 所有机位的动作链逐字同一，改的只有取景与运镜；
- 末帧承接段的第一帧与上一段真实末帧并排看过：同一人、同一空间、同一造型、同一持物状态；
- 每条补机位的参考组都含本镜出场角色的身份板，且 `ref_gate` 返回 `allowed: true`。

补机位拼不上时，允许同时改基准段与补机位；连续两次修补仍不成立就整段重写，不用叠化或硬切掩盖。
