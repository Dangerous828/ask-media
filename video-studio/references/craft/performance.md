# performance.md · 表演与神态描写

> 来源：公众号《100个导演级AI漫剧分镜》第 4 张「人物特写神态」10 条
> （OCR 提取，小标题完整，个别描述句有识别残缺，已用括号标注）
>
> **用途**：写 H3 提示词的「动作与表情」段，或生图的人物特写提示词。
> **核心价值**：把抽象情绪翻译成**可见的肌肉与动作**，比「他很伤心」具体得多。

---

## 一、为什么需要这份文件

H3 官方 `base-en.txt` 要求 `integrated_multimodal_description` 描述
「visuals, actions, shots, speakers, dialogue...」，其中 **actions 必须可见**。

我们实测过：写「他很伤心」「气氛紧张」这类抽象词，模型给不出表演。
必须写成「他低下头、手指攥紧杯沿、呼吸变重」。

**这份文件就是「情绪 → 可见动作」的对照表。**

---

## 二、十条表演骨架

> 写法：**景别 + 具体部位动作 + 可见的生理细节 + 情绪的落点**
> 括号内是 OCR 残缺处的合理补全，用前建议目检原图核对。

### 01 · 咬牙强忍

```
面部近景，下颌被死死咬住，眼眶泛红却强撑着不让泪落下，
倔强与脆弱同时写在脸上。
```

**可复用结构**：`面部近景，[某部位被紧绷] + [生理反应出现] + [强行压制] + [两种情绪并存]`

**为什么有效**：不说"悲伤"，只写"咬住下颌""强撑""不让泪落下"——三个可见动作。

---

### 02 · 垂眸失神

```
近景，主角低头垂眼，雨水顺发梢一滴滴坠落，
眼神空洞望向地面，周身笼着疲惫与无助。
```

**可复用结构**：`近景，[低头/垂眼] + [外部物理动作：水/汗/尘落下] + [视线落点] + [整体状态]`

**关键**：「雨水顺发梢坠落」是**外部物理事件**，它让静止的画面有了时间感。

---

### 03 · 仰头深呼吸

```
近景，主角微微仰头闭上双眼，喉结滚动，胸口起伏，
努力把翻涌的情绪压回胸腔。
```

**可复用结构**：`近景，[头/眼动作] + [喉结或胸口的具体起伏] + [压制的方向]`

**关键**：「喉结滚动」「胸口起伏」是可拍的，而「深呼吸」本身不可拍。

---

### 04 · 隔雨对视（双人）

```
中近景，两人隔着雨幕对视，雨水顺发梢与伞沿不断落下，
谁都没有先开口。
```

**可复用结构**：`中近景，[两人关系动作] + [隔断物：雨/玻璃/门框] + [共同的静止] + [否定式停顿]`

**关键**：「谁都没有先开口」把**沉默**拍成了可见状态。

---

### 05 · 指腹擦泪（双人接触）

```
近景，一只手抬起用指腹轻轻擦过另一人的眼角，
动作极轻，对方怔在原地，忘了躲。（防备瞬间瓦解）
```

**可复用结构**：`近景，[谁的手 + 触碰哪个部位] + [动作力度] + [被触碰者的僵住反应] + [防线变化]`

**关键**：用「指腹」而不是「手指」——力度差异是可拍的。

---

### 06 · 后颈相拥

```
近景，主角从身后被轻轻环住后颈，脸侧贴在肩上，
眼睛轻闭，防备瞬间卸下。
```

**可复用结构**：`近景，[拥抱的具体姿势：环住哪个部位] + [脸/头的落点] + [眼部动作] + [状态转变]`

**关键**：「环住后颈」比「抱住」具体，决定了画面的身体关系。

---

### 07 · 酒杯轻碰

```
近景，两只玻璃杯在灯下轻碰，杯壁相触的瞬间顿住，
谁都没有收回手。
```

**可复用结构**：`近景，[两件道具的接触动作] + [接触瞬间的停顿] + [双方未撤]`

**关键**：把人物情绪**转移到道具上**，比拍脸更高级。

---

### 08 · 掌背青筋

```
手部近景，用力攥紧栏杆的手掌，掌背青筋凸起，
指节泛白。
```

**可复用结构**：`手部近景，[握持对象] + [掌背/指节的生理反应]`

**关键**：**完全不给脸**，只用手部传达情绪。适合压抑型角色。

---

### 09 · 门框遮黑（转场用）

```
镜头推进到门框前，整幅画面被门框内部遮黑，
重新亮起时已在另一个房间。
```

**可复用结构**：`[镜头推进到遮挡物] + [画面被遮黑] + [亮起时已换空间]`

**关键**：这是**转场手法**不是表演，但能用来衔接两段情绪。

---

### 10 · 电梯合门（转场用）

```
镜头俯拍路面，[电梯门缓缓合拢]，画面收窄至一条缝隙。
```

> OCR 此处残缺严重，仅保留能确证的「电梯合门」主题。

## 三、通用规律（从十条里提炼）

| 规律 | 说明 |
|---|---|
| **情绪必须落到部位** | 「伤心」→ 下颌、眼眶、喉结、指节；不写情绪词 |
| **加一个外部物理事件** | 雨滴落下、烟雾升起、光斑移动 —— 让静止画面有时间感 |
| **双人戏靠隔断物** | 雨幕、玻璃、门框、桌面 —— 隔断制造张力 |
| **沉默要写成可见状态** | 「谁都没有先开口」「顿住」「没有收回手」 |
| **手可以作为主体** | 掌背青筋、指腹擦泪 —— 不给脸也能演 |
| **用具体名词代替泛词** | 「指腹」不是「手指」；「环住后颈」不是「抱住」 |

## 四、怎么用进 H3 提示词

**中文骨架不能直接进 H3**，必须翻译且嵌进结构：

```text
[Shot 2] At 00:03.500, the shot cuts to a close-up on <Subject 1>'s face.
Her jaw is clenched tight, the rims of her eyes reddening as she forces
the tears back, stubbornness and fragility surfacing on the same face.
```

要点：
- `[Shot 2] At MM:SS.mmm` 标记切点（`[Shot 1]` 无时间戳）
- `<Subject N>` 是参考标签，不是人名
- 情绪句写成**可见动作的英文**，不保留「倔强」「脆弱」这类抽象词
