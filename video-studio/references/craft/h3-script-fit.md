# H3 剧本适配：风格选择与制作质疑

用于明确采用 MiniMax H3 的剧本起草、现成剧本进入制作、分镜规划或画风选择。先读故事要兑现什么，再查对应风险；本参考输出制作建议，不替代剧作判断、H3 提示词规范或生产确认。

## 1. 读取后怎么做

1. 从输入或项目确认目标模型、画风、观看体验及已给出的时长。缺少画幅或时长时只标记受影响的判断，不为做检查强造参数；模型尚未确定时把结论写成“若采用 H3”。
2. 逐场检查下表中的风险，只记录剧本实际出现的项目。沿用现有场号；没有场号时引用动作或台词原文定位。
3. 按“影响剧情兑现的程度 × 证据可靠性”排序，先说最关键的 1–3 项，再列其余仍影响制作的项；无命中就明确说未见明显适配风险，不凑问题。
4. 每项给出保留剧情职责的拍法。可通过景别、调度、参考职责或后期解决的，作为可继续写作的建议；会改变核心动作、笑点、人物选择、画风或结局的，提出取舍并等待创作者决定该分叉，其他已明确部分继续完成。
5. 自己起草时采用不改变创作契约的稳妥实现，并简述重要选择；创作者提供的原文保持原样，建议另列。模型适配意见放在回复或用户指定的制作备注中，不塞进对白，也不为此另建一套 QA 文档。

反馈格式可用：

| 场次／原文 | 制作风险与剧情影响 | 证据等级／适用边界 | 保留剧情作用的建议 | 待创作者决定的取舍 |
|---|---|---|---|---|

证据不足时用“风险待测”，不伪装为模型必然失败。尚未提交或看过样片时，明确这是案头评估。

## 2. 证据等级

- **官方说明**：只支持原文规定的机制、协议或示例用途。官方示例能证明存在这种用法，不能证明成功率高于其他风格。
- **本地实测记录**：限定到记录中的模型、链路与场景；本参考引用的是既有记录，不表示本次重新跑过。
- **社区线索**：用户经验摘要收录的外部个例，本轮未复核原帖或源视频；只用于提示风险与设计验证，不能据此阻断创作。
- **待验证**：推测、冲突或缺少对照。给出待验证的问题，不写确定结论或成功率。

Qwen 静帧结果不能冒充 H3 视频实测；配置槽存在、正文出现某个词、机械闸门通过，也都不能证明画面执行正确。

## 3. 选风格：有示范不等于有排名

官方随模型提供 8 个场景技能：极简产品广告、风格化 3D 动画短片、立体纸艺停格解说、品牌宣传、MV 动态字幕、双人合作游戏开场、纸拼贴讲解、手绘与实拍融合。它们是官方提供的工作流方向，不是风格成功率排行榜。

| 创作方向 | 快速判断与该提出的质疑 | 证据边界 |
|---|---|---|
| 风格化 3D／Q 版／偏拟真的三维角色 | 可参考官方动画流程。先确认是“有体积的风格化角色”还是“接近真人摄影”；把评判重点落到身份、表演、空间与材质的一致性。 | 官方有 3D 工作流；“3D 拟现实必然更稳”“皮肤细节天生做不好”尚无本次可核对照。 |
| 极简广告／品牌图形／游戏开场／MV 字卡 | 官方有专项方案；质疑重点是精确品牌事实、UI、小字、歌词和节拍的验收要求。 | 专项技能存在不代表文字逐帧精确或音频分析能力有保证。 |
| 纸艺／纸拼贴／手绘与实拍融合 | 官方有专项方案；检查材料连续性、接触位置和动作能否清楚呈现。 | 不因此保证复杂穿越、变形或多场切换能一次成功。 |
| 真人写实／日常情景喜剧 | 官方 Ref2VA 有写实多机位情景喜剧示例，可以规划。若靠微表情或远景小脸承担反转，单独指出验收风险。 | 某个动画技能“不适用真人写实”只限定该技能范围，不能推导 H3 不支持写实。 |
| 纯 2D 平涂／简笔画／其他已指定介质 | 尊重项目已锁定的样张与参考图；检查定妆、场景、关键帧是否混入另一种介质。 | 不能仅因未列入 8 个专项就判不适合，也不能为了省事擅自改成 3D。 |

## 4. 从剧本里快速识别风险

下表的建议是实现选项；涉及故事意义的变更按 §1 提请创作者选择。

| 剧本信号 | 该质疑什么 | 保留剧情作用的实现选项 | 依据与边界 |
|---|---|---|---|
| 广角远景中靠脸认人、靠细微眼神揭晓身份 | 观众能否在该景别读出关键证据？ | 远景交代空间，近景承担身份或表情落点；用身份参考保持角色。 | **社区线索**：远景小脸清晰度报告有争议；无通用像素阈值。 |
| 密集 UI、聊天小字、精确 logo 或文件内容决定反转 | 关键文字需要逐帧准确到什么程度？ | 后期叠字或替换屏幕内容；前景特写展示必要文字，保留人物反应。 | **社区线索**：小字漂移与大标题可读案例并存，不能笼统断言文字强或弱。 |
| 激烈打斗／大幅变形同时叠加快速环绕、遮挡与换景 | 同一时刻需要模型维持多少独立变化？ | 降低运镜复杂度或分成有因果的动作段，保留决定性一击与反应；核心动作不可删时提出试片建议。 | **社区线索**：复杂动作与运镜复刻有溶解反馈，不等于所有动作戏都不适合。 |
| 手臂跨屏幕／门户、局部肢体穿越、人物从平面进入空间 | 肢体属于谁、边界在哪、穿越前后如何连接？ | 明确身体来源和空间两侧关系；在分镜阶段比较单镜连续实现、首尾帧约束、接触与反应拆拍。 | **待验证实现**：具体模式需按实际资产决定，不能保证 FL2VA 能解决。 |
| 玻璃碎片、半透明身体、重叠反射承担核心视觉证据 | 边界或碎片漂移会不会让观众误读剧情？ | 让轮廓、反光或单一可追踪物承担证据；透明机制若是核心设定则保留，并单独验证。 | **待验证**：本地经验摘要列为高风险；缺少可复核的 H3 样片／对照定位，不作材质禁令。 |
| 多角色抢话、同时说话、画外音与画中人并存 | 话落在哪个人、口型是否应该动、句子能否在窗口里说完？ | 明确说话者与可见动作，必要时顺次发声或外配；重叠对白是戏剧要求时保留为待测项。 | **社区线索**有串音反馈；本地闸门可查文字冲突，无法保证实际音色与口型。 |
| 同一空间穿越／揭晓在相邻两场或两镜重复执行 | 是补充信息还是把同一动作做了两遍？有无关键事件只剩静态结果？ | 一次动作负责改变空间，后续镜头承担新信息或反应；逐项保留“发现→变化→揭晓→行动”的必要因果。 | **本地实测记录**：本技能的事件对账与黑框段内自溶案例。按故事职责核对，不固定镜数。 |
| 首尾帧间要求连续运动，却计划写多个 Shot／绝对切点 | 想要连续插值，还是明确要硬切？ | 连续动作优先单 Shot；确需切镜时明确切点与动机。 | **官方说明＋本地实测记录**：本技能 R4a；FL2VA 多段曾诱发硬切，非每次必现。 |
| 角色板、场景图、关键帧介质不同；同时挂很多参考图 | 每张图只控制什么？是身份参考还是确切的起止帧？ | 先统一介质与身份，逐图分配职责；确切首尾帧和普通参考的模式按 H3 指南判定。 | **待验证**：既有项目经验提示先排查参考职责冲突；当前未附可复核样片定位，不据此量化图多的影响。 |
| 寄希望于最后超分、加 LoRA 或堆限制词解决全部问题 | 失败的是分辨率、身份、动作因果，还是参考职责？ | 先修来源问题；有依据时再选画质或风格处理方案，不把后处理当叙事修复。 | **社区线索**称 latent upscaler／EasyCache 有降质风险；**官方说明**提到风格 LoRA 与参考遵循的权衡。 |

## 5. 提示词阶段需要提前质疑的承诺

- **cfg=1 的 negative 槽**：官方 ComfyUI 指南明确 `BasicGuider` 没有负向分支。不要承诺“丢进 negative_prompt 就能排除”，也不要为此修改底层渲染器。优先描述目标可见状态，参考保留边界交给 H3 retention 规则。
- **正文否定**：正文中的单句 `no` 与独立 negative 槽是两回事。官方示例包含否定表达，官方动画技能与 ComfyUI 指南对成串禁词也有冲突；本机单句否定／禁词清单的 H3 A/B 尚未完成。因此采用正向描述作为默认，不能断言所有正文否定都会反向生效。
- **画风**：沿用已验收的参考与介质开场句；不要用一长串风格形容词替代空间、身份、光源与动作描述。品牌厂牌名无需作为通用模板固定后缀。
- **样片**：只建议最能验证核心风险的一项小样；明确它验证什么，不伪造费用、成功率或耗时。实际生成仍走 `h3-queue`，需要创作者对本次生成明确确认。

字段、素材角色、retention 档位与模式选择交给 `h3-prompt-writing`；提示词交稿交给 `h3-video-gate`。本参考不新增机械阻断规则。
