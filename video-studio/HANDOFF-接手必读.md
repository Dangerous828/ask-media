## 一、这个 skill 是什么，不是什么

**它是工具组 + 一组实测排障规律，不是提示词写法规范。** 提示词正文以项目已验收的写法为准，不由本 skill 规定；原始设计（风格权归 profile 独占 + 五槽拼装）实测更差。

组件清单与当前职责见 `SKILL.md` 开头工具表与「二、我现在在哪一步 → 读哪个」；组件该留该弃的逐项裁决见 `结论-提示词体系适用性.md` §四；定位修正经过见该文件 §一–§三、§七。

## 四、四条真正可复用的硬发现

| # | 发现 | 论证与数字 |
|---|---|---|
| 1 | 连续性靠「锚点链」，不靠单镜质量 | 相邻两镜共享机位轴／前景物／运动方向三选一；v4 八个转场全部落这一类，S06 与 S01 三件陈设完全复现。见 `MEASURED-闸门复验.md` §一 |
| 2 | 提高光要给「有面积的亮面」，点状物无效 | `>200` 是面积指标。见 `MEASURED-第三轮.md` §五。更本质的「被摄体决定出图质量」见 `结论-提示词体系适用性.md` §五 |

## 五、FL2VA 多段式会诱发真硬切（本项目最贵的教训）

**结论**：FL2VA 默认单段；写成三段式会诱发真硬切，且是概率性（同批 5 段未触发不代表安全）。首尾帧同属一段，只有真要硬切才分段。

事故现场、A/B 对照、官方依据与判据见 `MEASURED-闸门复验.md` §二「2.0 事故现场」；两道闸门（P0-4 / G28）的缺口与修复见同文件 §二「缺口 3」与「缺口 4」。
SKILL 的可执行规则见 `SKILL.md` §三 R4a。

## 六、四件套阈值必须按场景分档，不能一套通用

档位权威是 `scripts/qc_image.py` 的 `PROFILES`（含 `virtual-void` / `cartoon3d` / `interior` / `interior-backlit` / `aerial-landscape` / `screen-occluded` 六档及阈值）。
其中 `cartoon3d`（3D 卡通暖柔光）高光**行权值为 5–28%**：角色C高光 P50=16.0% / P75=35.3%，28% 只覆盖约半数样本，不是“覆盖多数”。示例项目实测建议的 15–25% 为**待采纳建议**（见 `MEASURED-示例项目实测.md` §五待办第 2 项），**未生效**。
同一批图在默认档、正确档、混合判据下的通过率差异及数据源见 `MEASURED-Opus六信号复验.md` §4.1 / §11 与 `qc_image.py` 的 `PROFILES` 注释；画风本性的辨析见 `MEASURED-示例项目实测.md` §三–§四。
`border_dark` 字段只记录不门控，实例见 `MEASURED-Opus六信号复验.md` §2.1。
