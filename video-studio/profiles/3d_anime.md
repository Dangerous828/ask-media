## 一、8 维度决策（写词前先确认，后续不轻易改）

| 维度 | 本 profile 的决定 |
|---|---|
| **叙事世界** | 当代温暖都市；现实向，允许轻微理想化；科技水平=当代日常（手机/电脑/电车） |
| **表现媒介** | **风格化三维（stylized 3D）**，有真实空间体积；保留赛璐珞式清楚轮廓；不做照片写实、不做平面色块 |
| **造型** | 亲和的立体卡通造型；角色比例以确认设计为准；脸、手、服装边缘、道具轮廓是精度重点 |
| **色彩** | 基底暖橙 / 辅助天空蓝 / 强调薄荷与琥珀；较明快而非荧光；亮暗过渡柔和 |
| **光影** | 柔和暖调电影打光；主光方向按场景定；轮廓清楚、暗部不死黑 |
| **材质** | 服装有可信褶皱、金属有风格化高光、食物有温润表面；**皮肤不做照片级毛孔或蜡像高亮** |
| **构图与运动** | 门窗/走廊/楼梯构成立体纵深；动作自然顺滑、重心合理；镜头移动有空间路径 |
| **清晰度与禁项** | 主体识别优先；允许细颗粒与镜头景深；禁止照片写实、廉价塑料、低多边形、死黑阴影、完全平面化 |

## 二、profile 六槽（拼接用）

### 【媒介】
风格化三维动画渲染，有真实空间体积，保留赛璐珞式清楚轮廓，高细节但经设计的材质

### 【色盘】
- 基底 `#F5A673`（暖橙）
- 辅助 `#87AEC9`（天空蓝）、`#F4D5D5`（粉）
- 强调 `#9DC2A5`（薄荷）、琥珀、象牙白
- 整体明快不荧光，亮暗过渡柔和

### 【光影】
主光：柔和暖调电影打光，方向按场景定，轮廓清楚

| 情境 | 光色处理 |
|---|---|
| 清晨、日常 | 柔和自然光，暖黄/象牙白配冷天空光 |
| 咖啡厅、居家 | 暖侧光，布料和木面保留立体层次 |
| 工作、校园 | 中性顶光与环境补光，避免全场过暖 |
| 黄昏、夜景 | 琥珀边光、粉橙局部；夜晚暖灯与蓝色空间对照 |

### 【材质】
- 皮肤：温润有次表面感，**不做照片级毛孔、不做蜡像高亮**
- 头发：成束成块，有高光但不油腻
- 服装：可信褶皱，布料有厚度
- 环境：木面温润、金属风格化高光、玻璃有反射

### 【正向锚词】（5–8 个，逗号分隔，前置）
```
3D动画渲染，赛璐珞质感，清晰轮廓，高细节风格化材质，柔和暖调电影打光，立体空间
```

### 【规避】（只放末尾，只写媒介/风格否定，**不写场景否定**）
```
照片写实，廉价塑料，低多边形，死黑阴影，完全平面化
```

> 注意：不要把「风格化比例」和「绝对禁止卡通比例」同时要求。
> 不要用材质术语覆盖人物识别描述。

## 六、关键规则：先定「世界明暗基调」，再写镜头

> **本轮最重要的发现。** 暗部超标的真正原因不是 profile，是镜头层没定义世界的明暗基调。

### 实测（同构图、同 profile、同 seed，只改场景基调描述）

| 版本 | 场景描述 | 平均亮度 | 暗部占比 |
|---|---|---|---|
| A | 「独立在灯塔城石阶上，望向成片灯火」（隐含夜景） | 21.7 | **92.0%** |
| B | 「站在被光包裹的灯塔城石阶上……**整个空间由光构成**：每一座灯塔的塔顶、街道、空气都在发光，**光充满画面**」 | **83.4** | **21.4%** |
| 官方基准 | — | 125.2 | 4.9% |

**只改这一处，暗部从 92.0% 降到 21.4%（−70.6 pt），亮度从 21.7 升到 83.4（+61.7）。**

### 为什么

官方样本的提示词**一个字都没写 night**：

```
A young man floating weightlessly in a vast golden digital void,
surrounded by flowing rivers of luminescent code, golden particles
and neon blue data streams drifting past...
```

它把场景定义成「**一个发光的世界**」，不是「一个夜景」。

而"灯塔城""塔顶在发光""夜空"这类词，模型会读成**夜晚的城市**——夜晚 → 大面积暗区。

### 三条硬规则

1. **禁止在镜头层写「夜」「夜晚」「夜景」「夜色」「深夜」「黄昏」「暗」**。
   要"晚上发生的事"，就用**光线本身**暗示时间，不写时间词。
2. **「整个世界在发光」按被摄体决定，不设强制定义句**（权威裁决见 `../SKILL.md` §三 R3「权威裁决」表）。普通室内/人物场景写它会制造 16–50 雾；被摄体本身是发光群体时才适用。
   - 普通场景：`塔顶在发光，街道被它照出一条暖光带`（写具体发光实体 + 受光面）
   - 发光群体场景：`整个空间由光构成，塔顶、街道、空气都在发光，光充满画面`（tB/nx1 这类灯海题材适用）
3. **环境密度三层都要写「被光照透/发亮」**，不能只写"有物体"。
   - 错：`后景是塔群`（物体存在但可能是暗的）
   - 对：`后景是连成一片光带的塔群与弥漫的光雾`

### 与 Toonflow 规范的对应

`visualStyles.md` 原文：
> 先写「左侧窗光照亮右侧墙面」等可见效果，再按需要补数字。

本条是它的加强版：**不只写"光从哪来"，还要写"光占有多少画面"。**

## 七、环境密度填法：场景 = 景别 + 空间特征 + 具体陈设 + 光源实体

> 来源：公众号《100个导演级AI漫剧分镜》第 1–2 张「景别与场面」20 条的结构提炼。
> **只抄结构，不抄文字**（原文含色值词，且是都市题材实例）。

### 7.1 公式

```
【环境密度】= 景别 + 空间特征（纵深/逼仄/开阔）+ 2–3 件具体陈设 + 1 个光源实体
```

三件事各自解决一个问题：

| 要素 | 解决 |
|---|---|
| 2–3 件具体陈设 | 画面写空（旧 skill 单格暗部 30.3% vs 官方 9 格均值 14.1%，两者口径不同不可并列） |
| 1 个光源实体 | 暗部超标（不给光源，模型按默认画黑） |
| 空间特征 | 三层无纵深、画面扁平 |
