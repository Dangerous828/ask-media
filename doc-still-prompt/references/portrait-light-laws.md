# 人像光线与构图：案例诊断

当人像光段反复改词无效、构图被参考拉偏或一批画面越来越相似时读取。本文保留 `L-Trunks/ai-portrait-light` 的来源陈述与案例启发；仓库数据、许可、挑片批次和约280张对照的原始记录未在本轮重新核验。它们不能证明跨模型定律，也不能代替当前项目已接受的画风和机位。

## 1. 先确认这张画面靠什么成立

读本镜职责，再说出一两个具体支点：人物与目标的关系、特殊取景、光落在动作部位、环境几何或成像处理。例如低机位从花间看到人物递出的手，重点就不是每根头发都发亮。

本帧支点是诊断入口，不是新增表格或硬配方。身份板可以靠中性比较，剪影可以靠轮廓，复杂市场可以靠拥挤的空间关系。背景密度、几何线、轮廓光与补色对都按当前作用选择。

## 2. 名词先验：需要测试的线索

模型可能把“路灯”“招牌”“黄昏”等名词与常见位置/外观一起补全，和当前空间指令竞争。遇到这种情况，先检查名词是否准确，再检查参考、取景和前后句是否冲突。

| 观察到的问题 | 可以测试的表达 | 边界 |
|---|---|---|
| 高路灯词与低灯位竞争 | 若场景实际是矮墙灯，就写具体灯具及墙体关系 | 不为使灯变低而把已接受路灯改成马灯。 |
| 招牌被放到远景 | 说明它安装在哪个实体、距主体多远 | 不无依据换成贩卖机或新增照脸来源。 |
| 灯笼数量/排列被默认补全 | 如实写数量、尺寸与相对位置 | 数字和几何都不保证模型精确执行。 |
| 因果标签被画成妆容 | 按可见肤色变化、位置和程度写当前结果 | 不凭“寒冷/贫困”推出肤色、尘土或创伤。 |
| 黄昏没有太阳盘 | 只有当前设计确要看见太阳时才描述其位置/可见范围 | 日落、阴天和无太阳盘的黄昏均可成立。 |

名词并非永远压过形容词。改词、参考替换和画布变化应以实际输入/结果检验，不能只凭一次命中宣布普适规律。

## 3. 光位与照明职责

方位角与高度各自说明，如“主体左前方”“略高于眼”“屏幕在手下方”。侧前45°和正前偏下是两种可用选择；正侧、顶光、逆光、多源与均匀光也都可用。取景不必把光源拍进去。

逆光是否需要另一种照脸来源，取决于本镜是否必须看清脸。剪影和黑衣轮廓可以是已接受设计；不强制打脸四件套、鼻侧亮斑或睫毛投影。光比与色温只在解决具体关系时使用，详见 [光比与衰减](lighting-ratios-falloff.md)。

```text
The bright doorway frames her dark coat. A small reflection along the sleeve separates the hand holding the key, while her face remains a quiet silhouette above it.
```

这段以手中钥匙为read，面部留暗不自动判失败。

## 4. 背景、颜色与成像

- **背景结构**：少而大的块面可降低竞争；密集树干、人群或光斑也可表达环境压力。判断背景怎样服务人物/动作，不能用一条几何线或背景元素数量判好看。
- **冷暖关系**：两个来源的颜色可以分别落在不同表面，增强区分；单色、低饱和与相邻色同样合法，不为每帧补补色对。
- **成像方向**：数字、胶片、直闪、柔雾或其他项目处理要与该画面一致。可以有明示兼容组合，例如数字拍摄加胶片仿真；不因出现两个术语就误判互斥，也不无依据堆标签。
- **构图族**：特写、半身、环境人像各有信息范围，横竖画幅都能设计。画幅由项目决定；某组横幅特写未收敛，只说明该组输入/模型条件的局限。

需要避免一批图同质化时，检查是否复用了与本镜职责无关的动作、机位、背景或灯法。逐帧确定关系即可，不强制第二批换介质或重做已接受画幅。

## 5. 位置不执行时的检查顺序

1. 对账完整正文、有序参考及其视角、画布和实际输出。参考是否默认正面居中？后文是否又要求另一构图？
2. 用必要取景边界、共同空间锚点和相互位置表达意图，见 [连贯画面正文](visual-prose.md)。精确左右、数量与占比允许保留。
3. 若实验仍偏，记录具体偏差与条件，再选择调整表达、参考或制作方案。涉及人物位置/机位的改变回上游，不能为“出片率”改戏。

来源曾记录z-image水平位置对照未明显改变。这是有限实验，不足以证明所有模型都无法控制左右，也不足以规定默认裁图。

### 裁切是可选制作处理

创作者/当前制作范围允许裁切且保留本镜必要信息时，可以计算候选窗口。以原图宽归一化，窗口左缘为x0、宽为s，原主体中心cx裁后为：

```text
cx' = (cx - x0) / s
x0 = cx - target * s
0 <= x0 and x0 + s <= 1
```

还需检查画幅、景别、关键道具、动作空间与输出分辨率。下采样也可能改变可见细节、构图和后续参考范围，不能称“画质零损失”或“唯一代价只是收紧”。作为生成参考的派生图按当前准入规则另行验收；本页不执行裁图或媒体生成。

## 6. 实验与结论的范围

记录模型/版本、正文、参考内容及顺序、画布、seed、采样参数和结果，明确比较变量。种子波动、参考先验与画布都可能影响结果；同一prompt失败两次不能排除随机性。可做有目的的同输入控制或参考替换，不默认无限重抽，也不由挑片速度推出改词无效。

提示词预算按目标模型实际tokenizer测量。某个语料的中英字符/token系数只是该样本的统计，不能跨语言/模型直接换算硬上限。

## 回读

- 当前画面最需要读清什么？光、焦点、背景和介质是否共同支持它？
- 是否有与本镜无关的打脸、发丝、轮廓、做旧、补色、几何线或固定数字？不适用记NA。
- 来源案例的结果是否被写成未验证的模型能力或必然物理结论？
- 方案是否仍遵守已接受身份、Look、机位、画幅与帧角色？

好看与可用都以项目目的及实际画面判断；量化指标辅助定位，不能由轮廓光、发丝或单一选片率证明。
