# 真人元素、隐私素材与多视角资产

当素材包含真人照片、手部、私密截图，或现有参考不足以支持本镜侧/背/俯视机位时读取。先区分已授权的可见身份特征、需要保护的信息和当前未知项，再确定处理方法。

## 真人与截图的隐私边界

- 核对当前素材里可识别的脸、饰物、纹身、袖口、倒影、联系方式、账号和界面信息，以及创作者准许保留的范围。戒指、手表或纹身可能是已接受身份，不一律删除。
- 需要保护的信息，在投入参考前使用已授权的裁切、脱敏或替代素材；操作与验证按素材流程执行。本技能只写文字，不执行图像修改。不把正文否定词当作输入像素已清理的证据。
- 手腕裁切、遮挡、改变取景或改曝光只能在符合当前镜头与隐私决定时选用。窗外可用已接受的曝光、磨砂玻璃、帘或取景边界表达；不统一把窗过曝，也不凭空改场景。
- 反射面也应在可见范围内核对。正文写实际可见反射或材质，风险清单与排除项另存；未经检查不宣称倒影和截图已安全。

## 视角覆盖与派生图

读取分镜实际需要的视角，核对现有图片是否保留必要轮廓、衣饰与可见身份。单张正面图不保证所有侧背镜稳定，但也不因存在侧视就自动要求完整三视图。

确有缺口时，说明缺少的可见事实与受影响镜头，选择已有素材、适合视角的原始资产或经认可的派生方案。不得为迁就参考强改已接受机位。派生图是新生成物，复用前按 `short-drama-review` 当前准入规则验收，参考顺序、用途与实际内容同步更新。

## 真人照片向目标介质转译

真人照片只为已授权的身份特征提供参考；裁出单人不等于目标介质身份已成立。按项目已定的真人、3D、2D或其他方向制作相应转译方案，不强制先经2D再转3D。目标介质中的可见锚点获接受后，才冻结供该方向复用的身份表达；中性采样姿势和表情不成为永久身份。

合照中的另一人、背景和偶然饰物不自动属于角色。年龄、职业、衣饰功能等事实不能只凭照片外观认定；未知项保持未知。实际制作与媒体复用继续由对应owner处理，本页不触发生产。
