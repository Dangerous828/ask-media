# 文字检查的诊断：事实、适用范围与解析误报

在检查器报告缺项或正文与检查结论不一致时读取。目标是修复实际漏项和检查器误判，不能为了获得PASS改掉人物态度、隐藏真实错误、补不适用细节或伪造项目登记。

## 先分三类

1. **真实缺失或矛盾**：对照上游事实与最终模型正文，必要信息确实没有表达或互相冲突。直接修对应关系，译文与摘录同步。
2. **不适用**：该项对当前介质、景别、帧角色或产物用途没有职责。记NA并给具体理由，不补不可见脸眼、皮肤、容器或光比。
3. **解析误报/能力不足**：正文已有明确证据但正则不识别，或检查器要求另一套项目布局。保留原句、实际输入与诊断，修检查器或报告限制，不把语义改成词表喜好的答案。

检查器源码能解释它怎样匹配，不能代替上游事实、媒体验收或创作者选择。运行结果是查漏证据，词面PASS不是生成效果证明。

## 常见报告怎样处理

| 报告情形 | 核对 | 正确处理 |
|---|---|---|
| 态度词未命中，例如 `content`、`reverence`、`desperate` | 人物对谁/什么持何种态度，是否有本帧可见载体？ | 若明确，记录词表漏识别；不为命中而换成另一种情绪。若含糊，补目标与表演关系。 |
| `rests flat on the table` 未命中姿态规则 | 归属、承托与放置是否清楚？ | 保留有效表达；修解析器，不删除有用姿态词来迁就正则。 |
| 介质句缺 `rendered` | 是否已清楚表达摄影、三维或绘制介质？ | 有证据即可，不给所有分支补同一个口令。 |
| `--project` 找不到材料 | 当前项目根与实际布局是什么？ | 修路径或选择适配的检查方式；不为通过检查新建SHOTLIST/第二身份库。 |
| 资产名被帧号正则截错 | 当前条目是IMG资产还是SHOT单帧？ | 保留正式ID与归属，修布局/ID识别；不假登记为另一镜。 |
| 画幅或左右触发错误 | 正文的画幅、数量与相对方向是否真实、必要？ | 这些事实合法；核对几何与上游，误报交检查器处理，不为避词删事实。 |
| 比喻触发不存在的角色 | 比喻是否造成真实实体歧义？ | 有歧义则改清楚；无歧义则记录presence误报，不塞入不在场角色身份段。 |
| 光向短语未匹配 | 真实来源、方向与受光关系是否清楚？ | 必要时补关系；不加固定 `from the left` 与实际光向冲突。 |
| 结论no缺证据 | 这是真失败、反向问题的正常no，还是不适用？ | 记录真实缺失/冲突及正文短引。只有真不适用才改NA，不用NA掩盖问题。 |

## 介质与眼部

平涂/硬边赛璐璐常用简化眼色块、眼线与必要高光；真人近景的湿角膜、内眼角、虹膜纹理不自动加入。二维水彩、厚涂或项目明确的混合画法可有软边与渐变，不能把 `soft transition` 当成所有2D的禁词。45°须说明是光的方位还是高度，和衰减分开判断。

需要实际改词时按 [连贯画面正文](visual-prose.md) 修对应画面关系。排除项和制作元数据另存；精确数量、人物左右与已接受文字仍如实表达，不用禁词清单取代事实判断。
