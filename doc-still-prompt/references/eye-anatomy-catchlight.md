# 可读眼部：视线、眼睑与光源反射

眼区在本帧可读且有作用时使用。解剖词表主要服务真人近景；3D与2D沿用项目的眼部设计，不把整套写实材质移植过去。不可见、闭合、远景或剪影眼部按[主流程](../SKILL.md)记录限制，不为填检查项补器官。

## 先确定目标与当前状态

视线描述从本帧实际对象出发：对方、物件、画外地点或有意直视的镜头。身体、头部和眼球朝向是不同事实，选择后一起核对遮挡与目标位置，不默认人物看观者。

- 头转向一边而眼看镜头时，眼球可能需要相对眼裂偏转；不能同时强求虹膜在眼裂正中。
- 低头看向较高目标时，可说明眼睛抬起；具体补偿方向由头、目标和相机的实际位置决定。
- 画面左右与角色自身左右分清。自然的侧身回看可以成立，不能仅因 `sideways` 与 `lens` 同现就断言斜视。
- 眼白分布随视线、头部角度与开睑变化。单眼一侧眼白较多可以是正常侧看，不据此诊断双眼失配。

若当前帧明确负责交代“已看见某目标”，核对观众是否能读到所需注意力关系。若本帧在发现之前、眼睛被遮挡或交接只需头身方向，沿用已定状态；后续才发现不授权起幅提前睁眼盯住目标。

## 眼睑形状与表演

上下等宽眼白不是中性视线的通用判据，也不证明在看镜头。上方眼白明显可见可能产生圆睁感；中性眼可用上睑轻搭虹膜上缘表达，但具体形状仍由身份设计、姿态与本镜表演决定。

可选写法：

| 当前需要 | 可见表达示例 | 使用边界 |
|---|---|---|
| 平静的睁眼 | `the upper lid resting just over the top edge of the iris` | 不是每个角色必须套用的身份句 |
| 有意侧看 | `her eyes directed toward the letter at her left` | 左右须与当前空间参照一致 |
| 低头而向门口看 | `her eyes lift toward the doorway while her head remains bowed` | 只在该姿态和目标几何成立时使用 |
| 有意圆睁 | 写上睑抬起及当前露出的眼白 | 由剧情表演决定，不用来补“眼神有神” |
| 闭眼、眨眼相位 | 写当前闭合形状，或按裁切省略 | 不要求瞳孔与高光同时可见 |

眉、眼睑和嘴部可以组合表达表演，不使用“抬眉与眯眼必互斥”的规则。表演选择见[微表演](performance-micro.md)。

## catchlight：角膜反射与场景光路

catchlight 是光源或明亮环境在角膜上的反射。它可能帮助读出眼球表面，但可见性取决于光源、相机、眼球朝向、遮挡、曝光、画风与输出尺寸；不是眼睛成立的必填项。

| 光源或环境 | 可能出现的反射 | 需要核对 |
|---|---|---|
| 可见方向上的太阳与天空 | 较小强亮点、较宽天空反射 | 太阳未被遮挡且反射几何可见时才成立；不强制两层都可辨 |
| 窗口 | 近似矩形、窗格或被遮挡的亮形 | 由实际窗形、视角和眼球曲率决定；窗可以在画外 |
| 格栅或有孔遮挡 | 分裂的亮形、碎点或较模糊的一片 | 不保证每个开孔各自成像可辨 |
| 屏幕、灯、火焰等 | 对应方向与尺寸的亮形 | 可以在下方、侧方或与其他源并存 |
| 明暗环境或低调光 | 很弱、部分被眼睑遮住，或无法辨认 | 不为补点而增设灯光、移眼或改曝光 |

10–2点是部分人像布光中的常见选择，不是自然光定律。高光也不必只有一个，不必两眼全等；同框人物可因位置、眼向和遮挡不同而出现不同的可见反射。

需要精修时，选择有依据的形状、相对位置与尺寸即可，例如：`a small softened reflection of the off-camera window along the upper edge of the iris`。句子描述当前光路，不保证模型执行；不为配高光更改视线目标或世界光源。

## 真人近景可选名词

| 部位 | 英文 | 可表达的当前特征 |
|---|---|---|
| 虹膜 | iris | 颜色、可读的径向纹理与局部受光 |
| 瞳孔 | pupil | 当前大小与朝向；大小不单独证明某种情绪 |
| 角膜缘环 | limbal ring | 可见时的虹膜边界；清晰度不作为年龄或神态硬证据 |
| 巩膜 | sclera | 当前露出范围与色调；不强制添加血丝 |
| 下睑水线 | waterline | 当前可见的细亮边；远景无需展开 |
| 内眼角/泪阜 | inner corner / lacrimal caruncle | 当前可见色调与湿润感 |
| 结膜/睑缘 | conjunctiva / lid margin | 解剖特征确需辨认时再用，不与泪阜混为同一结构 |
| 上下眼睑 | upper / lower lid | 开合、松紧与覆盖虹膜的形状 |
| 睫毛 | lashes | 可见轮廓、方向与局部遮挡 |

深色虹膜不必强行读出纤维；只有景别、光线与本镜任务支持时才描述。湿润、纹理、边缘清晰和高光各自按需要选择，不能把它们全部叠成“有神”配方。

2D可使用色块、眼线和项目既定高光符号；3D按角色设计和渲染介质表达。风格化眼不必复制真实角膜光学。

## 眼区回读

需要生成物验收时看真实眼区；仅有提示词时只作文字判断：

1. 当前可见的头、眼方向与目标是否相容？
2. 眼睑形状是否符合表演，而非为对称眼白被撑开？
3. 若描述了高光，其来源、几何与当前可见性是否可信？
4. 部位与材质是否适合景别、介质和角色设计？
5. 是否为模板新增窗、灯、直视、血丝或不可见眼部？

不适用的细节可省略或 NA。缺一个名词不等于眼部错误；命中词表也不证明眼向与光路正确。
