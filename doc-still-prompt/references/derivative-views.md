# 参考图派生视图、取景与状态

用已接受成图或角色锚点派生新视图、局部或状态时读取。纯文生图按[主流程](../SKILL.md)执行；派生任务同样需要必要身份、当前状态与可见关系，不因垫图自动豁免。

本页部分取景策略来自本地Qwen Image 2.1同族编辑通道的有限对照记录。它们是排查选项，不是“模型只听第一句”的机制结论；模型、编码器、参考与参数改变后不能假定结论仍成立。

## 先定本次改变与保留

在裁决中明确：参考实际画了什么、本次目标视图或状态是什么、哪些身份和造型保持、哪些构图和姿态允许改变。使用当前通道支持的方式组织输入，核对最后真正发送的正文与参考。

文字目标应容易发现，可在开头清楚表达取景，再沿目标画面的几何与可见内容展开；不固定首句咒语，也不规定结尾再重复一次。状态派生不一定需要改构图，视角派生也不自动改变姿态或表情。

完整身份保留在权威库；正文选适用的完整或已登记可见锚点。缺合适局部/视角锚点时先按既定身份补同库登记，不把整套脸、衣、鞋清单塞进局部图，也不笼统跳过身份核对。

## 取景词汇与几何线索

以下是目标表达组件，按当前已定视图选择，不要求逐字拼接或每项都用：

| 目标 | 可用表达 | 本帧需要核对 |
|---|---|---|
| 头肩近景 | `a tight head-and-shoulders portrait` | 头顶、下巴与肩的实际裁切；不默认护照姿势 |
| 正面全身 | `a full-body frontal view` | 头与躯干是否都要求正面、脚是否完整入画 |
| 背面 | `seen directly from behind` | 目标绝对视图、可见背面轮廓与造型 |
| 侧面 | `a profile view from the character's left side` | 角色解剖侧、身体与头向、鼻尖在画面中的方向 |
| 三分之四侧 | `a three-quarter view from the character's right-front side` | 当前可见侧与实际目标；角度数值有需要再用 |
| 局部 | `a tight detail view of the hand and sleeve cuff` | 哪个部位、邻接区域及裁切边界 |

`Rotate the camera 180 degrees`只有已知起始机位和旋转轴时才有明确终点；背面任务优先描述背面目标。鼻朝画右不自动等于右半脸可见；不能混用角色自身左右和画面左右。

需要严格正面时，可选鼻尖与面部中线、可见肩部的相对对齐作为线索。发型或帽子遮耳不构成不正面；头肩裁切不能为肩髋脚一律朝镜头而拉远。脸、躯干与眼的方向仍是独立选择。

## 一致性按可见范围表达

| 当前取景 | 适合承接的身份事实 | 边界 |
|---|---|---|
| 头肩 | 脸、发型、可见领口和饰物 | 不为完整身份补下装与鞋 |
| 手或其他局部 | 可见部位、袖口、相关识别标记与材质 | `same person`不能替代必要区别，也不应展开全套不可见清单 |
| 背面 | 轮廓、背面衣饰、帽包或发型 | 真实存在的后袋等须保留，不把所有pockets当正面元素排除 |
| 全身 | 本帧能见的脸、发型和整套造型 | 仍不绑定中性采样姿势或眼睑终态 |

年龄感只在可见部位有作用时承接角色设定；不为年龄标签给局部皮肤添加皱纹或缺陷。不能把一次眼镜局部失败写成所有脸部局部都不可用，也不把某个调用方的 `part` 字段禁用混进通用写作规则。

## 参考职责与来源

- 选择完成当前任务所需的身份、造型、地点或其他参考，说明顺序和职责。参考图不自动授权复制背景、人物数量与当前姿势。
- 回可靠锚点可减少累积漂移；已接受派生图也可以按当前用途评估。链式漂移是风险，不等于任何派生物都不能再用。
- 多视图板和多人拼接板可能被误读为多个实例。先核对每个角色、每张图实际包含什么，再按当前通道选择合适素材；参考形式本身不证明必定复制或必定消重。
- 已有接受状态不能证明本次一定保真。图数、标签、独立负向槽与生产方式查当前通道；不借本页新增媒体任务。

排除项另列拦截表，按[主流程](../SKILL.md)和目标通道决定是否映射。取景、人数、衣饰与遮挡主要用正向关系表达，不以负向face、身体部位或服装清单替代目标几何。

画风与材质来自项目已定Look及参考用途。若调用方另附画风前缀，必须核对最终真实输入；不能因预期“渠道会加”而让介质事实缺失，也不重复灌入整套不适用风格词。

## 有界经验与排查

现有记录曾出现：只写close-up却保留半身；局部图罗列整套衣服后得到全身；多人拼接板被误读为额外人物；眼镜局部请求回到整脸。可据此检查目标取景、身份清单与参考冲突，不能从少量seed推出普遍禁令。

诊断时记录实际正文、有序参考及内容哈希、画布、模型/编码器、参数和输出，明确本轮改哪项。需要更多对照时先确定范围与生产授权，不把重复强调第一句或无限换seed当默认修法。

## 完成核对

目标视图、可见边界和允许改变的内容是否明确？权威身份是否按当前可见性承接？坐标与朝向是否自洽？参考职责和最终输入是否对账？是否保留了本帧用途与介质，未为取景词、完整身份或风险模板擅改画面？
