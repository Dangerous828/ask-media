# 2D 绘制介质与漫画静帧

项目已选二维绘制方向时读取。以已接受的线条、色层、笔触、阴影边缘与密度为依据，不按“非真人”一律套国别标签。三维主体的材质表达见 [3D 分支](animated-3d-look.md)；项目明确的兼容混合介质按各自控制范围表达。

## 可选词汇

| 视觉方向 | 可选英文表达 | 怎样选择 |
|---|---|---|
| 条漫清线和平涂 | `clean ink linework, flat color fields, restrained layered shading` | 需要明确轮廓与色块时；不代表所有 manhwa 都同一风格。 |
| 手绘动画 | `hand-drawn contours, painted backgrounds, simplified character shading` | 按项目实际线条与背景处理，不用作者名代替可观察选择。 |
| 硬边赛璐璐 | `clean outlines, a small number of hard-edged shadow shapes` | 项目确实采用硬边分区时，不给这一层加入摄影式皮肤渐变。 |
| 厚涂/绘画 | `visible brushwork, volumes built from broad painted values, selective soft and hard edges` | 可用软过渡；“2D”不等于所有边缘都硬。 |
| 水墨/水彩 | `varying ink contours, translucent color washes, paper left open around the figures` | 留白、纸纹和晕开须来自本项目方向，不自动添加。 |

项目采用地域或作者风格名时，进一步说清它在本帧改变了什么。可以选兼容的线条、上色与背景组合；同一表面上的互斥要求才需裁决，不因两种风格名称并列就自动否决。

## 本帧怎么组织

1. 先确定本帧人数、区域、身份、姿态、持物与相互位置；沿核心关系写正文。
2. 用已定介质投影必要形状、色层和受光。例如轮廓的断续、阴影硬边、纸面留白各承担什么信息。
3. 眼睛按项目简化程度和表演写。平涂中性眼可用上睑轻搭虹膜上缘、简化色块和必要高光；高光数量不是配额。写实角膜、湿内眼角、虹膜纤维仅在明确采用这类画法且当前可见时使用。
4. 光影可以由色块、明度层级或绘画性处理承担。需要查灯位时用 [光位与阴影](lighting-angles-shadows.md) 作为词汇，不照搬棚灯、精确色温或人像光比套餐。
5. `composition / start / pose_proof / end` 及具体时刻沿用上游；正文只画该瞬间。构图参考不默认是视频起点。

## 正文与排除项

正文写目标可见状态；文字、logo、水印与介质风险按项目政策单列在排除表。只有目标通道确认启用独立负向槽时，执行层才映射相应排除项。要求可读文字的画面不能同时使用全局禁字。正文已有写实眼球或三维材质时，尾部追加否定词不能修复介质冲突，应直接改对应描写。

## 条件自检

- 线条、色层、边缘与背景密度是否服从已接受方向？没有强制地域分类、作者锚点或固定收尾词。
- 当前景别是否能读到所写细节？不适用的皮肤、光比、透光或眼部材质项记 NA。
- 核心空间、视线、持物和文字政策是否清楚？画面可平面化，不能因此改变必要地理或身份。
- 英文与中文是否同一事实？排除项、参考职责、帧相位标签与生产说明是否在正文外？
