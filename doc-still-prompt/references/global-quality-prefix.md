# 真人静帧的成像与质感取用

真人摄影分支按本帧景别与观看目标选择成像描述。器材与胶片是质感参照，不代表实际拍摄记录；虚拟摄影参数记为设计选择。正文使用一套可解释的成像方向，兼容的拍摄与后期组合须有项目依据。

| 要确定的内容 | 可选表达 | 取用条件 |
|---|---|---|
| 摄影介质 | `live-action film still`、胶片仿真的颗粒与柔和色彩，或数字摄影的平滑影调 | 读取项目选择；胶片、数字、闪光或光滑表面均非质量高低的代名词。 |
| 镜头与焦点 | 标准透视、长焦压缩、环境广角；清晰层与虚化层 | 服从已定机位、焦段意图和需要同时读清的对象，不为模板添加毫米数或浅景深。 |
| 皮肤 | 受光鼻梁的汗光、可读的细毛/毛孔、暗部柔和过渡 | 须符合身份、年龄、状态、景别和光路；干净、修饰或平滑皮肤可以是已接受选择。 |
| 材质 | 同一束光落在布、皮肤和金属时的反射差异 | 贴着实际受光对象写，不以材质或瑕疵数量凑配额。 |
| 亮度关系 | 屏幕与手、背景窗与面部等关键区域的相对亮度 | 只在控制观看次序时写；发光物可亮过脸，不要求背景统一压暗。 |

## 正文与制作说明

正文描写同一瞬间的曝光、空间、姿态、表情与材质。人物口型与台词同步、跨镜持续要求、帧率、无抖动闪烁等属于视频或制作验收；把当前实际可见状态写进画面即可。

帧角色与时刻取自上游计划：构图参考可在镜内任一声明瞬间；实际 first_frame 对应起点，关键姿势与终点各守自己的瞬间。role、参考用途及后续运动留在元数据。

光可以来自画外或多个实体，当前取景不必把所有灯具拍进去。阴影、反射和清晰范围与已定光态相容；需要肖像技法时再查对应参考，不统一要求轮廓光、明暗图案或色温数字。

排除项留在独立表内，有启用的负向通道时由执行层映射。正文写目标可见状态，必要精确文字服从当前文字政策。

3D 动画按 [3D 介质](animated-3d-look.md)，二维按 [2D 绘制](comic-styles.md)。各分支在本帧可见的表达通道不同，不套用真人肤质。
