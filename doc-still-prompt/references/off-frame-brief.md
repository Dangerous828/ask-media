# 画外依据表：查什么，怎样转成当前画面

当皮肤、衣饰、动作、光或物件状态需要依据时读取本页。它帮助选择必要事实，不要求每帧查完整履历或填固定十行。事实与用途的权威流程见[主技能](../SKILL.md)。

## 先分来源，再决定是否研究

| 来源 | 可以支持什么 | 边界 |
|---|---|---|
| 实际图片观察 | 当前可见的颜色、形状、位置、遮挡与状态 | 未见部位、身份背景和内心不能冒充观察 |
| 项目已接受资料或创作者决定 | 本次创作的身份、造型、动作、地点和画风 | 标明具体条目或决定；不伪装成外部查证 |
| 可核对的外部资料 | 必要的服饰结构、工艺、地域条件或物理知识 | 一般规律不证明特定人物身上已有某种痕迹 |
| 关系推断 | 支撑本帧空间、接触或成像的一种解释 | 标明推断；有多个解释时降低具体度，不补成唯一经历 |
| 未知 | 当前没有足够依据的内容 | 关键事实先解决；非必要细节不写 |

已有项目资料足够时直接使用。只有任务确需但材料不足的事实才研究，记录实际来源；没有检索过就不能填写“已查证”。虚构任务允许明确的设计选择，纪实反推须区分看见与推测。

## 记录本帧必要事实

| 事实或选择 | 本帧可见结果 | 来源及状态 |
|---|---|---|
| 具体资料中的事实，或明确设计决定 | 当前需要表达的身体、空间、接触、受光或材质关系 | 指向实际材料，注明已接受/观察/推断/待验证 |

行数由本帧需要决定。先记录中文事实与取舍，正文成文后再摘录必要英文证据；不预造英文句子凑表。不可见项注明原因；不适用项可省略或记 NA。只有关键且未知的事实才阻止继续，不能靠把未知改写成肯定细节消除缺口。

以下是研究入口，不是像素配额：

| 可能相关的维度 | 何时值得查 | 不应自动推出 |
|---|---|---|
| 生计、长期环境 | 当前人物设定与可见使用痕迹确有联系时 | 职业或荒地背景不证明贫困、伤裂、尘土或色差 |
| 气候、季节、时点 | 影响本帧衣着、湿污、太阳方位或环境状态时 | 户外不必汗流、低太阳不必眯眼、寒冷不必脸红 |
| 衣饰、地域与用途 | 具体衣物的结构或穿法影响可见轮廓与动作时 | 不用一个实用目的概括所有文化、仪式或时尚穿法 |
| 年龄与造型 | 本帧需要区分年龄感，且可见部位支持时 | 不因年龄标签添加皱纹、发际或皮肤缺陷 |
| 动作与接触 | 有承重、持物、压迫或接触边界时 | 轻触不必写成硬挤压；动态姿态不套静态站坐模板 |
| 光与机位 | 需要说明可见性、方向、明暗或焦点关系时 | 不强制唯一光源、窄焦面或前景遮挡 |
| 物件使用史 | 既定新旧、磨损或状态影响辨认时 | 新衣与洁净物件不因“真实感”而必须做旧 |

需要进一步推导时查[画外因素](off-frame-determinants.md)；只打开与当前问题有关的部分。

## 构图效果与来源相容

需要遮眼、半张脸、背身回看等效果时，检查它与已定动作、穿法、机位是否相容。遮挡可以由取景、身体转向、既有实体或光照形成，选择有依据的一种；不为了满足模板新增门帘、改造衣物或改角色动作。

具体衣饰应查具体来源。看路、防晒只是可能用途，不能由它们断言所有面纱必须留出哪些器官。创作者已接受的虚构设计按其世界规则核对；未知的现实穿法保持未知。

排除项与通道负向能力按主流程处理。正向描述中的干裂皮肤、抬眉或深黑阴影并不因词面而错误；判断其来源、当前可见性与用途，不维护一份把身体状态全部禁掉的词表。

## 两个对照例

**纪实反推**：照片只见儿童、肩部披布和荒地。可记录披布边界、面颊表面与光向；没有来源时，不补“多年曝晒”“缺水”“遮蔽处更白”。通用日晒资料只能说明可能性，不能证明这个孩子的履历。

**虚构设定**：创作者指定牧童刚洗脸、穿新衣。把这项决定记为创作来源，正文可写洁净面颊与新衣状态；不为套“户外真实感”添加灰尘、破口或盐渍。若后续明确安排跌进泥地，则由那一时刻的状态支持湿污变化。

## 完成核对

- 必要事实是否有实际来源，推断与设计选择是否如实标记？
- 正文是否只展开当前能见且有作用的结果，未把研究标签变成人物经历？
- 未知、不可见与不适用是否分清，未为凑行数造细节？
- 构图与当前动作是否仍符合上游，必要冲突是否已明确处理？
- 正文成文后，必要事实是否能找到对应关系或短语，中文译文是否忠实？

完成标准是必要事实可追溯、当前画面自洽；不是所有维度都产生一条英文描述。
