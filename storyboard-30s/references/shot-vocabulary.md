# 运镜词库 / 景别词库（原文照录）

---

## 运镜词库（原 7 项 + 2026-10-26 扩充 4 项）

```text
固定机位（带轻微自然呼吸抖动）、缓慢匀速向前推进、缓慢匀速向后拉开、水平左右横移、垂直上下摇摄、360° 缓慢环绕镜头、斯坦尼康跟拍
```

| # | 运镜（逐字） |
|---|---|
| 1 | 固定机位（带轻微自然呼吸抖动） |
| 2 | 缓慢匀速向前推进 |
| 3 | 缓慢匀速向后拉开 |
| 4 | 水平左右横移 |
| 5 | 垂直上下摇摄 |
| 6 | 360° 缓慢环绕镜头 |
| 7 | 斯坦尼康跟拍 |
| 8 | 固定机位（不加呼吸抖动，写实冷峻等不需要晃动的风格用） |
| 9 | 水平摇摄（机位不动、镜头左右摇） |
| 10 | 升降 |
| 11 | 手持跟拍（只用于剧情已接受的不稳） |

运镜栏可以写成 `<词库词>｜起幅：…｜落幅：…｜动机：…`，闸门按 `，` `,` `｜` `|` 切分取首段核对词库。

## 景别词库（原 5 项 + 2026-10-26 扩充 3 项）

```text
特写（面部 / 手部）、近景（胸口以上）、中景（腰部以上）、中全景（全身 + 近景环境）、远景（大环境全景）
```

| # | 景别（逐字） | 定义（逐字） |
|---|---|---|
| 1 | 特写 | 面部 / 手部 |
| 2 | 近景 | 胸口以上 |
| 3 | 中景 | 腰部以上 |
| 4 | 中全景 | 全身 + 近景环境 |
| 5 | 远景 | 大环境全景 |
| 6 | 大特写 | 局部五官、手指、道具细节 |
| 7 | 中近景 | 胸部以下、腰部以上 |
| 8 | 全景 | 全身 + 所在空间 |

## 使用约束

1. 每一镜的「运镜」「景别」两栏**只能从上面两张表里取词**，不得自造（例如不要写"甩镜头""希区柯克变焦"）。
2. 运镜与景别可以在同一镜里组合，如"缓慢匀速向前推进，从中景缓缓推至面部特写"——起点景别和终点景别都要取自景别词库。
3. 「固定机位」必须带括号里的"（带轻微自然呼吸抖动）"，这是原文写法，也是防止画面死板的关键。
