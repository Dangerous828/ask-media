# 节奏（pacing）——镜头时长与剪切率

> 镜长由完整表演、声音和必要信息变化决定；长短或均匀都可以服务叙事。
> 下表是观看感受的参考，不是镜数配额或生成任务时长。

## 一、镜头时长的语义

| 时长 | 语义 | 用在 |
|---|---|---|
| <1.5s | 冲击、信息轰炸、慌乱 | 打斗碎片、闪回、蒙太奇 |
| 2–3s | 正常叙事节拍 | 大多数镜头 |
| 4–6s | 沉浸、观察、情绪发酵 | 决定性瞬间、反应镜头 |
| >6s（30s 片里） | 连续表演、调度、凝视、时间感 | 能在镜内承担多轮因果与反应时保留，不设次数配额 |

## 二、节奏模式（剪切率的形状）

- **渐快**（长→短）：紧张累积，冲向高潮（追逐/对峙爆发前）
- **渐慢**（短→长）：释放、余韵、结尾呼吸
- **心跳式**（短-短-长）：冲击-冲击-消化，动作戏标准
- **匀速**：冷静观察，纪实感（固定机位系列）
- 写法：先排事件与声音，再决定切点和镜长，回看整体形状，不靠填镜数获得节奏

## 三、台词镜头的时长下限

台词字数 ÷ 4.1 字/秒 + 0.5s 反应余量 = 该镜最短时长（语速与 `h3-video-gate` 的 G18 同一口径；儿童、哭腔、拖音按 3–3.5 字/秒，成人急促按 5 字/秒复核，用 `--rate` 传给闸门）。
说不完先调整发声窗口与镜长；只有确需换视点时再拆镜，跨切声音连续。拆镜本身不会增加总发声时间。
听者反应要让观众读清；时长按实际表演与景别决定，不设统一 1.5 秒下限。

## 四、声音与画面的节奏错位（高级）

- 音效先行（J-cut 思维）：声音比画面早 0.3–0.5s 进入，剪辑点藏在声音里
- 慢镜头+正常速音效（或反之）= 主观时间
- 音乐重音对齐剪切点（cut on the beat）= MV 感；**故意不对齐** = 纪实感
- 静默是最强的节奏工具：高潮前一镜抽掉所有声音

## 五、与 H3 的对齐

H3 支持一次生成中的多个 `[Shot N]`；一个 Shot 内的多个表演节拍不等于多个切点。
- 先决定剪辑镜头，再选连续单镜、同场多镜容器或分段生成，不默认每镜一个独立 job。
- 时长约束按执行端区分：云端 API 的整数秒范围与本地 ComfyUI 的 `17k+5` 帧网格分别核对。
- 本地 24fps 换算示例：124帧≈5.17s、192帧=8s、243帧≈10.13s；不能把近似秒数写成精确等式。
- 短镜可以通过合法容器或素材可用区间实现；不为生成下限把成片节奏一律拖长。具体编译支持情况由下游确认。
- 节奏设计发生在**分镜表阶段**，生成与剪辑分别核对任务时长与实际采用时长。

## 六、自检

1. 必要镜头形成的节奏有意吗，能否去掉不带来新观看信息的切点？
2. 长短或均匀是否服务观看体验？镜长相同与差异较大都需结合表演判断，不设统一比例门槛。
3. 每个台词镜是否容纳完整对白、实际停顿与必要反应？
4. 高潮前后的静默、长镜或切换是否来自本段观看需要？
5. 声明时长的总账是否对得上（各镜相加等于声明值，首尾相接无空隙）？
