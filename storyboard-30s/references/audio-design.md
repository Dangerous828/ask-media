# AI 视频音频设计模板（原文照录）

---

## 音频标准公式

```text
[持续环境音（音量 dB）] + [定点关键音效（出现时间 + 音量 dB）] + [背景音乐（曲风 + 音量 dB）] + [人声约束]
```

四段都要有交代；dB 数值可选（AI 视频模型不执行具体分贝，写相对强弱即可）。没有背景音乐时写"无背景音乐"，不能空着（H3 正文对应 `non_diegetic_music: N/A`）。

---

## 音频素材库

| 类别 | 素材（原文） |
|---|---|
| 环境音 | 持续雨声、晚风、街道车流杂音、室内安静底噪、森林风声 |
| 关键音效 | 脚步声、开门声、纸张撕裂声、雨滴砸玻璃、金属碰撞、心跳声 |
| 背景音乐 | 低沉钢琴独奏、舒缓弦乐、氛围感电子合成器、无背景音乐 |

上表是**示例**，不是封闭清单。声源以剧本为准：剧本写了蝉鸣、玻璃杯碎裂就照写（忠于原文优先）；
剧本没写的声源不要自己添。短剧项目的声音层以《剧本.md》和 H3 方言的 `overall_soundscape` 写法为准。

## 可直接复制音频示例（原文）

```text
音频设计：持续细密雨声（-12dB），2 秒处加入纸张撕开清脆音效（-6dB），全程背景音乐为低沉舒缓钢琴独奏（-18dB），无多余杂音，人物对白人声清晰突出，音效不盖过人声
```

---

## 从示例读出的写法规则

1. 环境音：**持续** + 形容词 + 素材名 + `（-12dB）`。
2. 关键音效：写**出现时间**（"2 秒处"）+ 质感形容词（"清脆"）+ 素材名 + `（-6dB）`。
3. 背景音乐：写"全程" + 曲风修饰 + 素材名 + `（-18dB）`。
4. 人声约束：固定两句——"无多余杂音，人物对白人声清晰突出，音效不盖过人声"。
5. dB 量级参考示例：环境音 -12dB，定点音效 -6dB（最响），音乐 -18dB（垫底）。
   定点音效要能听清但不压过人声，音乐始终低于环境音。

---

## 落到分镜表的两种方式

- **整片音频段**（推荐，与示例一致）：在片头【场景】【角色】【道具】之后另起一段【音频设计】，
  按公式四段写完整一条，30 秒共用。
- **逐镜标注**：某一镜发生的定点音效，同时写进那一镜的「特效 / 音效」栏，带出现时间与 dB，
  与整片音频段保持一致，不要两处写不同的音效。

## 下游映射（可选，不构成依赖）

本公式的输出可直接映射到 MiniMax H3 的字段：
持续环境音 + 定点关键音效 → `overall_soundscape`；背景音乐 → `non_diegetic_music`。
字段语法与 `<d>` 时长标签见 `~/.agents/skills/h3-prompt-writing/`。
