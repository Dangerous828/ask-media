# 动作动机链（为什么做这个动作）

> 大佬总纲"人物为什么站在这里"的分镜版延伸：每一镜的每个动作都要有**因**。
> 没有动机的动作 = 摆拍感；有动机的动作 = 纪实感。

## 一、动机三问（每镜动作过一遍）

1. **欲望/任务**：这个人物在这一刻想要什么？（数完钱关店 / 追上他 / 藏起那张纸）
2. **阻碍**：什么在挡着他？（玻璃碎了 / 对方拔腿就跑 / 门外有人经过）
3. **反应**：动作是"欲望遇阻碍"的产物，不是导演的摆布。

**公式**：`欲望 + 阻碍 → 动作 → 结果/反应 → 下一镜的新欲望`

## 二、写法对比（同一镜）

❌ 无动机（摆拍感）：
```
镜3  中景，女生站在街道中央，抬手摸头发，镜头缓慢环绕
```
✅ 有动机（因果链）：
```
镜3  中景，女生把碎玻璃攥进掌心（她想留住这个证据），指缝渗出血珠（阻碍：疼），
     她因刺痛缩了一下手又攥紧（反应），抬眼望向街口（新欲望：他在等她），
     镜头随她的视线缓慢横移
```

要点：
- 每个身体动作前面挂一个"因为"，后面接一个"于是"
- **微动作优先于大动作**：指尖颤抖、咽口水、脚尖转向——微动作泄露心理，大动作只是位移
- 表情写变化过程不写状态：不是"她很伤心"，是"眼底落寞慢慢泛红，嘴角轻轻下垂"（大佬模板原文）
- 摄影机跟着动机走：她看向哪 → 镜头去哪；他想藏什么 → 镜头逼近什么

## 三、动作的"决定性一秒"

每镜挑一个**下一秒就消失**的瞬间作为快门点：
- 玻璃脱手悬空的一瞬 / 回头到一半 / 话说到一半被声音打断
- 写法：`the exact moment the glass leaves her fingers, still rotating in the air`
- 这就是静帧 skill 三问里的"为什么偏偏在这一秒"在分镜中的落点

## 四、镜头衔接的动机（连镜不跳戏）

相邻两镜之间也要有因果，不只是时间相邻：
| 接法 | 因果 | 例子 |
|---|---|---|
| 视线接 | 他看 → 切到他看的 | 镜4 她望向街口 → 镜5 街口空无一人 |
| 声音接 | 听到 → 切到声源 | 镜6 玻璃碎裂声起 → 镜7 地面碎玻璃特写 |
| 动作接 match-on-action | 起手 → 完成 | 镜8 抬手推门（起） → 镜9 门内视角门被推开（完成） |
| 反应接 | 事件 → 脸上 | 镜10 霓虹熄灭 → 镜11 她脸上光消失的表情 |

## 五、台词的动机

台词不是信息播报，是**动作的一种**（用嘴做的动作）：
- 每句台词回答：他为什么说这句、想改变什么、对方怎么接
- 对话用正反打时，切的点是**反应**不是台词——拍听的人比拍说的人更有戏
- 台词字数受镜头时长约束（见 SKILL.md 第四部分），说不完就拆镜，拆在"反应"处
