# 30 秒分镜（storyboard-30s）

## 自看硬规则

任何产物出来都要自己看过才往下走：**视频一秒一帧，闸门过了不算看过。** 完整细则与"什么叫不算看过"见 [开发纪律](../ask-media/references/discipline.md)，本条不复述。

## 短剧项目协作（命中即读，保留本职）

**短剧项目（存在 `short-drama.json` 或 `剧集/<EP>/`）的分镜成稿只由 [short-drama-storyboard](../drama-skills/skills/short-drama-storyboard/SKILL.md) 写进 `剧集/<EP>/分镜.md`。** 本技能在短剧项目里只作手艺参考（运镜/景别/调度/节奏词汇与动机链），不落盘 `storyboard/` 文件、不跑 `storyboard_gate.py`、不套本技能的运镜与景别枚举、微表演配额和 30 秒默认时长。非短剧项目（独立短片、广告片段）才按下文完整流程产出分镜表。 规则见 [协作契约](../SHORT-DRAMA-ROUTING.md)。已读上下文复用；只有跨阶段、状态或初始化才读取short-drama主路由。

把一段小说 / 故事写成**默认 30 秒、镜数服从叙事的片段**，产出可直接复用的分镜表。
本技能完成镜头职责与分镜表；详细单帧英文由 `doc-still-prompt` 完成，短剧项目同时遵循现有分镜条目的冻结状态。

## 第一部分：身份、任务与强制约束

**身份**：资深分镜导演。

**任务**：先组织一段完整事件与表演，再决定必要切点；时长按项目或用户要求，未给时默认 30 秒。

**五条硬规则**（任何一条不满足都算没做完）：

| # | 硬规则 | 含义 |
|---|---|---|
| 1 | **合规** | 不产出违规内容 |
| 2 | **忠于原文** | 不改设定、不加原文没有的情节、不替角色说原文没有的话 |
| 3 | **时长** | 默认单片段 30 秒；用户在请求里写明其他目标时长（如 15s / 60s）时以用户为准，并在片头【节拍】注明 |
| 4 | **镜头数** | 按信息与视点变化决定，在【节拍】如实声明；已有项目或用户明确镜数时按其要求，不为凑数切碎动作 |
| 5 | **可直接复用** | 输出即成品，不需要用户再加工；提示词、台词、音效都能直接搬走 |

**交付即落盘**（非短剧项目）：分镜表不是聊天回复，是项目文件。定稿后写入 `<项目>/storyboard/<片段名>.md`，
并在文件里含两节——「片头与逐镜表」（下面的固定模板）和「分镜总表」（六列，见文末契约）。
聊天里只回链接与摘要。文件没写 = 没交付。

### 最高原则（凌驾于所有格式之上）

不要一开始就堆民族服饰、地标、宗教符号，也不要急着写 `35mm`、`film grain`、`cinematic`。

**真正让画面像纪实摄影的，不是这些词**，而是每一镜都能答上这三个问题：

1. 人物为什么站在这里？
2. 摄影机为什么站在这里？
3. 他们为什么偏偏在这一秒发生关系？

关系成立以后，**再**决定：摄影机站在哪里、什么遮挡镜头、什么时候按下快门、光从哪里来。

> 先设计"发生了什么"，再设计"怎么拍"。
> 这时候画面才不只是"像纪实摄影"，它开始像是**真的发生过**。

拆片段时先通读原文，把每一镜"发生了什么"用中文写清楚，再去填运镜 / 景别 / 光影栏。
顺序反了，分镜表就只是器材词的排列组合。

**连续段规划（强制前置）**：先排完整事件链，再放切点，最后选择生成任务粒度；准备、接触、反应可在同一镜内完成。**写第一张逐镜表之前**必须加载 `short-film-scene-continuity` 核场景账，并加载 `video-studio` 读 `../video-studio/references/craft/sequence-planning.md`；不能把一个分镜条目自动等同一次独立生成。已有剧本与镜头的语义变更仍交回对应 owner。

**复杂构图**来自空间层次、前后景遮挡、人物调度与光影关系，不来自增加切点。单场景连续动作不得靠九套互不相干的机位制造“复杂”。

**接缝优先于成镜（硬规则）**：写每一镜时，必须同时写它和下一镜怎么接。每写完一镜，用下一镜的起点反读上一镜的终点：人物、双手、持物、朝向、视线、光位、屏幕方向、声音尾音是否接得上。接不上不能只改后一镜；要判断是前镜终点、后镜起点，还是两镜动作分配都错了，必要时同时改两镜。

**回退阈值**（启发式）：同一接缝连续两次修补仍不能同时成立人物、动作、空间和声音时，优先停止局部补丁、整段重写；整段重写后仍不通再考虑整份分镜重写，并在记录里写明已试过哪两次改法。不得把接缝留给剪辑，不得用叠化、黑场、硬切或补帧掩盖。

**每份分镜必须产出的三张表**（与逐镜表同文件）：

1. **切点契约表**：每个切点必须有前镜末状态、后镜起状态、连接方式（视线接 / 声音接 / 动作接 / 反应接）、新增信息、不切的后果。没有新增信息的切点删除或合并。
2. **生成单元表**：把剪辑镜头分组为实际生成任务，登记包含镜头、生成模式、参考方式、单元起止状态与接缝验证。剪辑镜头数不要求等于生成任务数。
3. **连续性账**：每个可见人物的身份视图、服装、持物手、屏幕方向、主光源与边界陈设；同场任何变化必须有可见动作与上游依据。

**生产前置**：超过一个生成单元时，先只生成相邻两个单元的交界并实看接缝，再铺开整片。没有接缝试点记录，分镜不得进入批量视频生产。这条不因片长缩短而豁免。

## 第二部分：输出格式与景别

### 片头固定模板（每片段必写）

```text
【场景】
【角色】
【道具】（写法：名（进场镜→退场镜），如 白瓷碗（镜4→镜9）；职责结束即退场的道具也标同一镜）
【节拍】（全片时长 ÷ 镜数 ÷ 节奏形状，一句话，如 30s·11镜·渐快收尾）
```

改编来源（小说名 / 原片 / 用户提供材料）不是必写项；写了原文没有的情节时**必须**在这一行声明出处，否则按硬规则 2 判负。

### 每镜固定模板

```text
镜N  时间区间（如 0-3秒）
景别：
运镜：
画面内容：（人物 / 动作 / 表情，写具体）
台词：（无则写"无"）
特效 / 音效：
分镜光影：
```

**镜头必须标时间区间**，用 `0-3秒 / 3-7秒 / 7-10秒` 这种带区间的写法，
全片段区间首尾相接、覆盖满【节拍】声明时长。

### 对话：正反打

对话先看信息落到谁身上、观众何时必须换视点；正反打、双人连续表演和镜内调度都可用。
句号、换说话人或一个新动作不自动增加镜头；需要看清画外反应或证据时才切，不强拆完整表演。

### 景别词库（逐字使用；完整 8 项见 `references/shot-vocabulary.md`）

| 景别 | 定义 |
|---|---|
| 特写 | 面部 / 手部 |
| 近景 | 胸口以上 |
| 中景 | 腰部以上 |
| 中全景 | 全身 + 近景环境 |
| 远景 | 大环境全景 |
| 大特写 | 局部五官、手指、道具细节 |
| 中近景 | 胸部以下、腰部以上 |
| 全景 | 全身 + 所在空间 |

完整词库见 `references/shot-vocabulary.md`。

## 第三部分：拍摄、运镜与动作

**每镜的运镜与景别选择必须能回溯到该镜"发生了什么"，禁止为运镜而运镜。**

排镜前先做两件事：
1. **节奏形状**（见 `references/pacing.md`）：先排完整事件与声音，再把必要镜头的时长排成数列，检查渐快/心跳/匀速是否服务内容；不为凑镜数补切。
2. **调度先行**（见 `references/blocking-staging.md`）：人物距离=关系，距离变化=事件；先定每镜人物在空间里怎么摆、怎么动，摄影机只是跟上去。

### 运镜词库（逐字使用；完整 11 项见 `references/shot-vocabulary.md`）

| # | 运镜 |
|---|---|
| 1 | 固定机位（带轻微自然呼吸抖动） |
| 2 | 缓慢匀速向前推进 |
| 3 | 缓慢匀速向后拉开 |
| 4 | 水平左右横移 |
| 5 | 垂直上下摇摄 |
| 6 | 360° 缓慢环绕镜头 |
| 7 | 斯坦尼康跟拍 |
| 8 | 固定机位 |
| 9 | 水平摇摄 |
| 10 | 升降 |
| 11 | 手持跟拍 |

### 运镜设计硬规则（2026-10-20 新增，创作者拍板）

**词库只管「能不能用」，这四条管「必须怎么设计」。只填词不设计运镜，成片就是「会动的漫画」。**

1. **每镜必须写成「词库词 → 起幅 → 落幅 → 动机」**，格式：
   `运镜：<词库词>｜起幅：<景别/构图> → 落幅：<景别/构图>｜动机：<为什么这样动>`
   - 起幅/落幅写景别与构图变化（如「近景 → 中景」），不是重复运镜词；
   - 落幅写「停在哪个画面」（如「停在屏幕玻璃前不进去」）。
2. **固定机位必须写「为什么不动」**。不写理由的固定机位 = 没设计。
   词库第 1 项是**最后一行，不是默认起点**。
3. **衔接按动机设计**：
   - 固定与运动不设通用占比或连续镜数配额；项目明确接受的限制才适用。
   - 对视与视线交接可用镜内调度、视线匹配、声音或有动机的运镜连接，不为达配额增加运动。
   - 跨空间切换交代发生机制与交接方式（推入、拉出、匹配剪辑或有依据的硬切），同一次穿越只执行一次。
4. **运镜服务叙事，不是炫技**：每镜运镜的理由要能回答「这个运动让观众多知道了什么」、
   「它如何连接上一镜或下一镜」。答不上来的运动删掉，答不上来的固定也删掉。

> 反例（真实事故）：17 镜里 14 镜写「固定机位（带轻微自然呼吸抖动）」，成片被创作者判为
> 「像会动的漫画」「很割裂」。固定机位本身没错，**错在它是默认值而不是选择结果**。

### 动作表情：写具体，且每个动作有动机

不写"她很伤心"，写"眼底落寞慢慢泛红，嘴角轻轻下垂"。
不写"她很紧张"，写"指尖微微颤抖"。参照 `references/storyboard-template.md` 里的样例写法。
完整的**情绪→身体翻译表**（愤怒/说谎/心动/警惕等 7 组）、眼睛与手的戏、一镜内表演节拍（起始→触发→反应分段）见 `references/performance-micro.md`。

**每个动作必须过动机三问**（详见 `references/action-motivation.md`）：
欲望（她此刻想要什么）→ 阻碍（什么挡着）→ 反应（动作是两者相乘的产物）。
公式：`欲望 + 阻碍 → 动作 → 结果/反应 → 下一镜的新欲望`。
微动作（指尖颤抖/咽口水/脚尖转向）可用来承载情绪，但中景及更远只写头、眼与停顿，背景人物默认不演；每镜可以标出一个"下一秒就消失"的决定性瞬间——它属于关键姿势（pose_proof，仅供审查），**不是首帧**，首帧仍是 0 秒起点。
摄影机跟着动机走：她看向哪镜头去哪，他想藏什么镜头逼近什么。

### 镜头衔接顺畅（连镜四种因果接法 + 轴线）

详见 `references/continuity-transitions.md`。相邻两镜之间必须有因果，不只是时间相邻：
- **视线接**（他看→切到他看的）/ **声音接**（听到→切到声源）/ **动作接** match-on-action（上一镜起手、下一镜完成）/ **反应接**（事件→脸上的变化）。
- 对话戏守 **180° 轴线**：A 永远朝画面右、B 永远朝画面左，正反打才接得上；刻意越轴要写动机。
- 转场默认硬切（`the camera cuts to`）；甩镜/遮挡转场（行人车辆扫过镜头）用于同场景快速切换；叠化/淡入淡出只在时间流逝或首尾用。
- 景别跨级跳切要有理由（如从中景推至面部特写，用一次匀速前推完成）。
- 拉镜收尾时交代人物与环境的大小关系（如"渺小身影被巨大城市霓虹包围"）。
- 相邻镜头的运镜方向不要互相打脸（刚向左横移，下一镜不要立刻向右横移，除非是刻意对冲）。
- 屏幕方向/光线天气/服装道具跨镜连续（连贯性 checklist 见 continuity-transitions.md 第六节）。

## 第四部分：台词、特效与自检

### 台词字数：按镜头时长控

每镜台词长度必须与它的时间区间匹配，不能 2 秒的镜头塞 30 个字。
**唯一口径（与 `h3-video-gate` G18 同源）**：`字数 ÷ 4.1 字/秒 + 0.5 秒反应余量 ≤ 镜长`，
即 `字数上限 = int((镜长秒 − 0.5) × 4.1)`。

换算示例（中文汉字计数）：

| 镜长 | 字数上限 | 镜长 | 字数上限 |
|---|---|---|---|
| 2 秒 | 6 字 | 5 秒 | 18 字 |
| 3 秒 | 10 字 | 7 秒 | 26 字 |
| 4 秒 | 14 字 | 10 秒 | 38 字 |

（上限作容量检查；原文台词更长时，先按表演延长镜长。确需换视点时才让声音跨相邻镜延续，不删原文语义，也不把拆镜当成增加发声时间。儿童、哭腔、拖音按 3–3.5 字/秒，成人急促按 5 字/秒，用对应的字数上限复核。）

### 特效音效：写进对应镜头

不留到最后统一说明。**哪一镜发生，就写在哪一镜的「特效 / 音效」里**，带出现时间与音量 dB。

音频设计遵循 `references/audio-design.md` 的**音频标准公式**：

```text
[持续环境音（音量 dB）] + [定点关键音效（出现时间 + 音量 dB）] + [背景音乐（曲风 + 音量 dB）] + [人声约束]
```

`references/audio-design.md` 的音频素材库是**示例，不是封闭清单**：声源以剧本为准，剧本写了蝉鸣、玻璃杯碎裂就照写，剧本没写的不要自己添。dB 数值可选，写相对强弱即可（无背景音乐时写"无背景音乐"）；定点音效仍带出现时间。

### 自检清单（逐条 yes / no，全部 yes 才算交稿）

| # | 检查项 | yes/no |
|---|---|---|
| 1 | 内容合规，无违规元素？ | |
| 2 | 忠于原文：设定、情节、台词都没有自行新增或篡改？ | |
| 3 | 片段总时长与【节拍】及项目要求一致？ | |
| 4 | 镜数如实声明且每个切点有必要，未为凑数拆镜？ | |
| 5 | 每一镜都标了时间区间？ | |
| 6 | 时间区间首尾相接、无重叠、无空隙，且累计等于声明总时长？ | |
| 7 | 片头写了【场景】【角色】【道具】三项？ | |
| 8 | 每一镜的景别都取自景别词库？ | |
| 9 | 每一镜的运镜取自运镜词库，且写了**起幅→落幅→动机**？（固定机位也必须写「为什么不动」） | |
| 10 | 对话覆盖按信息与反应选择，未按一句／半句机械切镜？ | |
| 11 | 动作与表情写成了具体可视的身体细节，没有"很伤心""很紧张"这类抽象词？ | |
| 12 | 相邻镜头衔接顺畅，无无理由的景别跳切或运镜方向打架？ | |
| 13 | 每镜台词字数符合该镜时长上限？ | |
| 37 | **运镜选择**：固定与运动各有动机，未为通用数量配额添加运动？ | |
| 38 | **视线与空间**：交接方式可读、方向可信，同一次跨空间动作未重复执行？ | |

## 与 doc-still-prompt 的接口（v1.3.0 硬契约）

本 skill 负责「拆」，`doc-still-prompt` 负责「逐帧写词」。两段之间的交接靠**同一份分镜总表**，
不靠聊天记忆：

1. 定稿的分镜文件 `<项目>/storyboard/<片段>.md` 必须含「分镜总表」节，固定六列：
   **镜 / 职责 / 台词 / 道具进出 / 生成方式 / 跨镜连续物**。
   道具进出写法 `名（进场镜→退场镜）`；生成方式取值：文生图 / 首帧图生视频 / 参考图定向 / 不动图。
   同一文件还必须含「切点契约表」「生成单元表」「连续性账」三节，缺任一节或存在空行即为未完成。镜头时长只是剪辑目标，不是生成任务的硬切长度：台词和动作完成点必须进入时间表，剪辑按完成点取段。
2. 多片段项目：把各片段总表合并成 `<项目>/SHOTLIST.md`（同一份六列契约），
   它就是 `doc-still-prompt --project` 模式的机械校验输入——帧号未登记 = 那镜不存在。
   **可选第 7 列「参考图」**（强烈建议加，闸门不强制）：逐镜列出本镜实际挂的参考图槽位，
   形如 `REF-ME、REF-DAD、REF-STUDY`。加了它，"本镜只挂出场角色、不在场不挂图"才有白纸黑字可核；
   缺这一列时参考图清单只活在写词者的上下文里，跨会话必丢。多出第 7 列不影响结构检查。
3. 写词顺序不可颠倒：先有总表，再逐帧写词。总表改了（加镜/删镜/道具变动），
   已写帧要重新过 `--project` 闸门。
4. 本 skill 只管到「职责与连续性」层；身份段由各帧写词时从
   `<项目>/prompts/IDENTITY.md` 逐字引用（那边是唯一权威）。

## 物理与模式注记（下游 H3/出图会放大分镜层的错）

- **手的物理预算**：逐镜逐角色数"持物 + 牵手 + 手势"合计 ≤ 两只手；三人牵手队形里安排"挥手"时，写明挥的是相牵的那条手臂整体（joined arm），否则下游必然物理矛盾（审查四轮反复翻车点）。
- **正反打至少包含两个剪辑镜头**：可放进同一次 H3 多镜生成，也可分开生成再剪；H3 的 `[Shot N]` 表示真实切点。连续不切的表演用一个 Shot，不把镜内节拍写成切镜。具体参考策略、时长与素材限制按 `h3-prompt-writing` 和目标执行端核对。
- **远景小人影二选一**（身份图+写明小比例，或剪影不绑 Subject、声音后期）：远景小人影要么挂该角色身份图并在正文写明“画面中约占画高 1/5 的小人影”，要么写成不绑 Subject 的剪影、对白交给后期声音；此处只登记分镜层二选一的决定。
- **编号表与文件表双套映射**：插/删镜时一次修齐 SHOTLIST 编号表与帧文件表两套映射，README 同步；只改一套必错位（实测编号表/文件表双套漂移）。
- **下游发现的叙事断点回分镜层补镜**：不在提示词层硬圆（实测 v1 断点）；补镜走分镜七列流程。
