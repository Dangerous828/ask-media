# 3D 静帧：身份与参考图排障

用于 3D 动画/Q 版静帧的可见身份漂移、参考职责冲突，或身份与构图互相回退。完整身份以项目权威库为准；本页不用于真人、2D 或视频提示词，也不把视频参考上限带入静帧任务。

## 1. 按本帧可见性选锚点

常规近景可引用完整身份；远景、背影、遮挡或只露手时，选用已登记/已接受的可见视角锚点。不能为了照抄脸眼细节而更改分镜，也不能把参考中的正面、站姿或中性表情自动变成本帧事实。

- 只露手：核对可见手型、肤色、饰物和袖口，不补瞳色或正脸。
- 远景背影：核对轮廓、衣色、帽包等可见识别点，不为“完整身份”改机位。
- 缺必要视角：登记真实缺口；不靠加词宣称不可见事实已核验。
- 不改变权威发色、衣色、比例或道具来迎合通用 Q 版外观。

多人及画中画按 doc-still 的 [多人场面规则](../../doc-still-prompt/references/multi-character-scenes.md) 分清实例与区域。独立项目沿用其身份库 `identity` / `view` 等既有登记方式；正式条目已有其它布局时人工核对，不为本页重建三件套。

## 2. 实际参考与职责对账

资产库可按项目需要准备三视图、表情或同框尺度参照；实际提交只选本帧所需，没有适用于所有角色和镜头的最少三板数量。整板用于需要多视向信息时，单视图用于只需一个视角时；二者都不是成功保证。

1. 核对每张实际上传图的内容、职责和次序；文字职责说明不等于区域硬绑定，多视整板也不必然产生多身体。
2. 检查同板视图是否同一 Look，避免正面戴帽、侧背无帽等矛盾。
3. 裁单人单视图时保留本帧需要的衣饰与轮廓；裁图是派生物，记录真实来源和裁后内容，正文描述实际喂入的这张图。
4. 需要媒体结论时由 `short-drama-review` 查看实际参考/派生物；文本阶段只核对路径、职责与计划，不宣称已验收。

### 多物参考带入了本镜不要的对象

2026-10-24 的 Qwen Image 2.1 Turbo 实测条件为 8 步、CFG 1.0、1024×576，4–5 张实际参考按长边 768/JPEG q80 提交。完整产品参考同时含刀、砧板、两番茄和价格牌；即使文字限制职责，结果仍分别出现多一张价格牌、四个番茄或两块砧板合并。这是该组合的观察，不断言所有多物参考必然复制。

命中此类问题时，把“外观身份”与“本镜数量、位置、持有状态”分别核对。可测试的修法是裁成单个必要物件的外观参考，或在不需要该物件的近景移除它；正文正向写清数量、区域、承托和接触。两块相似砧板需同时写明各自用途、表面内容和可见间隔。裁后核对没有残留不该借用的牌、食材或整组布置，并同步实际 REF 与职责；减少参考或文字检查通过都不等于画面已修好。

## 3. 身份与构图互相回退

历史案例中，只保身份会把远景拉近，只保距离又会丢身份。命中时分别保留可见身份锚点与距离/尺度事实，不用否定禁令堆叠，也不牺牲本镜景别。若可见信息不足，明确本镜只能锁哪些身份特征。

## 4. 验收与经验边界

已生成媒体由 `short-drama-review` 唯一负责验收；需要时按原分辨率查看本帧真正可见且项目要求锁定的特征。记录可见、不可见和无证据，是否阻断取决于本镜职责与已接受约束。尚未生成或没有原图时，本页媒体核对为 `NA：无图可验`，不得要求写词阶段先完成看图。

历史条件：2026-10-16 的 Qwen 垫图案例中，三类参照比两张参考更稳定地保住部分身份细节，这是该案例的观察。2026-10-23 的固定 seed ABC 参考替换又显示：统一整板可以修好一个镜头，也可以留下或加剧复制。不能由此规定所有镜头至少三板、所有整板禁用或单视图必成功；新通道与新组合需重新验证。

## 回读（只答本帧适用项）

| 检查项 | 结论与 NA 条件 |
|---|---|
| 可见身份锚点与权威库一致吗？ | 无角色/无需识别身份时 NA；不可见特征写原因。 |
| 参考内容、数量与职责和本帧相符吗？ | 无垫图时 NA；无多物复制故障时不强制裁图。 |
| 身份与距离是否各自保持？ | 无远景或没有互相回退时 NA。 |
| 媒体是否已由 review 实看验收？ | 未生成/无图时 NA；本技能不填写媒体通过结论。 |
