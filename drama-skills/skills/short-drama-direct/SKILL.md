# 短剧导演中间层

把剧本事实转成可持久继承的 `剧集/<EP>/导演.md`。本阶段拥有观看方向、逐场戏剧行动、
空间调度、观众知情策略和镜头计划；不拥有剧情事实、资产身份、正式镜头时长或提示词正文。

## 语料与剪辑准备的继承

写观看方案前按本场需求检索并完整读候选 template。采纳时记录条款、成立与失败条件、因果链和递进、注意与表演归属、不中断证明段、相对节奏、声画因果及实现责任；分派至已有 SHOT。模板补槽不得改剧情，机制条款不冒充剧本 N-ID。完整分工与就绪判据见 语料机制与剪辑准备（`short-drama` 技能 `../short-drama/references/mechanism-preparation.md`）。新增散文条件由人工回读，现有检查器不自动核验。

## Quick Start

```text
用 $short-drama-direct 给 EP001 写导演方案，再交给 $short-drama-storyboard 做正式分镜
```

新初始化的项目默认 `format.director_contract = director-v1`。旧项目只有在本文件存在时才启用；
用户要求升级旧项目时，先按当前剧本和已接受分镜补写本文件，再重审受影响镜头，不静默改剧情。

## 先做哪一步

1. 读当前《剧本.md》及必要的《视觉设定.md》。有已接受《分镜.md》时只把它当现有决定或待修订对象，
   不把它的构图反向当成剧本事实。
2. 写整集观看方向：观众最终获得什么变化，视觉/声音策略如何服务它。参考作品只写学什么和不学什么，
   不复制人物、镜头或故事。具体推导见 [导演手艺](references/director-craft.md)，规则分级见
   [阶段契约](references/stage-contract.md)。
    依据三级、冲突裁决、记录值与设计值、写作 QC 的单一真相源是
    逐镜证据台账（`../short-drama/references/observation-ledger.md`）；写《导演.md》时按它给每项事实标
    `源事实`／`派生判断`／`未定`，本场末尾写 `### QC 备注`，本技能不另写一套规则。
3. 每场先回答人物目标、阻力、可见策略、转折与承受者，再决定观众何时知道什么、站在谁一边。
4. 把场景当正在运行的空间排演：出入口、固定锚点、人物位置/朝向/视线、双手与持物、光源、
   可走路径和动作接触。不能用“保持连续”替代这些事实。
   本层只定**叙事必需的空间事实与关系**（谁在哪一侧、谁挡住谁、光从哪个方向来、能不能走过去），
   不写机位高度、焦段、景别数值——那些属于场记账，见下文「与场记账的分工」。
   双手与持物也只写叙事必需的那几项（带 N-ID）；逐镜的手位归场记卡。导演这里顺手多写的手位若与场记卡不同，
   不是 N 项的以场记为准——两边各写一遍，下游就会各取一边（实例：导演写"左手先撑下巴"，场记卡写"左手平放桌沿"，视频正文里变成"左腕全程贴着下巴"）。
   《观看方案》写"连续保持"就等于场记里同一机位同一张卡；写"切镜"就写出切点落在哪一拍，场记据此开卡。
   切点还要写**接法**：同场景或前后相近的场景，装不进同一容器时用转场卡（A 末帧 + B 首帧 → 中间段）；换了场景、换了光位或两帧位移一段走不完时，硬切并指定一个剪辑手段（声音桥、黑场等），不写裸硬切。判据四项（同场景、同光位、同集合、一段连续运动走得完）与取值来源见 `short-drama-video-prompts` 技能的 `../short-drama-video-prompts/references/seam-transition.md` §0.4，导演只做判断，数值取自场记。
5. 写镜头计划：每镜稳定的 `SHOT-...`、戏剧职责、信息/反应/空间变化、入场和离场状态。
   镜头计划是正式分镜的输入，不是按句号预切镜；后续合并或拆分时保留可追溯身份。
6. 按 [注意力与回读](references/attention-and-revision.md) 分场执行并回读实际成品。最后从成稿镜头反向
   检查剧本覆盖和离场状态，不生成另一份覆盖报告代替修正。

## 《导演.md》格式

一级标题含集号。先写整集方向，再逐场使用 `## <场景 ID> · <导演命题>`。每场字段完整格式见
[导演文档模板](assets/director-template.md)：

- `戏剧行动`：谁想达成什么；阻力是什么；用哪些可见策略； 策略失败时如何调整。
- `转折与承受`：哪个行动/信息改变局面；谁接收后果；怎样可见处理；离场时什么不同。
- `观众知情`：观众与谁同知，何时多知/少知；揭示或扣住哪个事实，靠什么载体。
- `观看方案`：为何连续保持或切镜；开场/收束关系；方案改变了什么观看体验。
- `空间与声音`：空间锚点、人物/道具/光源、主要声源与跨场交接；不重复整份设定集。
- `镜头计划`：每个 `SHOT-...` 的目的、来源事实、入场状态、主要变化、离场状态与交接。

关键场次若比较候选方案，只比较真正改变知情时机、观众立场、表演所有权或空间压力的方向；
选择结果直接写进本场字段，不保留平行方案库。

## 不是写作配额

普通场可以简短，仍须回答行动、后果、知情和空间。不能为了表格完整发明新冲突、眼泪、运动或音效。
信息变化而物理状态不变也能成立；有意静止、克制反应和空场都是合法选择。

## 与场记账的分工

整部戏另有一份 `设定集/场记.md`（场记账，一部戏一本，由 `$short-drama` 的 `../short-drama/references/continuity-breakdown.md`
定义）。它在**本技能之后**执行，把本层的空间排演落成可引用的数值。两者边界如下：

| 项目 | 本技能（导演） | 场记账 |
|---|---|---|
| 人物在哪一侧、谁挡住谁、谁看得见谁 | **定** | 引用，落成站位与轴线侧 |
| 光从哪个方向来、谁被照亮 | **定** | 引用，落成光位账的方位、色温、强度 |
| 人物为什么这样站、这场戏的空间压力 | **定** | 不改 |
| 机位位置、机位高度、焦段、景别、角度数值 | 不写 | **定** |
| 逐镜站位数值（"窗左一米"）、持物左右手、道具状态 | 不写 | **定** |
| 与上一镜是连续还是间隔、镜内起止状态 | 只写入场/离场状态 | **定**成逐镜时间关系 |

**冲突仲裁**：两边对同一空间事实说法不一致时，以本技能的**叙事必需**为准，回改场记账的数值；
若本技能只写了"允许偏差"级别的布局细节，而场记账给出了更具体且不违背叙事的值，则以场记账为准。
任何一方改动后，先改上游文档再改下游，不在提示词里二选一。

本层不需要预先知道场记账的 `CARD-...` 编号；场记账按本技能的场次排演建卡，一卡对一镜（`SHOT-...`）。
本技能的 `空间与声音` 是场记账建的依据，两者必须能逐场对上：场记账的场景空间账，其锚点与光位应能追溯到本层对应场次的排演。

## 可生成性边界

导演方案最终由生成模型执行，而当前视频模型无法精确兑现物件计数、厘米级尺寸、左右手指定、多人同时
复杂接触或道具逐帧位置。每场排演把空间事实分成两类，写在 `空间与声音` 里：

- **叙事必需**：观众看不到就会误读剧情的事实（谁拿着关键物、谁挡住谁、一样东西是否出现过）。
  每场尽量只留两三项，下游必须兑现，兑现不了就改机位、拆镜或交给剪辑。
- **允许偏差**：只为合理或好看而写的布局细节（砧板几厘米、卡片在左还是右、道具摆放角度）。下游按提示词
  尽力写，但成片偏了不判失败、不返工。

以下几类**默认叙事必需**，不能降为允许偏差（创作者以往都因此判废过）：在场人物的人数与身份、每人手的数量、
同场唯一固定物的数量（门、窗、电视、唯一的一把刀）、剧本点名的关键道具是否在场、背景是否违背已确认的
地点设定。它们兑现不了时按镜头改法处理（换机位、拆镜、交剪辑），而不是放行。

一项事实需要合成参考图、手工拼贴或叠加更多约束才能“逼”模型做到时，说明它超出了模型能力，应改成
允许偏差、换一种可见表达，或移到剪辑与后期（插入镜、字幕、遮挡），而不是让生产环节去造参考图。
画面质感永远优先于布局精度：为了布局正确而牺牲画风，是导演层要避免的结果。

本阶段不预写每镜秒数、reads 时间窗、关键姿势或首尾帧：它们依赖正式镜头边界，由分镜阶段决定。
也不在本文档写提示词、英文画面正文、参考图路径或生产参数。

## 完成

当前《剧本.md》的每个场景都有导演条目，或明确记录不拍的理由；每场有可见行动/信息变化、后果、
观看与空间决定；计划镜头覆盖该场制作内容，且入场/离场状态能衔接。将文档交给分镜 owner，
不自动开始分镜、图片或视频生产。

安装维护时运行：

```bash
python3 scripts/selftest.py
```
