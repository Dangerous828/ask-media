# 注意力预算与回读

导演层解决的是依赖与记忆，不是给模型更多规则。上下文越长、重复字段越多，关键事实越容易输给格式、
术语和近期样例。因此每次只让当前决定占用注意力。

## 单场工作包

写 `导演.md` 的某一场时，只带：

1. 本场完整原文和必要的前后剧情因果；
2. 上一场的真实离场状态（没有则写开场事实）；
3. 本场实际出现的人物、地点、道具与光源条目；
4. 本场导演输出格式和项目已接受的观看方向。

不把全剧资产、其他场次的完整分镜、模型手册、风格库或历史版本一起塞入。需要查某项事实时按名称取回，
不让检索结果取代原文。当前场完成并回读后，再进入下一场。

## 决定只写一次

| 层 | 拥有的决定 | 下游只做什么 |
|---|---|---|
| 剧本 | 发生什么、谁说什么、不可改事实 | 引用准确场景与原文 |
| 导演 | 为什么这样观看、谁行动、知情与调度 | 继承镜头计划，不重新解释剧情 |
| 分镜 | 镜头时长、reads、起止状态、摄影和画面证明 | 把已选方案变成可制作镜头 |
| 关键帧 | 某一瞬间实际可见什么 | 只投影声明的 start/pose/end |
| 视频提示词 | 从起点到终点的运动与声音表达 | 编译，不重新导演 |

已有方案缺失时只回责任层补决定；不得在最终提示词里临时新增剧情、人物策略或镜头方案。

## 三种注意力失散及修复

- **事实丢失**：左右手、道具归属、人物数量、知情顺序出错。减少无关资料，逐场回读原文，把交接事实
  写进离场/入场状态；不要用“保持一致”代替。
- **导演漂移**：先写镜头术语再补剧情，或每场套同一模板。先写行动和观众变化，再选摄影；删掉不能改变
  观看体验的运镜和姿势。
- **末端塌缩**：前半完整，后半越来越概括。按场提交中间产物，逐场回读；不要让一次长回答同时承担全片
  导演、逐镜分镜、全部首帧和最终提示词。

## 实际成品回读

每个工作包交付前，只看刚写出的内容回答：

- 能否复述人物目标、阻力、行动、后果和离场变化？
- 观众何时知道每个关键事实，是否有可见/可听载体？
- 哪个空间事实保证动作可执行，谁的手与何物接触？
- 是否出现剧本没有的台词、人物、道具、表情或镜头结论？
- 下一场能否直接从离场状态继续，而不用重新猜站位和持物？

发现缺项就修原文，不添加“已检查”来证明检查过。分镜 owner 再做一次独立回读：只读正式分镜，
看能否还原导演方案；不能还原的，先修分镜而不是怪模型记性。

**尽量让未参与当前稿的 reviewer 做一次来源对照**。同一生成过程更擅长证明“我已经写过”，不擅长发现
“我写错了”。独立回读至少包含：原文事实与绝对化措辞、镜内观看顺序、跨镜空间、首帧状态、摄影机可见性。
它不是可省略的审美加选项；结构校验不能覆盖这些语义错误。

### 回读时必须点名的漂移

- **绝对化发明**：原文只有一个入口，不写成“唯一出入口”；只在当下未易手，不扩成永远“不能收回”。
- **接触关系改写**：证物在掌心不等于“已放下”；某人没接手不等于“没人碰过”。逐字核对持有者、接触面和接管者。
- **位移后旧状态残留**：前移半步之后，不能再写距离一点没变。保留不变的是柜台分隔，不是人物距离。
- **首帧内部矛盾**：同一帧不能既看不到牌，又有牌背露出的高光。把“不可见”同时用于高光、反射、轮廓和遮挡。
- **摄影目标不可见**：过肩拍一人，不能无依据地停在另一人的正脸反应上。若反应是重点，先安排它的可见载体。

## 模型能力与证据

Flash 级模型可以承担范围明确的文本 agent 工作，但“模型等级高”不是注意力证明。技能评估应使用
事实埋点、干扰叙述、长上下文和新鲜会话，分别检查来源保留、导演一致性、镜头交接与关键帧边界；
生成与审查分开。任何模型通过记录只适用于该输入、该版本、该次任务，不能外推成普遍能力。
