# 导演阶段契约

`short-drama-direct` 只拥有 `剧集/<EP>/导演.md`。它继承《剧本.md》的事实和《视觉设定.md》的
身份/地理/状态，不改写剧情、人物或资产，不写正式分镜正文与生成提示词。

## 规则

| ID | Class | Knowledge |
|---|---|---|
| DIR-01 | structural_invariant | 启用 director-v1 时，每个剧本场景都有导演条目或明确未拍理由；导演场次 ID 必须解析到《剧本.md》。 |
| DIR-02 | reviewed_invariant | 每场写清当场目标/阻力、可见行动或信息变化、后果承受与离场变化；不把文学情绪直接当表演方案。 |
| DIR-03 | reviewed_invariant | 观众知情时机、观看立场与揭示载体有明确决定；不得提前泄露来源要求扣住的事实，也不藏掉本镜必须交付的证据。 |
| DIR-04 | reviewed_invariant | 场景排演写出必要空间、人物、双手、持物、接触和光源事实；连续不是无事实的“保持一致”。 |
| DIR-05 | reviewed_invariant | 镜头计划有独立戏剧/观看职责、来源、入离场状态与交接；不按句号、说话人或固定秒数机械切镜。 |
| DIR-06 | structural_invariant | 正式 SHOT 能在导演镜头计划中解析；计划可以拆并，但来源事实与镜头身份必须可追溯。 |
| DIR-07 | reviewed_invariant | 当前决定按单场工作包形成并回读；下游只继承已选方向，不在提示词末端重新导演。 |
| DIR-08 | reviewed_invariant | 空间事实区分“叙事必需”与“允许偏差”；必需项只保留观众看不到就会误读的少数事实，且人数与身份、手的数量、同场唯一固定物数量、剧本点名的关键道具、地点设定默认属于必需，不能降为偏差。需要合成参考、拼贴或持续加约束才能兑现的布局，改为允许偏差、换可见表达或移交剪辑后期，不让画风为布局精度让路。 |

`director-v1` 是文件/项目级格式契约。机械校验只覆盖 DIR-01、DIR-06 与字段/引用存在性；
其他条目需要内容证据，不因表格齐全而自动通过。
