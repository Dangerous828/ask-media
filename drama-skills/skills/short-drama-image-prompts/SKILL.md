# 短剧资产图片提示词

把视觉事实写成可复用、可修改、可直接复制的角色板、场景板、道具板或状态图提示词，统一保存到
`剧集/<EP>/图片提示词.md`。每项用 `IMG-...` 标题，正文放在 `### 可复制提示词` 引用块。
`IMG-...` 只是该提示词条目的稳定 ID，不声明图片已生成或可用；实际图片只能来自创作者已提供的输入，或经确认后的生产结果。
本技能持有资产提示词文件、制版用途与参考边界；正文使用 `$doc-still-prompt` 的单帧成文方法，
直接回填当前IMG条目同一正文，不循环派单、不叠加独立四段稿或第二套身份库。

## 文字核对与媒体边界

逐项回读当前资产事实、实际可复制正文和参考范围。涉及真实图片像素的断言须打开相关原图核对；
未出图时完成文字核对并明确画面未验证。脚本通过或文件存在不代表媒体合格，生成物准入由
`$short-drama-review` 持有。本技能不为满足文字交付而生成图片，也不重复定义视频采样配额。

## 语料与剪辑准备的继承

按已接受的机制需求落实资产状态变体与指定瞬间，状态名取视觉设定、连续性值取场记；终态不能提前进起始帧。纯后期效果只准备其所需元素，不让生成预烘焙。完整分工与就绪判据见 语料机制与剪辑准备（`short-drama` 技能 `../short-drama/references/mechanism-preparation.md`）。新增散文条件由人工回读，现有检查器不自动核验。

## Quick Start

```text
用 $short-drama-image-prompts 为 EP001 已确定的人物、地点和道具写可直接复制的图片提示词
```

## 入口

有当前视觉设定即可直接开始；剧本只在提示词需要确认剧情状态时读取。Look Development 是可选分支。
先确认用途：身份板、造型/状态变体、地点板、道具板、组合 production sheet 或比较风格帧。
分镜需要生产尾帧时，可把已接受的「收尾关键帧提示词」落实为独立 `IMG-...` 状态图条目：
说明来源 SHOT 与终点，沿用视觉事实和参考范围，不重新设计动作。实际生成以该 IMG 条目为来源。

**场景板与状态图先读 `设定集/场记.md`。** 地点板的地面、主光源实体与方位、色温、强度、边界陈设、
出入口与允许观察的方向，取自场记账的场景空间账与光位账；同一地点在不同场次光态不同时，账本里是两组值，
图也分两张板，不在一张板里写两种光。道具板的状态取道具账的「初始状态／状态变化」。账本没有对应行时
按 `$short-drama` 的场记方法补充所缺来源事实，再回填本条目；不转交整份写词任务，也不自行改写已接受光态。

创作者可读说明跟随项目语言；可复制正文跟随 `short-drama.json#/format/prompt_language`。没有
`short-drama.json` 时正文默认
使用 `en`，并在同一任务中保持一致；不能从创作者说明语言推断提示词语言。

## 工作流

1. 锁定这一张图要固定的身份、状态、空间或比较变量。
2. 只读所需资产事实、视觉方向、负面约束和已提供参考图。
3. 依本图核心关系组织主体身份、当前变体、构图/视角、光色材质与背景的可见结果，
   使用 `$doc-still-prompt` 方法；不把填写顺序变成统一句式或材料清单。
   分镜来源的状态/端点图读取其显式 `composition / start / pose_proof / end`、时刻与七项镜头字段，
   在可复制引用块外保留 `- 镜头语言：...`，正文写可见取景和该瞬间状态；role、相位标签、
   后续运镜及排除项留说明层，不重设计机位。字段定义由 `$short-drama-storyboard` 的
   `../short-drama-storyboard/references/keyframe-camera-language.md` 持有。
4. 每张参考只控制身份、造型、地理、构图或风格中的明确部分，并在 `REF-...` 槽位里写出封闭词表中的 `用途`。
5. 检查身份与变体、文字政策、视角和光线是否冲突。
6. 用户要全部资产就完成全部，资产组只是内部批次。

## 提示词要求

- 开头先写对象和用途，不用风格词淹没身份。
- 只包含当前图能同时满足的要求；多视图/状态对照写清版面关系。
- 保留稳定识别锚点，变体只改允许变化的部分。
- 被《视觉设定.md》连续性锁点名的条目保留其可见身份/造型/状态锁面；未来持续范围与跨镜制作要求留说明层。
  锁面混入流程说明时先请上游owner区分可见事实与制作约束，不为逐字复制把两者塞进同一正文。
- 避免无验证作用的质量词堆砌。
- 可见文字、logo、水印、界面和字幕服从已接受政策；目标空白、图形或精确文字在正文表达，排除项另列。
- 正文可直接复制，不含占位符、流程说明、文件路径或 QA 结论。目标通道是否启用负向槽由执行阶段核实，
  不把no清单拼在正向正文末尾；真人/3D/2D不统一要求做旧、轮廓光、SSS或固定光比。

## 完成与投产

每个点名对象都有明确用途、可复制正文、参考边界和禁止项，且相互不矛盾，即完成。本次请求同时
修改图片提示词与分镜时，当轮刷新受影响镜头的「图片提示词项」，不另建对账产物。实际生成必须
转 `$short-drama-produce`，展示精确任务并取得显式确认；本技能不调用外部服务。
六份创作文档齐备后，可转 `$short-drama` 对跨文档结构做一次机械核对；内容质量仍由创作者审查。
