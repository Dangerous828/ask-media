# 入出点与镜序

## 入出点

在素材可用区间内，按信息、表演与节奏选入出点。
动作镜可以从动作已经开始的位置进入；反应、等待、揭示前停顿可以保留静止。
出点要让观众读到本镜的结果，并避开后续漂移或无意重复。

**动作连续的接缝优先在可衔接的动作阶段切，静止是否保留由镜头职责决定。** 不直接把每条生成素材的整段首尾当采用区间。做法：

- 跑 `../scripts/check_motion.py` 定位疑似起停，回看是否为无意停滞；仅剪不承担剧情作用的 padding。
- 动作接力时比较方向、阶段和速度；等待、反应与有意收势可保留静止。
- 剪完重测并连看；0.25 秒窗口和 3 倍运动比用作告警线索，不作跨景别、跨题材的通过门槛。
- 纯反应镜可以独立承担切点；声音桥依已接受的声画意图选用，不强制加声。

对白先确定实际发声区间，保留完整的字音与需要的停顿。生成的对白镜常晚开口、句后拖尾：
入点落在开口前约 0.25 秒，出点落在台词结束后留约 0.4 秒反应，整段不短于约 1.2 秒；
只按属于本句台词的发声定位，不被杂音拖长。
画面切换可以发生在一句台词中间，前提是音轨连续、说话人和叙事关系清楚。
不要为了换画面把原台词改成两句。内置 render 只做同步切段；分离画面和声音的剪法
需要先用外部剪辑工具完成，记录所用素材、声音区间和处理方式。

## 镜序与相邻关系

默认沿用分镜镜序。调整时检查动作因果、视线、空间关系、信息揭示和声音衔接。
相近景别与机位之间的切换容易暴露跳动，可比较改变角度、插入反应或有意跳切的效果。
是否保留由观众需要看到的信息决定，不把景别、机位和运动方向的组合设为禁令。

重复信息没有新增作用时可删；如果第二次增加反应、对照或重新解释，可以保留。
拆取两段素材也可以，但要确认动作、台词和情绪仍连贯。

## 切点与转场

动接动、声音桥和切到不同主体都可帮助衔接，按本场叙事选择。
若相邻镜头有生成漂移，先判断能否通过取舍或接镜校正解决；叠化等转场不能替代缺失的内容。

**叠化只用于同场景同侧的两个镜头。** 换场景、换光位（暖光卧室 → 电视冷光客厅）时叠化会在过渡帧里
让两套空间同时可见，读作掉帧而不是转场；这类接缝用硬切加声音桥。实测：换场加 6 帧叠化，
过渡帧里儿童房的地垫和客厅的沙发叠在一起，比不加更明显。

**叠化是把几何跳变摊到几帧，不是消除它。** 实测三帧叠化让跨镜像素差从 62 降到 20 一帧，
但 20 仍是同镜基线（约 1）的十几倍，观众照样能感到一顿。所以叠化只能当兜底，
不能当解法；真正的解法见 [接缝的量法](generated-footage.md#接缝的量法跨镜诊断) 的归因。

**转场卡（A + C + B）的剪法**：C 的首帧与 A 末帧、末帧与 B 首帧是同一画面，拼接时各去掉重复的一帧，其余整段保留；C 的音频不与两端连续，接缝按声音桥处理。C 是生成的中间段，不当作 A/B 的延长去裁。判据与生产见 `../../short-drama-video-prompts/references/seam-transition.md` §0.4。

**换场景或四项判据不成立的接缝**：剪辑单必须登记该接缝的剪辑手段（声音桥为默认，黑场/白场要有叙事动机，叠化只用于上一条限定的同场景同侧），不留裸硬切；手段只处理观感，补不出缺失的画面状态。

剧本的 `[转场]` 可能交代时空变化，也可能明确指定声音或画面效果，先读具体要求。
可通过新镜头中的环境信息、声音桥、黑场或其他已接受效果实现。
内置 render 只做硬切；需要声音桥或画面转场时使用外部工具，并记录处理参数。

## 时长与完成

删短某段后，只有其他段落确实需要更多表演或阅读时间才延长，不机械补齐总秒数。
目标时长若是创作参考，报告实际时长与差异；若是用户明确的交付限制，则继续调整或指出
缺少哪些素材才能满足，不能把它自行降为参考值。

下一轮修改应针对成片里可见或可听的问题，优先修复影响理解、连续性和交付要求的部分。
