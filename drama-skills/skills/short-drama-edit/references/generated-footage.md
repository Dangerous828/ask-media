# 生成素材的可用区间

## 先检查素材

逐段播放素材，记录实际时长、可用区间，以及不能使用的部分及原因。
重点检查起始等待、动作回弹、身份或道具漂移、异常提亮、重复表演和口型错位。
静止、暗部和停顿是否可用，取决于它们是否符合镜头职责。

需要比较画面变化时，可每 0.25–0.5 秒抽帧；在疑似缺陷附近加密到逐帧查看。
亮度测量可以辅助发现缓慢漂移，身份、动作和局部细节仍需看画面。

可用区间短于计划时长时：

- 已完整承载信息和表演，可以缩短。
- 其他素材能够承接缺失信息，可以换镜或调整镜序。
- 必要动作、台词或反应仍缺失，列出缺口并请求补素材。

不要只为避开画面缺陷而丢掉故事所需的信息。若画面不可用而对白完整，可评估保留声音、
另配画面的剪法；外部混音与画面处理须记录在剪辑单中。

## 把缺陷反馈给上游

描述缺陷发生的时间和画面，再给出希望保留的状态，例如「结尾高光过曝，需保持桌面纹理可辨」。
反馈只描述要的状态，不写“不要出现 X”：上游若是 H3，没有否定通道，被点名的 X 反而会被画出来（见 `short-drama-video-prompts` 的「H3 没有否定通道」）。
重出后比较同一处是否改善，不把某次生成结果当作所有模型的规律。

## 运动连续性（生成素材的头尾刹车）

生成模型产出的镜头普遍**在头尾留静止**：开头从关键帧「起步」，结尾「刹车」回到静止。
这是逐镜生成最容易被误判成"色彩不接"的问题——观众感到一顿一顿，第一反应会去查亮度，
但真正的元凶常常是切点两侧都没有动作可接。

**先量运动，再量色彩。** 用相邻帧差（帧均值绝对差）量每镜的运动量曲线：

```bash
# 逐帧运动量：输出相邻帧差序列，看头尾是否显著低于中段
ffmpeg -i shot.mp4 -vf "scale=64:112" -f rawvideo -pix_fmt gray - | python3 -c "
import sys, numpy as np
w,h=64,112
d=np.frombuffer(sys.stdin.buffer.read(),np.uint8)
fr=d[:len(d)//(w*h)*(w*h)].reshape(-1,w*h).astype(np.float32)
diff=np.abs(np.diff(fr,axis=0)).mean(axis=1)
n=len(diff)
print('head',diff[:7].mean(),'mid',diff[n//2-4:n//2+4].mean(),'tail',diff[-7:].mean())
"
```

定位告警：**头/中 < 0.5 或 尾/中 < 0.5 时回看疑似起步／刹车**。这是下述项目的经验比值，非通用质量门槛；有意等待、反应、自然收势、景别变化和低运动分母可能合法触发。

实测样本（12 镜 AI 生成 2D 平涂短剧，768×1344/24fps）：

| 镜 | 头/中 | 尾/中 | 结论 |
|---|---|---|---|
| S4 | 0.07 | 0.02 | 头尾几乎全静止，只有中段在动 |
| S11 | 0.25 | 0.06 | 同 |
| S6 | 1.76 | 0.06 | 尾部完全静止 |
| S12 | 0.24 | 0.14 | 头尾都弱 |
| S3 | 0.27 | 0.30 | 头尾都慢 |
| S1 | 1.04 | 0.41 | 只尾部刹车 |
| S5 | 1.89 | 0.13 | 只尾部刹车 |

**12 镜里 9 镜有严重头尾静止。**

再看成片切点两侧的运动量比（切点前后各 0.25s 窗口，跳过转场内部），11 个切点里 8 个超过 3 倍：

| 切点 | 前运动 | 后运动 | 比值 |
|---|---|---|---|
| S9→S10 | 0.11 | 12.59 | **114.4** |
| S11→S12 | 0.17 | 7.18 | **42.8** |
| S10→S11 | 5.99 | 1.07 | **0.18** |
| S4→S5 | 0.32 | 3.82 | 12.1 |
| S1→S2 | 0.09 | 1.12 | 11.9 |
| S6→S7 | 0.07 | 0.76 | 11.0 |

**这是本项目无意起停的量化线索**：切点前后运动幅度突变，与当次生硬反馈相符。
亮度色温校正无法替代动作衔接修复；其他项目仍须结合有意静止、景别变化与真实表演判断。

### 处理顺序（重要：先动这个，再动色彩）

1. **先回看并只剪不承担剧情作用的头尾停滞**。裁多少按真实动作与发声区间决定，保留完整反应、自然收势与有意静止。
2. **修剪后重测并连看**，确认无意起停改善、动作与声音仍完整；不要求所有镜头的头/中、尾/中都 ≥ 0.5。
3. 修剪会让成片变短，这是正常的；不要为了凑时长保留静止段。
4. 只有当运动已经接上、仍然觉得「跳」时，才去查亮度色温。

**顺序错了会白做。** 实测教训：先花力气做了逐镜校色 + 转场（亮度差从 94.7 压到 12.5，
指标全部达标），创作者看片结论是「感觉没有区别」——因为真正的病是运动接不上，
色彩修得再好也还是 PPT 感。

### 修剪解决不了的时候

若某镜整段都是慢速或静止（如纯反应镜），修剪无效时按镜职责判断：

- 反应镜的信息就是「静止」时保留它；可按已接受声音设计用声音桥连接，也可保留有意义的静默，不为比值达标添加声源。
- 剪辑节奏上把它与前后镜组成可理解的呼吸单元；独立反应镜可以承担切点，是否保留按信息与情绪落点判断。
- 确需动作时属于素材缺口，回生产阶段补，不要在剪辑里硬凑。

## 接缝的量法（跨镜诊断）

上一节量的是**单镜内**有没有动作；这一节量的是**跨镜**画面对不对得上。两件事都要量，但用途不同：
运动比找的是「切点两侧没东西可接」，像素差找的是「两侧根本不是同一个画面」。

**绝对像素差没有意义，必须跟同镜基线对照。** 同一镜内隔 0.125 秒的两帧本来就有运动（说话时头部微动、
镜头缓推），跨镜切点的差要和这个基线比才知道跳不跳。

量法：切点两侧各取一帧算逐通道均值绝对差；再在同一镜内取隔 3 帧（24fps 下 0.125 秒）的两帧算同样指标作基线。

实测样本（3D 动画短剧，1024×576/24fps，三镜独立生成，2026-11-11）：

| 量点 | 像素差均值 | 差 >40 的像素占比 |
|---|---|---|
| 镜1→镜2 跨镜 | 62.8 | 73.6% |
| 镜1 内 0.125s | 0.72 | 0.2% |
| 镜2→镜3 跨镜 | 101.8 | 90.9% |
| 镜2 内 0.125s | 0.64 | 0.1% |

**跨镜差是同镜基线的 50–150 倍。** 反过来说，跨镜差只有基线 3–5 倍时属于正常切点，不必修。
这是定位线索，不是质量门槛：动作幅度大的镜、故意跳切、闪回都可能有高差。

### 归因：切点没选对，还是机位本来就不一样

这个区分决定能不能只靠剪辑修。做法是把前一镜末帧和后一镜**逐帧**比，找最接近的那一帧：

- **最小值明显低于当前切点**（如 62 → 18）→ 切点没选对。往后挪到那个位置，纯剪辑能修。
- **最小值几乎不降**（如 62 → 62）→ 后一镜整段的机位、景别或背景就是另一套。切在任意一帧都一样，纯剪辑无解。

实测：某三镜短剧的镜1 末帧拿去比镜2 前 40 帧，最接近的是第 24 帧，差仍有 62——说明镜2 从头就是另一套机位
（景别差一档、机位高度从 0.62m 俯视变成 0.42m 仰视、背景的玩具与地垫走向整体换了）。这种只能回生产阶段重出开口。

### 剪辑能修的与不能修的

| 接缝问题 | 纯剪辑 |
|---|---|
| 动作在切点两侧断开 | 能：挪切点让动作横跨 |
| 音频在切点处塌坑、听感断一下 | 能：填环境声、做声音桥 |
| 曝光、色温、构图微差 | 部分：叠化、接镜校正 |
| 机位／景别／背景整套换了 | 不能：重出开口 |

把第四类当第一类修，会花时间挪切点和加叠化，改完还是跳——因为镜头本来就不在同一个空间。
报告时直接说「这是机位差，剪辑修不了」，比交一版加了转场还是跳的片子有用。

## 接镜与色彩一致性

逐段生成的素材曝光各不相同，同一场景里切过去会像闪了一下。`render` 默认在同一场景内自动接镜：
剪辑单里相邻、并经《视频提示词.md》的「分镜」与《分镜.md》的「来源」追到同一场景 ID 的几段为一组，
测量每段的逐通道均值与离散度，各向组内中位数拉近 70%，每个通道只用一个增益和偏移。
它只让切点不再跳，不把各段拉成同一均值；换场、插叙和追不到场景的段不动。
实际用到的数值列在 render 输出的「自动接镜」里。

自动接镜看的是全画面统计，会受景别、服装面积和背景影响，以下情况在对应 CUT 处理：

- 段内有意的光态变化（关灯、闪回、冷暖对比）写 `- 画面：不校`：这一段不校正，也不计入组内中位数。
- 自动接镜后仍有可见偏差，先按同一光态选脸、衣物或中性表面作基准比较，再写校正。
  写了校正的段只用这里的值，不再自动接镜，也不计入中位数：

```text
- 画面：亮度 +0.06；色温 -6
```

- `亮度`：加法偏移，工具支持 −0.25…+0.25。
- `饱和`：倍数，工具支持 0…2。
- `色温`：工具的冷暖校正量，支持 −30…+30，正数提红压蓝；不是开尔文值。

这些范围是内置工具的处理范围，不是画面质量标准。需要更大或更精细的校正时使用调色工具。
先试小幅校正，再看渲染结果和相同区域的测量。人物身份漂移、错误光源或缺失动作应交回上游。
整集都不要自动接镜时，在交付规格写 `- 接镜匹配：无`。

生成阶段仍应保持已接受的光线和色调；已有素材只差可校正的曝光或白平衡时，优先评估后期修正。

## 颗粒

项目需要时，在交付规格写 `- 颗粒：6`；不写或写「无」就不加。
内置工具支持 0–20 的动态噪点强度，在拼接后对整片统一应用。
这是一种可选质感处理，不保证产生胶片效果，也不能修复身份、动作和光线错误。
需要按场景区别处理时，使用外部调色工具并记录决定。
