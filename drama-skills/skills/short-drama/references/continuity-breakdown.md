# 场记账（continuity breakdown）

> 依据三级、冲突裁决与写作 QC 的单一真相源是 [逐镜证据台账](observation-ledger.md)（同目录）。
> 账本的机位／光位／站位／持物／时间关系数值不挂依据级，保持唯一数值权威。

场记（script supervisor / continuity supervisor）在真实片场是**准备岗**，不是事后检查岗。
拍摄按场次跳拍：同一场戏的两半可能隔几天才拍，机位高度、光位、道具状态、演员手上的东西都可能变。
所以账必须在开拍前做完，分发给各执行部门当唯一依据；现场只做核对与记录，不做连续性设计。

短剧的 AI 生产同样是跳拍的：先出场景资产、先定白模机位，再逐镜生成，镜与镜之间隔着很多轮。
这条方法原样适用。

## 落到哪里

| 项 | 值 |
|---|---|
| 路径 | `设定集/场记.md` |
| 粒度 | **一部戏一本**。不按集拆、不按场拆，不为每集复制一份 |
| owner | `$short-drama` 主路由（项目级文档） |
| 借用知识 | 空间调度与场次观看读 `$short-drama-direct`；机位/走位/轴线预演读 `video-previs` |
| 版本 | 文首一行 `- 账本：CONT-V001`；改账就换版本，下游引用连同版本一起记 |

不建 `剧集/<EP>/场记.md`，也不建 `场记/SC001.md` 之类的分片。一部戏只有一本，
这样"同一场戏的两半隔了很多轮才做"才不会各写一份互不相认的账。

## 阶段位置

```text
剧本 → 资产（先出场景/地点）→ 导演 → 场记（一部戏一本）→ 分镜 → 图片提示词 → 视频提示词 → 生产
```

- **输入**：已定稿剧本 + 已出的地点/场景资产 + 白模预演工程（白模由剧本与场景资产建出来，见下）。
- **不需要人物形象**。这一阶段的人物只是占位模具，写 A / B / C 这样的代号，不写长相、妆造、
  身份参考、服装细节。人物形象定稿后，把代号换成姓名即可，账本结构不动。
- **可以早开始**：资产出到"场景/地点"就够，不必等人物形定稿。
- **必须先做完**：六本账写完并互相对齐，才允许写第一张分镜和第一条生成提示词。

白模不是外部送来的东西：它由剧本与场景资产建出（`video-previs` 的「从剧本新建白模」入口），
再把摆出来的机位、高度、轴线侧、景别抄进账本。已有的原片白模（拉片路线）同样可以当输入。
两边的对应关系写成账本里的「白模引用」行。

## 为什么不能留到生成时再想

真实片场最难还原的是**机位高度**：高度一变，主体与背景的视差就变，同一场戏换个高度重拍，
两半拼不到一起。AI 生成没有"重拍同一条"这回事，改一次机位就是一条新的片子，
前端分镜、图片提示词、视频提示词全要跟着改。

同理，光位写错一次，整场的光色与阴影方向就分叉，后面每张图都要重新校准。
所以在准备阶段把六本账定死、彼此对齐，是让后续每次生成都读同一组值，而不是每轮重新判断。

## 机制、状态与剪辑接续准备

建卡前读取《导演.md》本场采用的完整模板条款、保护段与实现责任，按 [语料机制与剪辑准备](mechanism-preparation.md) 落入原六账：状态保持/单调/可逆/重置规则，动作阶段与可见接触证明，屏幕方向/注意目标，成对声画交接、所需素材和白模可见性。接续条件集中在时间线账一次记录，两卡引用同一条；具体时间窗和余量预算由分镜确定。它们不替代唯一机位/光位值，也不让场记重新导演。

必要条件未定或冲突写入「未对齐项」，相关范围不交为就绪；已有检查器不自动识别这些散文条件，逐项人工回读。时间连续/间隔与状态是否连续分别判断。

## 六本账

### 1. 场景空间账

每个场景先建可命名的空间锚点，后续所有镜头都回指这组锚点。锚点要有名字，能在一句话里指认。

| 字段 | 写什么 |
|---|---|
| 场景 ID | 与《剧本.md》的 `EP001-SC001` 一致 |
| 地面 | 材质、色、反光程度、是否可走 |
| 主光源 | 实体来源（窗、门、顶灯、灯架），不是"光线柔和"这类形容词 |
| 边界陈设 | 至少一件能把方位钉住的固定物（桌、柜、门、栏杆） |
| 出入口 | 人物能从哪里进、从哪里出；几个都写 |
| 相对位置 | 用方位词或简图描述锚点彼此的坐标关系（窗在北墙、桌在窗下、门在左侧等） |
| 观察方向约束 | 这个空间允许从哪几侧看，哪一侧会穿帮（无墙、无景、逆光死区） |

同场所有镜头的锚点必须一致。发现两镜拍的是"同一间房的两种说法"，回改本账，不在分镜里二选一。

### 2. 逐场逐镜调度卡

真实场记的记录分三层：主体、光、摄影机。调度卡把这三层落到每一镜。
每镜一张卡，ID 写成 `CARD-<场景 ID>-<序号>`（如 `CARD-EP001-SC002-03`）。

**一张 `CARD-...` 与一个 `SHOT-...` 强制一一对应**：场记账先定卡，分镜按卡建镜，一卡一镜、一镜一卡。
不允许两张卡合成一个 `SHOT-...`（那是把两个机位塞进一镜），也不允许一个 `SHOT-...` 借用两张卡
（那会让这一镜同时有两个机位高度与两个光位）。需要多机位或多段时，在账本里就拆成两张卡，分镜跟着建两个镜。

分镜里必须在镜内写明 `- 场记：CARD-...`，且该 ID 必须能在账本里找到；反过来，账本里每张卡也必须
被恰好一个 `SHOT-...` 引用。卡与镜的数量相等，集合相同。

```markdown
### CARD-EP001-SC002-03
- 场景：EP001-SC002
- 主体
  - 在场：A、B
  - 站位：A 在窗左一米，B 在桌后偏右
  - 朝向：A 面向 B（画右）；B 面向 A，头略低
  - 姿态：A 站立、重心在左脚；B 坐、上身略前倾
  - 双手：A 左手垂、右手提袋；B 双手交叠在桌面
  - 持物：A——纸袋（右手）；B——无
- 摄影机
  - 位置：从门口一侧斜向内，距 A 约三米
  - 高度：约 1.35m（略低于 A 眼平）
  - 焦段：约 50mm 等效
  - 景别：中景
  - 角度：平视偏仰
  - 轴线侧：A 侧（保持 A 在画左）
- 运镜：固定（景内在动的是 A 的右手落袋、B 抬头）；这一拍观众要看的是手落下的那一下，机位一动会抢掉它（示例：理由换成本镜自己的，不照抄句式）
- 镜内起止：起——A 提袋站立、B 低头；止——A 把袋放上桌，B 抬头
- 与上一镜的时间关系：连续（接 CARD-EP001-SC002-02 的同一动作）
- 与下一镜的时间关系：间隔（B 抬头之后约两秒）
- 与下一镜的接缝：转场卡（场景同 SC002、光位同 L-02、在场集合同 A/B、A 的位移一步走完）｜硬切＋声音桥（换场景）｜容器内切点
```

- **只写占位代号**。A/B/C 是模具，不承担长相。人物形象定稿后换名字，不换结构。
- **一卡一镜**。每张卡只描述一个机位下的一段连续画面；出现第二个机位就另开一张卡，不在卡内切换视角。
- **机位高度必填**，写数值量级（"约 1.35m""约膝高""约头顶高"），不写"低机位"三个字了事。
- **轴线侧必填**：写本镜站在谁的哪一侧，以及这条侧由哪个建立镜定下。
- **接缝字段**：写本镜与下一镜的接法，并按 `seam-transition.md` §0.4 的四项判据（场景账、光位账、调度卡在场与持物、位移能否一段走完）逐项写出取值。四项有一项不成立就不能写转场卡，写硬切并指定剪辑手段。末镜写「场尾」。
- 同一镜只写一条"镜内起止"，写不下就是该拆镜，不是该加形容词。
- **运镜必填，且不写裸"固定"。** 每张卡回答三件事：动还是不动（固定也是选择）、为什么（这一镜观众的注意要在哪里发生）、动的话怎么动（触发、幅度、落点，如"极缓推近，不超过 5cm，推的是她决定的那半秒"）。固定时写画面里什么在动。
  整集多数卡写成同一个"固定"时，在文末「未对齐项」写明这是导演的选择还是没想过。实例：一个项目 16 张卡里 14 张只写了"运镜：固定"四个字（另一个项目 6 张里 4 张带了理由，不算裸"固定"），下游于是把整集写成固定取景。
- **导演写"连续保持、不切"，账本就不为同一段连续画面开多张卡。** 一卡一镜意味着每张新卡是一次新的机位。导演要的是一个连续取景，账本里就建成一张卡（单机位）、分镜建一个镜；导演要多个机位，就在导演方案里写出切点。导演与账本对不上时按下节"与导演的分工"仲裁，回改后再往下。

### 3. 光位账

逐场统一，不逐镜重编。

| 字段 | 写什么 |
|---|---|
| 主光位置 | 相对空间锚点的方位（左窗、门内灯、顶光） |
| 方向 | 从哪打向哪，与人物的相对关系（顺光、侧光、逆光） |
| 色温 | 具体倾向（日光 5600K 冷白、钨丝 3200K 暖黄） |
| 强度 | 相对量级（主光压背景一档、主光与补光约 3:1） |
| 阴影走向 | 影子落在哪面（人脸左侧、地面朝门） |
| 补光/环境 | 有无、来自哪里 |

同场只允许一组主光值。确实需要变（如有人开灯）时，在光位账里写明**哪一镜、因为什么动作**改变，
并把改变前后的值都写出来，不留给生成时临场决定。

### 4. 道具账

每个关键道具一行，跟踪它的整条命：

| 字段 | 写什么 |
|---|---|
| 道具 | 名称（与《视觉设定.md》道具条目同名） |
| 进场镜 | 第一次出现的镜头 |
| 初始状态 | 出场时什么样 |
| 状态变化 | 逐条：哪一镜、变成什么（开封、沾血、交到谁手里） |
| 持有者链 | 谁拿着 → 谁接过 → 落在哪 |
| 退场镜 | 最后一次出现的镜头，或写"留场" |

只在单镜出现、不跨镜的不必建行；跨镜出现且观众看得出前后不一致的都要建。

### 5. 时间线账

每镜与上一镜的时间关系只有两种，必须二选一写清：

- **连续**：接上一镜的同一动作，中间没有省略；下一镜的起点就是上一镜的终点状态。
- **间隔**：中间省略了一段时间；写出省略的量和依据（"约两秒，B 抬头之后"）。

同一段连续动作被拆成多镜时，全部标"连续"，并在调度卡里让起止状态首尾相接（上一镜的"止"就是下一镜的"起"）。
标"间隔"的镜头要给观众一个能读出来的时间线索，不能靠观众猜。

### 6. 白模引用

每个镜头写明它在白模预演里的对应位置，便于核对"账与白模一致"。

| 字段 | 写什么 |
|---|---|
| 白模工程 | 白模 storyboard JSON 的项目相对路径或工程名 |
| 白模镜头 | 该镜在白模里的镜头 id（如 `S7`） |
| 白模机位 | 白模里用的机位类型或 pos/look 标识（`ots`、`wide`、显式坐标） |
| 核对状态 | `已核` / `待核`；`白模缺此镜` 不是合法终态，必须补建或写进「未对齐项」并说明技术障碍 |

白模引用的作用只有一个：让"账里写的机位"和"预演里摆的机位"能在同一行上对起来。
它不是参考图清单，也不进任何生成请求——白模产物不能当生成参考图，见 `video-previs` 的跨技能红线。

**哪怕只有一个场景，也必须建一个最基础的白模。** 这是硬要求，不接受"单场简单、数值已经写清"
作为跳过理由。原因不是白模能提升画面，而是**后续 agent 会漂移**：分镜、静帧、视频提示词分属不同轮次，
每轮都会重新理解一次"A 在桌子的哪一侧、他在她左后还是右后、玻璃反光从哪个角度进来"。
文字数值能写对一次，不能保证三次都读成同一个意思；白模把这一组关系钉成一张可回看的画面，
后面每轮对照它，而不是各自重新想象。

最基础的白模只需要：一个场景底、人物占位块、每镜一个机位。不需要美术、不需要贴图、不需要动作细节。
判据是——把任意两镜并排看，能不能立刻判断两人相对位置与机位方向前后一致。

确实因为技术原因建不出来时，在「未对齐项」里写明具体卡在哪一步、用了什么方式代替核对，
不能写成"没有额外价值"。

## 生成阶段的读取规则（硬规则）

1. **六本账在第一次生成之前必须全部写完，并互相对齐。** 同一镜在空间账、调度卡、光位账、
   道具账、时间线账、白模引用里的值必须是同一组值。
2. **生成阶段只准引用账本里的值，不许重新描述机位、光位、站位。**
   分镜、图片提示词、视频提示词写"景别/机位/高度/轴线/光位/站位"时，来源是《场记.md》对应的那一行，
   不是这一轮对话里的新判断。
3. 发现账本内部对不上，或账本与剧本对不上时：**回改账本和上游，再往下写**。不在生成提示词里
   临时选一个值糊过去。
4. 需要改一个镜头时，先改账本里这一镜的行，再改下游。已经生成过的素材随账本版本一起标记作废。

## 与现有文档的边界

先分清两个容易混的名字：

- **场记账**（本文件，`设定集/场记.md`）：一部戏一本，记录机位/光位/站位/道具/时间线的**数值**。
- **场景账**（`short-film-scene-continuity`）：独立短片的场景数与同场空间锚点核对，是结构判断，
  不记录逐镜机位高度与光位数值。短剧项目走本文件；独立短片可以两样都要。

《场记.md》不重复、也不取代下面任何一份：

| 文档 | 它拥有什么 | 场记账不做什么 |
|---|---|---|
| `剧集/<EP>/剧本.md` | 剧情、台词、场景划分 | 不改台词，不新增场景 |
| `剧集/<EP>/视觉设定.md` | 人物/地点/道具的识别锚点与连续性锁 | 不写长相、妆造、身份参考 |
| `剧集/<EP>/导演.md` | 场次戏剧行动、观看方案、镜头计划 | 不改导演判断，不重新排戏 |
| `剧集/<EP>/分镜.md` | 观众 reads、画面证明、关键帧正文 | 不写提示词正文；`SHOT-...` 与 `CARD-...` 一一对应，数量与集合都相同 |
| 白模预演工程 | 机位/走位的可播放预演 | 不产生美术，不产生参考图 |

与导演的分工：导演定叙事必需的空间事实与关系（谁在哪一侧、谁挡住谁、光从哪个方向来），
场记账把这些落成可引用数值（机位高度、焦段、景别、站位距离、逐镜时间关系）。两边冲突时，
叙事必需以导演为准回改账本数值；导演只写了允许偏差级细节时，以账本更具体的值为准。

场记账是这些文档之上的**数值层**：它把"这台机位多高、这场光从哪来、这只手拿什么"定成可引用的值。
分镜与提示词引用这些值，不再各自发明。

## 写完之后

- 逐场回读：把某一场的所有调度卡连着读，能不能看出一条连续的空间与时间？
- 跨场回读：同一地点在不同场次出场时，空间锚点与光位账是不是同一组值？不是就分开立场景
  （因为光态不同就是两个场景），不要在一套锚点里写两种光。
- 卡镜对账：账本里的 `CARD-...` 与分镜里的 `SHOT-...` 是否一一对应——数量相等、集合相同、每个镜内都写了 `- 场记：CARD-...`。
- 白模核对：账里写的机位高度、轴线侧、景别，和白模里摆的是不是同一个。对不上时以**剧本与空间约束**
  为准改白模，或改账，但要写下改了哪个。
- 仍未定的项集中写在文末 `## 未对齐项`，一项一行，写清卡在哪。不把未定项留在脑子里。
  本节按 [逐镜证据台账](observation-ledger.md) 分三类登记：`未定`（上游没给、推不出）、
  `疑似`（有线索但看不清／听不清）、`冲突待裁决`（两个来源说法不一致，两条都留并写明按哪个上游仲裁）。
  三类都只进本节，不写进调度卡的数值字段；裁决后回改上游，再改下游。
