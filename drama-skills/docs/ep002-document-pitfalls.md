# EP002 创作文档格式定位表

接手批量报错时，先读 [修复与复核](../skills/short-drama/references/document-repair-lessons.md)，再用本表定位格式。这里不替代当前阶段模板，不把实现缺陷升级为创作规则。

| 位置 | 写法与核对 |
|---|---|
| 视频提示词「分镜」 | 只写对应 SHOT ID；CARD 或说明使用自己的字段，避免附加文字进入 ID 解析。 |
| 视频提示词「生成方式」 | 精确写「图生视频」或「文生视频」；模型、六段结构、执行模式另行说明，并服从当前通道能力。 |
| 每帧镜头语言 | 七项：景别、水平角度、机位高度、焦段意图、构图：、焦点：、帧相位：。元数据位于该帧说明层，模型正文写可见画面；重复字段误报应修解析范围。 |
| 视觉依据 | `《视觉设定.md》·地点「加油站」（控制：范围）`；多个条目以分号连接，名称与标题逐字一致。范围从该帧实际内容反查。 |
| 视觉设定标题 | `## 地点 · 加油站`；不要把「本集新增」等注释混进名称。多人分别建条目。 |
| 人物画面代称 | 非中文提示词中使用的名字写出准确拼写；正文不点名该人物时可写「无」，不能用它逃避可见人物的依据声明。 |
| 连续性锁 | 按模板书写 LOCK 和完整 SHOT ID；锁面用项目提示词语言，并在适用正文中真实出现。不能单为子串检查让画外道具入画。 |
| REF 用途 | 从身份、造型状态、地理、构图、尺度、效果、起始帧、结束帧、风格中选当前模板支持的值，不发明组合枚举。不要为凑用途重复上传同一张图。 |
| 图片提示词项 | `IMG-…《名称》（控制：范围）`；条目必须存在且含可用正文，没有则如实写无。 |
| 输入参考图缺口 | 写真实已核实 REF，并明确剩余缺口；全无时写「无（待补参考图：…）」。路径存在不能代替像素及验收核对。 |
| SHOT 与 MOTION 参考 | 声明一致；先由分镜确定用途，再让视频文档继承。不能机械以下游反向覆盖上游。 |
| 首帧接力 | 本地 H3 首帧与多参考互斥；不能要求首帧旁再挂身份板。真实帧还须符合起点、人物与道具状态及准入要求；不符合就更换续接方案。 |
| 人物构图 | 每个可见人物使用视觉设定中同名条目；小帅不能写成「他」，加油员、店员等功能角色也需明确对应。 |
| 画面证明计划 | start 记录 0s，composition 记录所选瞬间，pose_proof 记录镜内姿势。时刻落在对应 read 内；记录 start 不自动意味着生成首帧，生产 start 时需有独立正文。 |
| 观众 reads | 时间窗按当前契约首尾相接、覆盖镜长，内容对应观众依次理解的事实。不能只改时间码掩盖信息提前出现。 |
| 被操作道具警告 | 核对实体或已登记承载关系；计算器页可以由手机条目承担，车门可由汽车地点承担，并注明理由。不要为接收者「给他」创建道具条目。 |

## 使用与验证

先用一个代表镜验证模板，再扩展到整集；批量替换后回读受影响正文和引用。格式脚本通过只证明它实际覆盖的结构与算术。检查器提前退出、模板与实现矛盾、回归测试失败，都要单独记录。

EP002 此次修复中发现的未闭合实现问题：镜头语言说明字段被按全镜标量解析而误报重复；此前为首帧接力新增的身份豁免触发 `test_image_to_video_with_visible_person_but_no_identity_ref_is_an_error` 回归失败。两项均不能靠污染提示词或继续放宽校验处理；本总结不声称这些实现问题已修复。
